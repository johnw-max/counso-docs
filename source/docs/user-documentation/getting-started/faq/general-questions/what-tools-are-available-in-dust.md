# What tools are available in Dust?

Dust offers several built-in tools: Knowledge Search (RAG on unstructured data), Data Structuration (converting unstructured to structured data), Table Query (SQL-like querying), Visualization (graph generation), Web Navigation and Reasoning.

See details at [Tools & capabilities](/docs/user-documentation/agents/tools/index)
