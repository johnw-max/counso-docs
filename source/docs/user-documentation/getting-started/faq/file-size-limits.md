# File size limits

In-conversation file uploads:

* Images: 5 MB
* Audio files: 25 MB
* Data files (txt, pdf, doc, json, etc.): 50 MB
* Code files: 50 MB
* Delimited files (csv, tsv, xls, xlsx): 50 MB
