# I don't know how to start creating an agent, what should I do?

Click **Create** to start a Sidekick‑guided flow. Describe your goal, and Sidekick will help you draft clear instructions and propose the right tools. You can also browse templates from Create; selecting one opens Sidekick pre‑loaded with that template's context.
