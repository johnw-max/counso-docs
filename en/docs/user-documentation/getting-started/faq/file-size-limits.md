# File upload limits

Conversation uploads use the following per-file limits. If your workspace's upload dialog shows a different limit, follow the value displayed there.

| File type | Maximum size |
| --- | --- |
| Images | 5 MB |
| Audio | 25 MB |
| Documents and data files, such as TXT, PDF, DOC, and JSON | 50 MB |
| Code files | 50 MB |
| Tabular files, such as CSV, TSV, XLS, and XLSX | 50 MB |

These limits apply to conversation attachments. Data connections can have separate limits on file size, extracted text, or worksheet rows. Split a large file into useful sections when needed, and check that important pages or tables were read correctly after upload.
