# Why is a response taking a long time?

A request may take longer when it searches many sources, processes large files, or uses several tools. Try a narrower question, a smaller date range, or one relevant source. Check that your network and browser are working normally.

If only one Agent is slow, ask its owner to review its sources and tools. If many users are affected, report the approximate time, Agent, and request to the workspace administrator or support contact.
