# Why is an updated document missing from an Agent answer?

A connected source may need time to sync or index changes. Check that the file remains in the selected connection scope and that the connection reports no error. Exact timing depends on the source and workspace setup.

Start a new conversation and ask for the document by name or a distinctive phrase. If the new text is still missing, ask an administrator to check the connection status and indexed scope. For urgent exact wording, open the original document directly.
