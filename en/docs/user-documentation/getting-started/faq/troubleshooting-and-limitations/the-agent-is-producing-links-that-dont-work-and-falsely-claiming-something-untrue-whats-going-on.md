# Why did an Agent return a broken link or unsupported claim?

An Agent can generate a plausible but incorrect link or infer more than its sources support. Ask it to cite the source it actually used, then open that source yourself. A citation is more useful than a link invented from memory.

Narrow the question to the available material and ask the Agent to label claims as supported, inferred, or unknown. If the answer still makes an unsupported claim, correct the Agent instructions or report the example to its owner.
