# Customer support use cases

An Agent can help a support team find relevant guidance, summarise a case, draft a response, and group recurring feedback. Connect only the support material and ticket records the team is authorised to use.

## Troubleshoot an issue

Provide the customer’s question, relevant product version, error text, and permitted case history. Ask the Agent to return likely causes, the evidence for each, checks to try, and the point at which the issue should be escalated. Do not let a plausible guess become a confirmed diagnosis.

## Draft a customer reply

Ask for a response based on approved help articles and known-issue notes. Request the source beside each instruction and a separate sentence for anything that needs engineering confirmation. A support specialist reviews the tone, technical accuracy, and customer-specific facts before sending.

## Identify themes in feedback

For a defined period, ask the Agent to group feedback by topic and provide representative source references. Distinguish the number of records actually reviewed from an estimated trend, and check duplicate reports before reporting counts.

## Improve team knowledge

After resolving a case, have a human reviewer decide whether its verified resolution belongs in a help article or known-issue log. The Agent can draft that update, but the knowledge owner approves and publishes it.

## Suggested request

```text
Using the approved support guide and this ticket, draft a reply. Show the source for each troubleshooting step, list what remains unverified, and do not promise a fix date. Do not send the reply or change the ticket.
```

Sending replies, changing ticket status, or updating customer records requires an enabled tool and a person’s review.
