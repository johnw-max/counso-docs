# Knowledge and information retrieval use cases

An Agent can search connected, approved sources and help turn them into a concise answer. It can only find material in its configured scope; it does not automatically know every file in the organisation.

## Find an internal answer

Ask a specific question, name a team or period, and request a citation. For policies and procedures, ask the Agent to quote the relevant rule, its effective date, and any exception. Open the source before relying on the answer.

## Create a team FAQ

Collect approved guides and recurring questions in an accessible location. Ask the Agent to group questions, draft short answers, and flag gaps or conflicts. A content owner verifies and publishes each answer.

## Summarise discussions or research

When the relevant connector and access are available, ask for a summary of a named set of messages or documents over a defined period. Request evidence, decisions, blockers, and unresolved questions separately. Check sample records and avoid treating an incomplete index as a complete survey.

## Use web information carefully

If web search is enabled, ask for dated source links and distinguish public web material from internal records. Verify important information at the original site, especially when prices, policies, or current events may have changed.

## Suggested request

```text
Using only the current approved travel policy, answer whether this trip needs prior approval. Quote the applicable section and effective date. If the source does not cover the case, say what information is missing.
```
