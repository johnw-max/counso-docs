# Introduction to Counso

Counso is a shared AI workspace where people can work with configured Agents, approved knowledge sources, and connected tools. What appears in your workspace depends on your organisation’s setup and your own access.

## Ask your first question

1. Open **Work** and start a conversation.
2. Check which Agent is selected. Choose one whose purpose and access fit the task.
3. Ask one clear question, identify the relevant source or period, and say what format would help.
4. Review the answer against its sources before sharing or acting on it.

You can address an Agent in the conversation using `@` when the interface offers the Agent picker. For a simple first test, ask for a short summary of a document you are allowed to use, then check the key facts yourself.

## Choose an Agent for the work

Your workspace may include shared Agents created by colleagues, as well as general-purpose Agents. Open an Agent’s details to understand its instructions, available tools, and data scope. A specialised Agent is useful when its sources and rules match the task; it is not automatically more accurate for unrelated work.

## Work with others

Use a shared Pod when teammates need a common place for conversations, files, and tasks. Keep sensitive work in a restricted area with the right members. A shared conversation or Pod does not grant extra access to a connected source system.
