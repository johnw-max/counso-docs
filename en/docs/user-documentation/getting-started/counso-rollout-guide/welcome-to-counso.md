# Welcome to Counso

Counso brings configured AI Agents, team knowledge, and collaborative work into one workspace. You can ask questions, organise information, draft content, and work with colleagues in a Pod. The models, sources, and actions you can use depend on your workspace setup and permissions.

## Start with the main areas

- **Work** is where you find Agents, start conversations, and open Pods and Skills.
- **Spaces** organise connected data and its access scope.
- **Admin** is for workspace settings, members, and permissions.

## Three useful habits

1. **Choose the right source.** Name the file, period, or business entity you mean. An Agent can use only sources that are configured and accessible to you.
2. **Review the answer.** Check citations, names, amounts, dates, and conclusions before sharing or relying on them.
3. **Separate a suggestion from a completed action.** If an Agent proposes changing an external record, confirm the authorisation and check the destination system afterwards.

Counso can help organise information and coordinate work; the responsible person still makes business decisions. For a shared workspace, see the [Pods overview](../../pods/overview.md).
