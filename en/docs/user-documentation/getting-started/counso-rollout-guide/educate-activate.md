# Train and support the team

Training should show people how to complete one task, check its answer, and find the right owner when something is uncertain. Add your organisation’s own data and approval rules to the material.

## Cover the essentials

Explain why the team is using Counso and which tasks are suitable. Show which data may be used, how to choose an Agent and name a source, how to inspect citations, and what to do when a file is missing or a result is wrong. Make clear which outputs require approval by an accountant, manager, or administrator.

## Run a hands-on exercise

Use an approved, low-risk example. Demonstrate asking a question, checking the cited source, clarifying a gap, and saving a follow-up task. Ask each participant to complete the flow themselves. Include a case with incomplete information so they practise asking the Agent to identify the gap instead of guessing.

## Keep learning from use

Ask users which steps became easier, what required correction, and which sources were missing. The workflow owner can then decide whether to improve the instructions, update source material, provide more training, or pause the use case.
