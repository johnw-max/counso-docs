# Team onboarding material

A short onboarding session should help each person complete and check one useful task. It does not need to cover every feature in the workspace.

## Suggested session

1. **Explain purpose and limits.** Show which work the team is trying to improve and which data must not be shared.
2. **Demonstrate a request.** Use an approved short document; show how to select an Agent, state the outcome, and request a useful format.
3. **Practise checking sources.** Open a citation, verify dates and facts, and identify what the Agent could not confirm.
4. **Show the team workflow.** Demonstrate where shared files and conversations belong, how to assign a follow-up, and who reviews the result.
5. **Collect questions.** Record recurring access, source freshness, and quality issues for the workflow owner.

Before sharing this material, add your organisation’s approved data types, human-approval points, support contact, and available connections. After the session, have each participant complete a low-risk request, check its source, and update or share the result as appropriate.
