# Set up your Counso workspace

Before a team uses a new workflow, confirm that members can sign in, connected sources are in scope, and Agent access matches the intended audience. Menus and available connections vary by workspace, so use the controls currently shown in your Admin area.

## Manage members and identity

Review the member list, invitation flow, and available roles. If your organisation uses single sign-on or central identity management, follow the identity administrator’s process. For a login problem, verify the invited address and identity-provider status before creating another account.

## Configure connections and tools

Connect only sources the workflow requires. Confirm the connected account can access the intended material. A data connection used for search and a tool that changes a record are different capabilities; verify the specific action and Agent configuration before enabling a write.

## Set access boundaries

Decide which Spaces or Pods are open to a broad audience and which require invitation. Shared conversations and files are visible according to membership. Folder names and Agent instructions do not replace access controls. Use separate spaces when audiences differ and review their members explicitly.

## Maintain the workspace

Periodically check members, connection health, and the usage information available to administrators. Record who owns each workflow and who reviews its output. Pricing, model availability, and product features depend on the current workspace and service agreement; do not reuse figures from another account.
