# Manage Agents

Use the Agent management page to find and organize Agents you can access. The list can be searched and filtered, including by Agents you can edit and default Agents supplied by the workspace.

## Open and edit an Agent

Open **Manage Agents** from the main page. Select an Agent to review its description, configuration, editors, tags, and access. Administrators can open any Agent in view-only mode. To change it, choose **Become an editor** in the banner or **Editors & Access** section; this adds the administrator to the Agent's Editors list. Make and save the change as an editor.

Before editing an Agent, check which sources and Spaces it uses. A change to its tools or audience can affect both data access and who can use it.

## Create and assign tags

Tags help members find Agents by purpose, team, or workflow. Administrators can open **Manage Agents > Tags > Manage Tags** to create, rename, or remove tags and see which Agents use them. If there are no tags yet, the workspace may suggest tags based on existing Agents.

After tags are available, assign them from the Agent list. Use a consistent set of labels so members can search and filter the catalog.

The same **Become an editor** approach may be available for Skills in Skill Builder.
