# Set up a workspace

This guide walks a workspace administrator through the first setup: connect a useful source, make it available to the right people, and give them a focused Agent to try. You can use the workspace before adding sources, but answers grounded in company material require data the Agent can access.

## 1. Review membership and roles

Open the administration area and confirm who has administrative access. Invite members with the role and permissions they need. Keep administration, billing, and security access limited to the appropriate people. See [Workspace roles, groups, and permissions](admin-governance/workspace-governance-roles-groups-and-permissions.md).

## 2. Connect one source

Open **Spaces** and go to **Connections**. Choose a supported connection, select **Connect** or **Authenticate**, then authorize the account and choose the folders, channels, or other locations to sync. Start with one useful, appropriately scoped source; you can add more later. For setup details, see [Connections](../data-sources/connections.md).

## 3. Put the source in a Space

A connected source is not automatically available to all workspace members. Add the selected data to an open or restricted Space and choose the Space audience. Check both the selected source scope and the Space membership before sharing. Read [Spaces management](spaces-management.md).

## 4. Try a focused Agent

Use an available default Agent or create one for a specific task. Give it access only to the Space and data it needs. Ask a question with an answer you can verify in the source, then check whether the Agent found the right material and cited it clearly.

## 5. Share carefully

Before publishing an Agent or making it available in a collaboration channel, check the Agent's editors, audience, and data sources. A person who can use the Agent still needs permission to its source data. If an integration such as Slack is enabled, test in a channel where the participants are expected to see the answer.

After the first test, add another source or workflow only when there is a clear need. Keep access and instructions focused as the workspace grows.
