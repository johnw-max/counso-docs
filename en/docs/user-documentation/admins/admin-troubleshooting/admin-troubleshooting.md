# Troubleshoot workspace administration

## Before you begin

Identify workspace, role, Agent or Space, and the smallest reproducing request. Never send passwords, keys, tokens, customer records, or private conversations.

## Steps

1. Check Agent, source, Space, and usage settings; record exact error and time.
2. Repeat the smallest safe request once and note whether one person, Agent, or workspace is affected.
3. Use the support/help contact exposed by Counso or the approved administrator route.
4. Include workspace ID, area, client, reproduction, expected/actual result, and any visible request ID; attach only redacted material.

### Example report

```text
I’m signed in to the finance workspace. In Work > Agent conversation, I asked,
“List unpaid supplier bills for August, with source and amount.” The answer said
the source was unavailable. Two members saw the same result, and no write was
attempted. Include the request time and any visible request ID in the report.

```

These details help support narrow the investigation. Supply a corresponding redacted sample if more material is needed.

## Result

Support receives a reproducible, privacy-preserving report and can separate access, configuration, usage, and provider failures.

## Common questions

**Where is the status page?** Use only a link displayed or provided by Counso.

**Should I create a public issue?** Use public channels only for non-sensitive questions.

**What if no support control is visible?** Ask the workspace owner for the approved Counso contact path.

## Compare affected and unaffected users

First determine whether the issue affects one person, one Agent, one connection, or the whole workspace. Compare the affected person's role and access with a member for whom the same action works, then inspect the relevant connection, usage, identity, or audit details. Change one setting at a time and repeat the same safe check.
