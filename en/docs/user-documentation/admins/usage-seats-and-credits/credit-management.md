# Credit management

Use **Admin > Usage** to see the usage information and controls enabled for the current Counso workspace. Available credit sources, limits, reset dates, and billing options depend on the active subscription.

## Understand the available balances

A workspace may show an individual allowance for a member, a shared workspace pool, or both. Some subscriptions also display an overage option. Use the order and status shown in the usage panel to understand which source a request will draw from; do not assume that another plan's limits or overage rules apply here.

If both an individual allowance and a shared pool are enabled, the current usage panel explains the draw order. A member-specific spend limit may cap how much of the shared pool that member can use. Check its description: in configurations where the limit applies only to the shared pool, it does not reduce the member's separate seat allowance.

## Review usage and manage limits

The Usage page shows the workspace balance and may include a Members table with each member's seat, consumed usage, and remaining balance. Use the table to search or filter members and to adjust seat or individual pool limits where those controls are available.

Depending on the subscription, workspace administrators may see some of these settings:

- **Default workspace pool limit:** sets the default amount of the shared pool members may use. A setting of zero may prevent members from drawing from the pool.
- **Member spend limit:** sets a different pool allowance for an individual. Check whether changing the default affects only members who still inherit it.
- **Upgrade request:** lets members request a seat or usage change when they reach a limit. Review requests in the Members section if that tab is available.
- **Automatic seat change:** if offered, may move a member to a higher seat when they reach a limit. Confirm the subscription and billing impact before enabling it.
- **Balance and request notifications:** review the threshold and recipients shown in the current settings.

A top-up, if available, is an additional workspace balance. Before purchasing, check the current checkout summary for amount, price, expiry, and any other conditions.

## Automated activity

If Counso shows a separate usage section for an enabled automated workflow, review its owner, run frequency, expected volume, and any available cap. Use only the controls and eligible sources shown in the current workspace.

For the distinction between a member's role and seat, see [Seat management](seat-management.md). For how an interaction contributes to usage, see [Credits](credits.md).
