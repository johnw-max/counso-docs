# Manage connections

Connections make selected content from other platforms searchable in Counso. Open a Space, choose **Connections**, and select the platform to connect. An administrator authorizes the connection and chooses the content to synchronize.

Keep the connected account and its permissions stable: changing that account's access can change what the connection can retrieve. Make the synchronized sources available in the appropriate Space and select them in the agent's knowledge settings.

Choose a guide for the platform you use:

- [Google Drive](google-drive.md)
- [Notion](notion.md)
- [Confluence](confluence.md)
- [Microsoft](microsoft.md)
- [Intercom](intercom.md)
- [Zendesk](zendesk.md)
- [Gong](gong.md)
- [Snowflake](snowflake.md)
- [BigQuery](bigquery.md)

A connection provides synchronized knowledge. To create or edit records in another platform, configure the relevant agent tool as well.
