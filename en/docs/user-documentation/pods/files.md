# Work with Pod files

The **Files** area is the Pod's shared library. Uploaded files, linked company material, and files created by an agent are available to members and can be searched by agents.

## Before you begin

Prepare the source files and decide whether the Pod needs a copy or a live link. Upload a copy when the Pod needs a stable snapshot. Link company data when the source should remain managed centrally.

## Add and organise files

1. Open the Pod and choose **Files**.
2. Choose **Add**, then select **Upload file**. Select files or drag them into the list.
3. For structure, choose **Add > New folder**, name the folder, and move files into it by drag-and-drop or the file menu.
4. To link shared company material, choose **Add > Add from Company Data**, select the pages or folders, and save.
5. Click a file to preview it. Use its menu to rename, move, delete an uploaded file, or remove a linked item.

An agent can also fetch material through an enabled connector and save the result into the Pod. State whether the result is a snapshot or a transformed copy, and keep the source name and date in the file name or description.

## Keep a changing file current

For a weekly report or other living document, ask an agent to fetch the source and overwrite the same Pod file on a schedule. Confirm that the source connector can read the source and that the agent has permission to write the Pod file. A new file with a similar name is not the same as updating the existing one.

## What you should see afterward

The file appears in the shared list and can be opened by permitted members. Linked data carries its link status and is retrieved from the managed source; an uploaded file is a Pod copy. Agents can use indexed material automatically, but a file format that is not indexed may need to be referenced directly in a conversation.

## Common questions

### Why can I not link a private source?

Pod links must remain readable to every Pod member. Use an uploaded, approved copy or place the work in a Pod whose members have the required source access.

### Why is a changed source not visible immediately?

Indexing or synchronization can take time. Check the source, wait for the next update, and ask the agent to read the original when exact current content matters.

### Is a generated file the same as the source of truth?

No. Label generated or converted files clearly. Keep the authoritative source in its owning system and use the Pod file for collaboration or a declared snapshot.
