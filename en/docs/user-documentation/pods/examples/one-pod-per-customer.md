# Example: a Pod for each customer

A professional-services team can create one Restricted Pod per customer when each customer has a different audience, source set, or confidentiality boundary. This keeps collaboration in one place without mixing one customer’s material with another’s.

## Set it up

- Use the customer’s agreed name and identify the service period or engagement in the description.
- Add only the staff and customer contacts who should see the shared workspace. Keep internal review notes in a separate restricted area when the customer should not see them.
- Add the engagement brief, agreed policies, and customer-provided files with clear dates and source names.
- Create tasks for missing documents, review work, and agreed follow-ups.

## Work with customer-provided material

Ask the Agent to list what arrived, identify the period and entity where evident, and flag missing or unreadable items. Do not infer missing figures or tell the customer a document was processed until the responsible accountant has checked it. Keep originals and corrections traceable.

A customer invitation grants visibility to the Pod contents according to membership; it does not create a separate hidden folder inside the Pod. If internal and customer audiences differ, use separate Pods and carefully review each Agent’s access scope.
