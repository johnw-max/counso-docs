# Example: a shared asset library

A design, brand, or communications team can use a Pod to keep approved, reusable material together. The Pod should contain assets intended for its member group; an Open Pod is suitable only when every workspace member may see the contents.

## Set it up

1. Create a Pod with a clear purpose, such as “Approved brand assets.”
2. Add the small group that maintains the materials as Editors and select the intended visibility.
3. Upload approved logos, templates, writing guidance, and reference files. Use folders such as `Brand`, `Templates`, and `Product images` only to organise files.
4. Add a short description that explains the current versions and whom to contact about an update.

## Use and maintain it

Ask an Agent to use a named source file when drafting a report or content piece. Have it save a working copy in the relevant project Pod; do not let it overwrite the approved master. The asset owner reviews replacements, removes superseded files, and keeps a simple change note when a change affects other teams.

## Check before sharing

Do not put licensed, confidential, or customer-specific files in a broadly visible Pod. Confirm that each person who needs an asset can access it, and that removing someone from the Pod does not leave another copy exposed elsewhere.
