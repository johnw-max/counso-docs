# Example: a content production Pod

A campaign or editorial Pod can keep the brief, drafts, comments, approvals, and publishing tasks together. Use a separate Pod for a campaign when its audience or source material differs from other work.

## Set it up

1. Add the approved brief, audience, key messages, terminology, and brand guidance to **Files**.
2. Create one task per deliverable, such as an article, email, or event description.
3. Assign a writer and a reviewer; state the channel, format, and due date in the task.
4. Ask an Agent to draft from named sources and mark unsupported claims for review.

## Review and publish

Keep the draft and feedback in the task’s conversation so the next reviewer can follow changes. The reviewer checks factual claims, links, permissions for imagery, and tone before approving. A person publishes through the normal channel and records the final link and date in the Pod.

An Agent may help adapt approved copy into a shorter version or another language. It should not publish or claim that publishing succeeded unless a suitable tool performed the action and the destination confirms it. Content calendars, automatic review tasks, and performance reports are optional workflows that require their own tools and setup.
