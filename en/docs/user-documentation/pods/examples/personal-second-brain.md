# Example: a personal knowledge Pod

A personal Pod can hold notes and references that one person regularly uses. It is useful for keeping recurring work and follow-ups together, but it should not become an unreviewed copy of every private file or connected account.

## Set it up

1. Create a Restricted Pod and keep its membership limited to yourself unless collaboration is intended.
2. Add only the policies, notes, and working documents you are allowed to store there.
3. Write a short description of your current work and how the material should be used.
4. Create tasks for commitments that need an owner or due date.

## A practical weekly routine

Ask an Agent to summarise the Pod’s open tasks and recent notes, separate decisions from ideas, and list items that need your attention. Review the list, update tasks, and remove or replace information that is no longer current. Keep sensitive source records in their approved system unless your organisation allows a copy in the Pod.

Scheduled summaries or connections to email and calendars require the corresponding tools and permissions. If they are not available, use a manual review rather than assuming the Pod is collecting information in the background.
