# Pod policies for workspace administrators

Administrators manage two Pod policies under **Admin settings > Capabilities**: who can create Open Pods, and whether members can add files manually.

## Pod visibility

| Setting | Effect |
|---|---|
| **Private and open Pods** (default) | Members can create either Restricted or Open Pods. |
| **Private Pods only** | Members can create only Restricted Pods. The Open visibility toggle is disabled and a notice is shown. |

Turning on **Private Pods only** does not close existing Open Pods. Pod Editors can change those Pods to Restricted manually.

## Pod files

| Setting | Effect |
|---|---|
| **Manual updates allowed** (default) | Members can upload files and link Company Data to a Pod. |
| **Manual updates disabled** | The **Add** button is hidden. Agents and automated connectors can still populate the Files tab. |

Both policies default to the more permissive option. Changing a policy affects the corresponding controls for members; review existing Pods separately when changing visibility policy.
