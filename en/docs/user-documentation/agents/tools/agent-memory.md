# Agent Memory

Memory lets an Agent retain selected information across conversations so it can respond with relevant continuity, such as a user's stated preferences or recurring context. When enabled for an Agent, it may decide to save useful information from a conversation; a user can also explicitly ask it to remember something.

Memory is separate from shared Knowledge sources. It is private to the individual user for that Agent and is not a workspace-wide record for other members. Users can review or delete saved items from the Agent's details panel. Deleting an item cannot be undone, and memory remains until it is removed.

Enable Memory from the Agent builder's **Tools** area, then explain in the Agent instructions what kind of user preferences are appropriate to remember. Do not ask it to retain credentials, sensitive records, or temporary facts that should not outlive the task. Check the memory panel if a response appears to rely on outdated personal context.
