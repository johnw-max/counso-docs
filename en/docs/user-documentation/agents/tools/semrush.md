# Semrush

The Semrush remote tool connects an Agent to the Semrush account's available keyword, domain, SEO, or trends data. It is operated and supported by Semrush; available reports and API units depend on the provider account and plan.

A workspace administrator adds the Semrush MCP tool from **Spaces → Tools** and completes the authentication option shown by the current form. Use the approved Semrush account and share the tool only with the relevant Space. Add it to an Agent, then run one narrowly scoped domain or keyword report.

Before using a result, check the selected account, report type, date range, and any provider unit consumption shown by Semrush. If access is unavailable, confirm API access is enabled on the Semrush account and that the key/OAuth identity has the needed product access. Contact Semrush for provider-side data or API issues.
