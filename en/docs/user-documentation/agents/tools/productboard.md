# Productboard

Productboard tools let an Agent capture feedback and work with notes, features, and related product entities. They can help with feedback triage, backlog review, roadmap planning, research summaries, and dependencies. Available actions are governed by the connected account and Productboard field permissions.

An administrator adds Productboard under **Spaces → Tools → Add Tools** and completes OAuth. The tool may support workspace-level credentials or individual user credentials; select the mode shown by the current form. Share it with the intended Space, then add it to an Agent.

## Available operations

- **Get Configuration** describes note and entity types, required fields, supported values, and allowed operations.
- **Create Note**, **Update Note**, **Get Note**, and **Query Notes** manage or search notes, including source, owner, status, tags, and date filters.
- **Query Entity**, **Create Entity**, and **Update Entity** work with products, components, features, subfeatures, initiatives, objectives, key results, releases, release groups, companies, and users. Entity fields and relationships vary by type.
- **Get Relationships** retrieves parent/child, linked, blocking, or blocked-by relationships.

Read the configuration before writing: creation fields and update operations vary by type. Confirm the target note or entity and its relationships, then check the record in Productboard after a change.
