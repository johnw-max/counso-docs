# Canva

The Canva AI Connector lets an Agent find existing designs and, where enabled by the Canva organisation, create, edit, autofill, or export designs. Available actions depend on the account plan, organisational controls, template permissions, and the identity used for authorization.

## Connect Canva

A Canva administrator first enables the AI Connector under the organisation's **Controls and permissions**. In the workspace tool list, add the Canva MCP tool and complete the OAuth flow with the intended Canva account. Use the callback and fields shown by the current connection form; share the tool only with the Spaces that need it.

Add it to an Agent and start with a search or a read of a known design. For creation, resize, template autofill, or export, specify the target folder/design and output format, then review the resulting artifact in Canva. If the tool is unavailable, check that an administrator enabled the Connector and that the account can access the design or template.
