# File Generation

File Generation lets an Agent create a downloadable document from its answer or convert provided content into a supported format. Common outputs include PDF, Word, Excel, CSV, and presentation formats; the current conversation tool shows which formats are available.

Enable the capability in the Agent builder's **Tools** area and tell the Agent what artifact to create, who will use it, and how to structure it. For a spreadsheet, specify sheet names, columns, formulas, units, and whether source data should be preserved. For a presentation or document, state the intended audience, length, and sections.

The Agent can generate a new artifact or convert one file format to another, but conversion does not guarantee that formulas, layout, embedded media, or formatting have been preserved. Open the downloaded file and check its content, formulas, links, page breaks, and dimensions before sharing. If the result is incomplete, clarify the source range and output requirements rather than assuming the first file is ready.
