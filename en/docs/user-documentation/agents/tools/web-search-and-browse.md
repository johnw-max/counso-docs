# Web Search and Browse

Web Search finds relevant public pages for a question; Browse opens and reads selected pages so the Agent can work from their current content. These capabilities use the public web and are different from searching an organization's connected sources.

Enable the capabilities in the Agent's **Tools** settings. In its instructions, state when to search, which domains or page types are appropriate, how recent the information should be, and how sources should be cited. For a current or disputed claim, ask the Agent to compare more than one reliable page and provide links.

Search results may omit pages, surface outdated content, or reflect a site's published text rather than its underlying records. Pages may block access or require sign-in. Give the Agent a specific domain or page when results should be limited. For private company material, use an authorized Connection or Tool rather than assuming web search can access it. Verify important facts on the cited page before relying on the answer.
