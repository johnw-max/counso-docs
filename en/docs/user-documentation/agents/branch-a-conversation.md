# Branch a conversation

Branch a conversation when you want to continue from a particular point without changing the original discussion. A branch creates a separate conversation with its own later messages and files.

## Create a branch

Use the conversation's **three-dot menu** to branch from the latest Agent message. To branch from the middle of a conversation, open the menu on the specific Agent message and choose the branch action there. The conversation-menu option uses the latest Agent message as its starting point.

Branch preparation typically takes 10–20 seconds while the system summarizes the conversation. You can send messages during this time; they are queued until the new conversation is ready.

## What the branch contains

The new conversation starts with a summary of the conversation up to the selected point. It also receives copies of files and tool outputs available in the parent at that point, so later edits in the branch do not change those parent files, and vice versa.

The branch inherits the same Space or project and the tools and MCP servers available to the person who creates it. The person who branches becomes the initial participant. The parent shows a link or note identifying the branch point, and the branch shows a **Branched from** link so you can trace its origin.

## Permissions and independence

Branching does not modify the parent conversation. The branch is a separate conversation with its own future messages, files, and actions. It begins with the parent's access at the time of branching, but permissions can diverge later if restricted content is added or membership changes.

People who can access the parent do not necessarily become participants in the branch. Check its participant and Space settings before sharing it with colleagues.

## Common questions

**Can I branch a branch?** Yes. Each branch is a separate conversation and retains its own lineage.

**Are attachments available in the new branch?** The system copies the files and tool outputs that were available at the branch point. The copies are separate from the parent's working set.

**What if I want a different answer?** Continue in the branch with the new direction. The parent remains unchanged, so you can compare both paths.
