# Create your first Agent

An Agent combines instructions with selected Tools and Knowledge. Start with one clear task, give it only the information it needs, and test the result before sharing it.

## 1. Start with Create

From the home page, select **Create**. Choose a blank Agent or a template. Sidekick opens to help draft the instructions and suggest a starting configuration. Read its suggestions before applying them; you can edit the text and configuration at any point.

## 2. Write the instructions

Describe the work, the expected answer, and what to do when information is missing or conflicting. Use Sidekick to refine the draft, then review each change in context. See [How to write effective instructions](llm-best-practices/how-to-write-effective-instructions.md) for a practical structure.

## 3. Choose Tools and Knowledge

Sidekick may suggest capabilities based on the task. In **Tools & Knowledge**, add only the sources and actions the Agent needs. For a document-search example, choose the relevant Space, select the connected source and the specific folder or collection, then add a short description explaining when to search it. Remove suggestions that do not belong to the task. Read [Tools and capabilities](tools/index.md) for the available options.

## 4. Test in Preview

Use the preview beside the builder to try representative questions. Check that the Agent finds the expected material, uses the right sources, and follows the requested format. If it misses something, adjust the instructions or source selection and test again.

## 5. Add a name, description, and tags

In **Settings**, give the Agent a name people can use to call it, a brief description of its purpose, and tags that help colleagues find it. **Suggest** can propose tags from the description. Workspace administrators manage the available tag list; other members can choose from that list.

## 6. Publish and choose Editors

Publish the Agent when it is ready to be used by workspace members. A published Agent is available only to people who can access its underlying data sources. Until it is published, it is visible to you and its Editors. Add the people who should maintain it in **Editors**. Review its data access before sharing.

## 7. Use the Agent

In a conversation, call the Agent by its name or handle and state the task. If it is not available to a colleague, check whether it is published and whether that person can access its sources.

## A few habits that help

- Give an Agent one main responsibility; chain Agents when a task has distinct stages.
- Keep the source list focused so the Agent can choose relevant material.
- Spend time testing instructions and the expected output before colleagues depend on it.

For instruction examples, see [effective instructions](llm-best-practices/how-to-write-effective-instructions.md).
