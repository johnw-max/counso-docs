# Schedule an Agent

Create a schedule in the Agent Builder's **Triggers** section. The schedule describes when the Agent should run and can include a message to guide that run.

## Create a schedule

1. Open the Agent in Agent Builder and go to **Triggers**.
2. Add a **Schedule**, give it a recognizable name, and describe the frequency in plain language.
3. Select the time zone the schedule should follow. The initial choice may use your location; check it explicitly if the schedule serves another region.
4. Add an optional message with the work the Agent should perform on each run.
5. Review the generated schedule preview. Confirm the displayed days, time, and time zone match your intention.
6. Save the Agent so the schedule is registered.

## Check a scheduled run

After saving, review the schedule details and the first run. At present, trigger runs may be visible only to the Agent editor, depending on workspace configuration. Confirm who can view the resulting conversation before using a schedule for shared work.

If the preview has the wrong local time or cadence, update the schedule description or time zone and check the regenerated preview before saving. A schedule controls when the Agent starts; it does not by itself grant people access to the Agent's sources or make its result visible to everyone.
