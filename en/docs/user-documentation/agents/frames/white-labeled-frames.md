# Add your brand to shared Frames

Workspace administrators can configure the branding shown on publicly shared Frames when the workspace offers this option. The branding appears on the Frame page and can also appear in link previews; it does not change the Frame's data or sharing permissions.

## Configure the logo and icon

1. Open **Admin** and select **Branding**.
2. Upload the company logo and icon, then save.
3. Open a publicly shared Frame and check the result in a browser tab and in a link preview.

Use a horizontal logo that remains readable in a compact header and works against a light background. The company icon should be square with a **1:1 aspect ratio**; it is used as the browser favicon. Link previews may use the logo where the sharing destination supports Open Graph previews.

Check that the public Frame contains only the information intended for external viewers. Branding changes the presentation of a public Frame; it does not make private content safe to share or limit who can open a public link.

Availability can depend on workspace configuration. If **Branding** or the Frame options are not shown to an administrator, check the workspace's current feature settings.
