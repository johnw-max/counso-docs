# Use meeting transcripts with Agents

If Meeting Transcripts is available in your workspace, an Agent can work with new meeting transcripts and, where configured, send a follow-up by email. Check which transcript source and Agent are selected before relying on automatic processing.

## Google Meet transcripts

1. Turn on transcription for the Google Meet meeting.
2. Connect the Google Drive account that owns the transcript. Meet normally saves transcript files in the organizer's Drive, often in **Meet Recordings**. The meeting organizer's account therefore needs to be the connected account.
3. Select the intended Agent in the Meeting Transcripts settings.
4. After a meeting, confirm that the transcript file exists in Drive and that the expected Agent processed it.

Detection may depend on the transcript filename. If both **Transcription** and **Meeting notes** are selected in Meet, the generated file can use a different name and may not be detected. For meetings that should be processed automatically, select **Transcription** and verify the resulting file.

If a transcript does not trigger, check that the Drive connection is active, the file exists, the connected user organized the meeting, and the intended Agent is selected.

## Notetakers and sales-coaching sources

Meeting notes from services such as Granola or Fathom can be made available through a workspace connection when that connector is offered. Connect the service in the appropriate Space, then ask an Agent about the meeting material that is available to it.

For a sales-coaching connection such as Gong, the person configuring it may need a technical administrator role in that service. Review the provider's privacy settings: the source may include workspace transcripts except those marked private. A Praiz connection is similarly available only where the workspace offers it.

## Common uses and review

Agents can summarize meetings, extract customer feedback, or help assess a sales conversation. Compare the summary with the original transcript before sharing it, especially when it includes commitments, customer sentiment, or action items. Confirm recipients before sending any email follow-up.
