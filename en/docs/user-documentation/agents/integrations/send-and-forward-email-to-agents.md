# Email an Agent

If **Email Agents** is enabled for your workspace, you can address an Agent from email. The workspace administration page provides the address to use; copy it from there rather than constructing an address from the Agent name.

## Enable email access

A workspace administrator opens **Workspace Settings > Capabilities**, enables **Email Agents**, and reviews the security notice. Only use this feature if the workspace shows it as available.

## Start or continue an email thread

Use the Agent address shown in the workspace to start an email, forward a message, or add the Agent when replying to a thread. Include any instructions in the message body. The service matches the sender's email to a workspace member; messages from people who are not members are not processed.

The Agent reads the email thread body and attachments included in the message you send. It does not get attachments that appeared only in earlier messages. It replies to the sender in the thread; other To or Cc recipients do not receive the Agent's answer. The Agent cannot start an email conversation on its own or change the recipient list.

## Actions and permissions

The Agent uses its usual instructions and tools with the sender's workspace permissions. If an action that changes an external system requires confirmation, review the private confirmation request before accepting it. Forwarded content can include untrusted instructions, so treat it as you would when forwarding a message to a colleague.

Check the Agent address and recipient before sending. If the workspace does not display an address or the message is not processed, ask an administrator to confirm that Email Agents is available and enabled.
