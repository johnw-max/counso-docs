# Create an Agent from a template

Templates give you a starting point for common Agent use cases. Choosing one opens a guided creation flow in Sidekick with the template's context already loaded. Sidekick drafts initial instructions and may suggest Tools and data sources for the use case.

## Follow the guided flow

1. Open the template gallery and choose a template that matches the work you want the Agent to do.
2. Review Sidekick's draft instructions and the proposed Tools or sources.
3. Accept a suggestion, edit it to fit your team's process, or decline it if it does not apply.
4. Test the Agent in Preview using an example from the intended workflow.
5. Set its name, description, tags, audience, and Editors; then publish when the configuration is ready.

A template is a starting point, not a guarantee that its instructions or source choices match your organization. Check every suggested capability and data source before publishing. For the complete setup, see [Create your first Agent](create-your-first-agent.md).
