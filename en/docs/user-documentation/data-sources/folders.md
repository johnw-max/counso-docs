# Folders

Folders keep uploaded reference material together and make it available to Agents as a source. Admins and Space builders can create one from **Spaces → Folders**. Give the folder a clear name and description that identifies its subject, owner, date range, and contents; the description helps an Agent choose the right material.

Folders can contain two broad kinds of input:

- **Documents**, such as PDFs and text files, for search and extraction. PDFs are converted to text; complex tables and embedded images may not be extracted reliably.
- **Tables**, commonly CSV files, for structured analysis with a table-query capability.

Manual folder uploads and conversation attachments have different size limits. The interface shows the applicable limit; as a reference, the source documentation lists 30 MB for manual Folder uploads and 10 MB for conversation attachments. Check the current form before preparing a large file.

Folders are scoped to their Space and do not automatically become available to every Agent. Add the relevant folder to the Agent's knowledge configuration and verify that the Agent can find a known record. A folder does not synchronize changes from the original file; replace or update its contents when the maintained source changes.
