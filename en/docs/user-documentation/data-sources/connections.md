# Connections

A Connection synchronizes an administrator-selected part of a provider into a Space so Agents can search it. Setup has two decisions: which records to sync, and who should be able to use them. Choose folders, channels, sites, pages, projects, or other provider scopes first; then assign the connection to the intended Space. Use a restricted Space when access should follow membership rather than being available to the whole workspace.

After authorization, the first sync can take several minutes. Check its status and ask an Agent to find a known, non-sensitive item. Compare the item, source location, and visibility with the provider. If it is missing, check whether it was selected for sync, whether the connected account can access it, whether it is in the right Space, and whether refresh has completed. Do not broaden the source or Space until you know which boundary caused the gap.

A Connection is for synchronized retrieval. It does not make an Agent perform live provider actions; configure a separate Tool for those operations. Likewise, a Tool's credentials do not automatically make the provider's entire content searchable.
