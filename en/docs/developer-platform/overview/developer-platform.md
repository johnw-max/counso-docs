# Counso developer platform

The Counso developer platform gives teams a way to connect Agents to their own applications and workflows. Use the API to create conversations and work with workspace data programmatically. The [API reference](../counso-api-documentation/openapi-and-postman.md) describes the available requests. The JavaScript SDK provides a client for applications built in that environment.

An Agent combines a model with instructions, tools, and company knowledge. Members can use a default Agent or build custom Agents for specific tasks, and several Agents can participate in one conversation. The model picker offers models made available to the workspace; administrators can restrict which models members may select. Conversations are where people and Agents exchange requests and results. A workspace contains its members and configuration; Spaces organize access to conversations, tools, and data.

Counso makes information available through several kinds of data sources: managed Connections that sync provider content, public websites ingested for search, Folders for uploaded documents and tables, and custom sources built with the API or an import script. Connections sync according to their configured provider settings; admins can narrow the scope to particular channels, folders, or pages where the connector allows it. Tools let Agents perform operations in external systems, subject to the connected identity’s permissions. A data source holds indexed content that an Agent can search or include in context; a tool is for taking action. Indexing a file does not grant permission to change the source system, and adding a tool does not automatically make all of that system’s content searchable.

Agents can search data sources for relevant passages, include documents from newest to older until the model’s context limit is reached, query tables, or extract structured data according to an Agent’s configuration. For example, create a conversation with `POST https://app.counso.ai/api/v1/w/{wId}/assistant/conversations`, then send messages to `/api/v1/w/{wId}/assistant/conversations/{cId}/messages`. Replace the base URL when your application targets another Counso environment. Available models, integrations, and administrative controls depend on the workspace. See the [JavaScript SDK](javascript-sdk.md) and [API reference](../counso-api-documentation/openapi-and-postman.md).
