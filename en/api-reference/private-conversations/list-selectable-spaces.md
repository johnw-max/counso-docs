# List selectable Spaces

Private session interface. Shows regular Spaces the user can choose for a conversation and indicates which ones are selected now.

```http
GET /api/w/{wId}/assistant/conversations/{cId}/selectable_spaces
```

Base URL: `https://app.counso.ai`

## Authentication

This operation requires a user OAuth access token in `Authorization: Bearer <token>`. A signed-in browser may use its Counso session cookie. A workspace API key does not supply user identity.

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `wId` | path | string | Yes |  |
| `cId` | path | string | Yes |  |

## Responses

| HTTP status | Description |
| --- | --- |
| 200 | Selectable Spaces for the conversation. |
| 401 | Unauthorized |
