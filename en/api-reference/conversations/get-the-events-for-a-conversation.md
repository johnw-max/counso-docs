# Get the events for a conversation

Fetches the event history attached to a conversation in workspace {wId}.

```http
GET /api/v1/w/{wId}/assistant/conversations/{cId}/events
```

Base URL: `https://app.counso.ai`

## Authentication

Send a workspace API key or a user OAuth access token in `Authorization: Bearer <token>`. The credential must belong to this Counso deployment and have access to the requested workspace and resources.

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `wId` | path | string | Yes | ID of the workspace |
| `cId` | path | string | Yes | ID of the conversation |
| `lastEventId` | query | string | No | ID of the last event |

## Responses

| HTTP status | Description |
| --- | --- |
| 200 | Events for the conversation, view the "Events" page from this documentation for more information. |
| 400 | Bad Request. Missing or invalid parameters. |
| 401 | Unauthorized. Invalid or missing authentication token. |
| 404 | Conversation not found. |
| 500 | Internal Server Error. |
