# Import Dropbox files into Counso

An administrator configures and runs an import script to bring selected Dropbox files into a Counso data source. Before the first run, choose the folders and file types, confirm the destination, and check that its members are allowed to see the files. The import covers the selection configured for that run; keep Dropbox as the original source.

Documents can include Dropbox Paper, Markdown, Word, and plain-text files. Imported records can include a file name, Dropbox identifier, folder path, format, and available creation or modification details. Ask the administrator to confirm the supported formats and metadata before importing, then check sample documents to make sure their content is readable.

Start with a small, representative selection. After the run, compare source and destination counts, review the import log, and open samples from different folders and formats. Check that text, paths, names, and dates are readable, and resolve failures before widening the scope. Dropbox remains the place to make and verify file changes.
