# Import Salesforce account summaries into Counso

An administrator can configure and run an import script to create searchable summaries of selected Salesforce accounts in a Counso data source. Before running it, choose the destination and confirm the accounts, date range, and fields to include.

A summary may combine account details—such as name, industry, revenue, employee count, phone, website, and billing or shipping address—with related contacts, account status, sales information, open opportunities, and recent support cases where available. Salesforce permissions affect which records and fields can be included. Check contact and support information carefully, and make sure the destination audience is allowed to see it.

Start with a small sample that includes accounts with different related records. Compare each summary with Salesforce, checking account identity, addresses, contacts, opportunity stages and amounts, and case details. Review the import output and compare counts with the selected accounts. Resolve missing relationships, unexpected values, duplicates, and failed records before importing more. Make and verify CRM changes in Salesforce.
