# Import Linear issues into Counso

An administrator can configure and run an import script to bring selected Linear issues into a Counso data source as searchable documents. Before running it, choose the destination and confirm the teams, filters, fields, and date range for this import.

An imported issue may include its identifier, title, description, URL, team, project, state, creator, assignee, subscribers, priority, estimate, cycle, labels, and relevant dates. Comments and available activity history add context. After import, check which relationships and attachments are included. The connected Linear account’s permissions affect which data is available.

For a first run, select a few issues from different teams and states, including one with comments or planning details. Compare the imported documents with Linear and check identifiers, descriptions, assignments, project or cycle, dates, comments, and history. Review the import output and compare counts with the selected issues. Resolve duplicates, missing relationships, or failed records before importing more. Make and verify issue changes in Linear.
