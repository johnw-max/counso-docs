# Import Guru cards into Counso

An administrator can configure and run an import script to bring selected Guru cards into a Counso data source. Before running it, choose the collections or cards to include, select the destination, and confirm that its members may view the material.

A card can include its title and body, plus ownership and verification details such as the owner, verifier, collection, boards, verification state, interval, and dates. A source link or card identifier may also be retained. These details help readers see where information came from and whether a card has been reviewed. Check the imported cards to confirm which fields are available.

Start with a few cards from different collections, including one with verification information. After the run, compare each sample with Guru: check the title, body, collection, board, owner, verification state, and source reference. Review counts and errors, and investigate missing or duplicated cards before importing more. Guru remains the place to update and verify cards.
