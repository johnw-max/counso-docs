# Import HubSpot company summaries into Counso

An administrator can configure and run an import script to place selected HubSpot company summaries in a Counso data source. Before running it, choose the destination and confirm which companies and date range are included. The administrator can adjust the selection to suit the records needed.

A company summary can combine basic company details with related contacts, deals, and notes available to the connected HubSpot account. Details can include contact names and email addresses, deal stage and amount, dates, and note text. Some related information may be unavailable because of account permissions or the fields selected for import. Check contact information and confirm that the destination audience is allowed to see it.

Start with a small group of companies that cover different record types, such as one with several contacts, an open deal, and notes. Compare each Counso document with HubSpot, checking related records, labels, amounts, and dates. Review the import output and compare counts with the selected companies. Resolve missing associations or duplicates before importing more. HubSpot remains the place to update CRM records.
