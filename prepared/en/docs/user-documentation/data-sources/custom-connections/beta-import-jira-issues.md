# Import Jira issues into Counso

An administrator can configure and run an import script to bring selected Jira issues into a Counso data source. Before running it, choose the destination and confirm the projects, filters, fields, and date range for this import.

An issue document can include its key and summary, description, type, status, priority, assignee, reporter, project, and available dates. It may also include resolution, labels, components, sprint or epic details, time-tracking values, links, subtasks, comments, and attachment references. After import, check whether attachments open as files or appear only as references. The connected Jira account’s permissions affect which fields are available.

Start with a small set of issues from different projects and statuses, and make sure the destination audience may see their content and comments. Compare the imported documents with Jira, checking descriptions, people, dates, relationships, and attachments. Review the import output and compare counts with the selected issues. Resolve missing or duplicated records before importing more. Make and verify issue changes in Jira.
