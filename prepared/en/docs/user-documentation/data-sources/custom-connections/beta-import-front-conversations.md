# Import Front conversations into Counso

An administrator configures and runs an import script to bring selected Front conversations into a Counso data source. Before running it, choose the destination and confirm which inboxes and date range are included. The administrator can adjust the selection for the work at hand.

A conversation document can bring together its subject, status, assignee, timestamps, messages, and tags. Messages can include sender and time information; check access carefully when internal notes are present. Each document has a size limit, so review long conversations after import for missing or cut-off messages. Check the imported conversation to see whether attachments appear as content, links, or are not included.

Start with a small set of conversations from different inboxes and statuses, and make sure the destination audience may see them. Compare the imported documents with Front, checking message order, senders, timestamps, tags, and any missing or cut-off content. Review the run log and address failures before importing more. Front remains the place to make and verify conversation changes.
