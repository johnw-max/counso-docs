# Use Counso in Zendesk

The Counso application in Zendesk lets support staff work with Agents alongside a ticket. It uses the conversation as context, helping the team prepare a reply or investigate a customer question.

## Set up the application

A Zendesk administrator installs the Counso application supplied for the organization and connects the intended Counso workspace. Staff using the application need the corresponding Counso access; check the account email requirements during setup.

The administrator can choose the default Agents shown to the team and restrict application access to the appropriate Zendesk groups or roles. Review the customer-information setting before sharing ticket context: hiding customer metadata is different from removing information already written in the conversation.

## Work on a ticket

Open a ticket, choose an Agent, and describe what you need. Check the answer against the actual ticket and relevant policies before using it in a customer response.

This application is an Agent interface within Zendesk. Synchronizing Zendesk records into a Counso knowledge source is a separate connection with its own access and synchronization settings.
