# Use Agents from your browser

When your organization provides the Counso browser extension, it opens a side panel for working with Agents without leaving the current page. Install it only from the distribution source provided by your organization, sign in to the intended workspace, and pin the extension if you want quick access. Browser permissions are used for requested page context; page content is not read automatically.

## Ask a question from the side panel

The extension provides a conversation composer and conversation history. Depending on the version enabled for the workspace, you may be able to mention members, format text, attach Agents, Tools, Skills, or Knowledge, and resume recent conversations. Unsent drafts may be saved when you close and reopen the panel.

## Share page context

You can attach selected text from the current tab or request a screenshot in the composer. Keyboard shortcuts may be configured in the browser's extension settings. An Agent can also request permission to read a page when the request needs it; review the browser permission prompt before allowing access. Workspace administrators may be able to disable browser-page tools.

Agents may request access to more than one open tab for a question that spans several pages. A page showing a PDF or other file may offer to attach that file to the conversation. Review the attachment and workspace audience before sharing it.

## Page interaction and connected tools

If enabled, an Agent may interact with the current page through clicks and keystrokes, for example to navigate or fill a form. Check the page and proposed action before allowing it to continue. Where a dedicated connected Tool is available for a service, the Agent may use that Tool instead of interacting with its webpage.

## Known limitations

Some web applications render content on a canvas rather than as normal page text. If the extension cannot capture that text, attach a screenshot or export the page to PDF where available. Browser, workspace, and extension settings can change which features are available. If past conversations do not open, update the extension using the browser's extension-management page and try again.
