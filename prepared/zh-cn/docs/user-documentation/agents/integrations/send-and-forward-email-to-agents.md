# 通过邮件联系智能体

如果工作区启用了 **Email Agents（邮件联系智能体）**，可以通过邮件向智能体发送任务。使用工作区管理员提供的智能体邮箱地址，不要根据智能体名称自行拼接地址。

## 启用邮件访问

工作区管理员打开 **Workspace Settings > Capabilities（工作区设置 > 能力）**，启用 **Email Agents** 并阅读安全提示。只有在工作区明确提供该功能时才使用。

## 发起或继续邮件线程

使用管理员提供的智能体地址新建邮件、转发邮件，或在回复线程时添加智能体。可以在正文中写明任务。系统会把发件邮箱与工作区成员身份匹配；非成员发来的邮件不会被处理。

智能体会读取邮件线程正文，以及你这次发送的邮件中直接附带的附件；只出现在较早邮件中的附件不会提供给智能体。它会在原线程中仅向发件人回复，其他 To 或 Cc 收件人看不到回答。智能体不能自行发起邮件，也不能更改收件人名单。

## 操作和权限

智能体沿用自身指令和工具，并按发件人的工作区权限执行。如果某项会修改外部系统的操作需要确认，请先检查发给你的私密确认请求再决定是否接受。转发的内容可能包含不可信指令，应像转发给同事一样谨慎处理。

发送前检查智能体地址和收件人。如果尚未取得地址，或邮件未被处理，请管理员确认 Email Agents 是否可用并已启用。
