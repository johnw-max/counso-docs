# 通过 Zapier 运行智能体

Zap 可以把其他应用中的事件传给 Counso 智能体，再将回答用于下一步。例如，表格新增一行后，让智能体整理一段客户摘要。

## 设置 Zap

使用工作区管理员提供的 Counso 集成。你需要有权连接目标工作区，并使用已共享的智能体。

1. 新建 Zap，选择启动流程的事件。
2. 添加集成中的智能体动作，连接需要使用的 Counso 工作区。
3. 选择智能体，将来源字段整理成清楚的请求，包含具体任务和必要背景。
4. 设置时区及自动会话使用的名称。
5. 用一条记录测试，检查回答后再将结果接到后续动作。

启用前检查触发频率和结果去向，避免测试流程与正式流程重复处理同一条记录。涉及重要记录修改或对客消息时，应先复核智能体的回答。
