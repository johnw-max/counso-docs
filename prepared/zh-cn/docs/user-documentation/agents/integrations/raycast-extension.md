# 通过 Raycast 使用 Counso

Raycast 扩展提供了通过键盘打开 Counso 智能体、发起请求的方式，无需先进入 Counso 网页。

## 登录

安装为 Counso 工作区提供的扩展，打开登录命令，核对工作区地址并使用 Counso 账号完成授权。选择需要使用的工作区，再选择智能体。

## 发起请求

打开智能体命令，选择智能体并输入任务。如果要附带其他应用中选中的文字，发送前检查选区内容。把回答与原始材料核对后，再复制回正在处理的工作中。

## 设置快捷入口

在 Raycast 的扩展设置中，为智能体命令分配快捷键或别名，避免与常用应用的快捷键冲突。如果显示了错误的工作区，先检查扩展的登录账号和工作区选择，再开始新会话。
