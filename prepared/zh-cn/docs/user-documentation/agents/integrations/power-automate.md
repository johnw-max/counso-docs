# 在 Power Automate 中使用 Counso

Counso 自定义连接器可以在 Power Automate 流程中请求智能体回答或上传文档。管理员提供适用于目标工作区的解决方案安装包和连接配置。

## 安装与连接

导入解决方案的人需要有权在目标 Power Platform 环境中创建资源。自定义连接器的许可证要求由 Power Platform 管理员确认。

1. 打开目标环境，在 **Solutions** 中导入提供的解决方案。
2. 打开其中的自定义连接器，按安装包随附的认证说明创建连接。
3. 使用一条简短消息或一份小文档测试动作。
4. 在 Counso 中检查实际生成的会话或文档，再把连接器共享给需要使用的人。

## 加入流程

选择连接器动作及工作区连接，映射必要字段，完整测试后再启用。导入更新版解决方案后，应重新检查原有连接和流程；安装成功并不代表业务结果已经正确生成。
