# 通过 Make 运行智能体

在 Make 场景中，可以把其他应用的信息交给 Counso 智能体处理，再将回答传给后续模块，例如生成摘要草稿或分类字段。

## 创建场景

使用为工作区提供的 Counso 模块和账号连接，选择该账号有权使用的共享智能体。

1. 新建场景，选择触发事件或运行时间。
2. 添加 Counso 智能体模块，选择正确的工作区连接。
3. 选择智能体，将传入字段映射到消息中。
4. 填写相关时区及便于辨认的会话名称。
5. 用一条样例记录运行一次。打开模块输出，确认回答正确后，再把正文传给其他模块。

开启场景前检查运行时间、错误处理和重试方式。智能体成功回答，不代表后续模块已经保存记录或发送消息；这些动作需要分别检查。
