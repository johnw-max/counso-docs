# 在 n8n 中使用 Counso

n8n 工作流可以将消息交给 Counso 智能体处理，也可以上传文档供后续使用。先取得适用于当前 Counso 部署的节点包和连接配置。

## 配置工作流

由 n8n 管理员按当前环境支持的方式安装节点包，为目标 Counso 工作区配置凭据，并限制凭据可用于哪些工作流。

1. 添加触发器，例如定时运行或来源新增记录。
2. 添加 Counso 节点，选择智能体请求或文档上传动作。
3. 发送智能体请求时，选择共享智能体，并填写消息及相关背景。
4. 上传文档时，选择目标位置，映射节点要求的文档标识、标题和正文。
5. 单次执行测试，同时检查 n8n 输出和 Counso 中的实际结果。

启用前核对节点连接的目标环境。检查重试方式和记录标识，避免临时失败后产生重复会话或文档。
