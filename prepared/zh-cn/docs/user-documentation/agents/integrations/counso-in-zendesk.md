# 在 Zendesk 中使用 Counso

Zendesk 中的 Counso 应用让客服人员在处理工单时使用智能体。应用以当前对话为背景，帮助准备回复或分析客户问题。

## 设置应用

由 Zendesk 管理员安装组织提供的 Counso 应用，并连接目标 Counso 工作区。使用应用的人员还需要相应的 Counso 访问权限，设置时核对账号邮箱的要求。

管理员可以指定团队默认可选的智能体，并按 Zendesk 用户组或角色限制应用访问。共享工单背景前检查客户信息设置；隐藏客户元数据并不会自动删除对话正文中已经包含的个人信息。

## 处理工单

打开工单，选择智能体并说明任务。将回答与实际工单、相关政策核对后，再用于客户回复。

这个应用是在 Zendesk 内使用智能体的入口。把 Zendesk 记录同步到 Counso 知识库，是另一项独立的数据连接，需要单独设置访问范围和同步。
