# 在浏览器中使用智能体

如果组织提供 Counso 浏览器扩展，你可以在不离开当前网页的情况下通过侧边栏使用智能体。仅从组织提供的分发渠道安装，登录预期工作区；如需快速打开，可将扩展固定到浏览器工具栏。浏览器权限用于响应明确请求的页面内容，不会自动读取网页。

## 在侧边栏提问

扩展提供对话输入框和历史记录。根据工作区启用的版本，你可能还可以提及成员、设置文字格式、为对话添加智能体、工具、Skills 或 Knowledge，并继续最近的对话。关闭侧边栏后，未发送的草稿可能会保存，并在再次打开时恢复。

## 分享页面内容

可以在输入框中附加当前标签页的选中文字，或请求生成页面截图。浏览器扩展设置中可能允许配置键盘快捷键。如果请求需要读取网页，智能体也可能先申请权限；请先检查浏览器的授权提示，再决定是否允许。工作区管理员可能可以关闭浏览器页面工具。

如果问题涉及多个页面，智能体可能会申请访问多个已打开的标签页。当前页面显示 PDF 或其他文件时，扩展可能会提示将文件附加到对话中。分享前检查附件内容和对话受众。

## 页面操作和已连接工具

如果工作区启用了相关能力，智能体可能通过点击和键盘操作当前页面，例如打开页面或填写表单。继续前检查页面状态和拟执行的动作。如果某项服务已经连接了专用工具，智能体可能优先使用该工具，而不是操作服务网页。

## 已知限制

某些网页应用会用 Canvas 绘制内容，而非普通网页文字。若扩展无法读取其中的文字，可附加截图；如可行，也可以先将页面导出为 PDF。浏览器、工作区和扩展设置会影响实际功能。如果无法打开历史对话，可在浏览器扩展管理页更新扩展后重试。
