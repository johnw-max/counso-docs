# 在 Google Sheets 中使用 Counso

表格插件可以将选中的单元格区域发送给 Counso 智能体，并把结果写入指定列，适合逐行检查的摘要、分类等任务。

## 连接插件

安装为工作区提供的 Counso 插件，从表格的 **Extensions** 菜单打开设置面板，使用管理员提供的凭据和连接选项接入目标工作区。

## 处理单元格区域

1. 先选择一小段输入数据。
2. 打开插件的智能体面板，选择适合任务的共享智能体。
3. 核对输入区域，指定不会覆盖重要内容的输出列。
4. 添加明确的处理要求并运行。
5. 将返回值与原始行逐项比较，确认后再扩大处理范围。

请求应简短、聚焦，第一次不要处理数千行。复用表格时重新核对输出列。智能体生成的回答与表格公式计算、普通编辑是不同操作，需要分别检查。
