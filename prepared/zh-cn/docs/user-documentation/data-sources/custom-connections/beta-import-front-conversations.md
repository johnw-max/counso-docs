# 将 Front 会话导入 Counso

管理员配置并运行导入脚本，将选定的 Front 会话放入 Counso 资料源。运行前，先选好目标，并确认要纳入哪些收件箱和日期范围；管理员可以按本次工作调整筛选范围。

一份会话文档可以汇集主题、状态、负责人、时间、消息和标签。消息可能带有发送者和时间；如果包含内部备注，请仔细确认访问范围。单份文档有大小限制，导入后要检查较长会话是否有消息缺失或截断。查看导入结果，确认附件是正文、链接，还是未纳入。

先从不同收件箱和状态中选少量会话试跑，并确认目标成员有权查看这些会话。将导入文档与 Front 对照，核对消息顺序、发送者、时间、标签，以及是否有内容缺失或截断。查看运行日志，处理失败项后再扩大范围。会话的修改和核验仍以 Front 为准。
