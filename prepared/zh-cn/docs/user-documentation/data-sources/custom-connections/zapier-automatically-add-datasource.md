# 通过 Zapier 上传文档

Zap 可以将来源事件整理成 Counso 文档。例如，把新增的客服工单转换为文字，存入智能体使用的资料文件夹。

## 准备目标位置

选择接收资料的 Counso Space 和文件夹，导入客户记录前核对谁有权阅读。使用为工作区提供的 Counso Zapier 集成和凭据。

## 创建 Zap

1. 选择来源应用和触发事件，先测试来源记录。
2. 添加集成中的文档上传动作，选择 Counso 连接。
3. 选择目标文件夹，映射稳定的文档标识、清楚的标题和智能体需要的正文。
4. 用一条记录测试，在 Counso 中打开生成的文档。
5. 核对内容和存放位置后，再启用 Zap。

依赖重复运行前，检查上传动作如何处理已经存在的标识。新增记录触发上传，不会自然涵盖来源后续的修改和删除；这些变化需要另有对应的流程支持。
