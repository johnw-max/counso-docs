# 将 Linear Issue 导入 Counso

管理员可以配置并运行导入脚本，将选定的 Linear Issue 导入 Counso 资料源，生成可检索文档。运行前，先选好目标，并确认本次导入涉及的团队、筛选条件、字段和日期范围。

导入的 Issue 可能包含标识、标题、描述、链接、团队、项目、状态、创建者、经办人、关注者、优先级、估算、周期、标签和相关日期。评论及活动历史也可提供背景。导入后请检查哪些关联关系和附件已纳入；连接 Linear 账号的权限会影响可读取的数据。

首次运行时，从不同团队和状态中选几条 Issue，其中包括带评论或规划信息的记录。导入后与 Linear 对照，核实标识、描述、经办人、项目或周期、日期、评论和历史。查看导入结果，并按选定的 Issue 核对数量。解决重复记录、关联缺失或失败项后再扩大范围。Issue 的修改和核验仍在 Linear 中进行。
