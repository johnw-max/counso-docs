# 将 Dropbox 文件导入 Counso

管理员配置并运行导入脚本，将选定的 Dropbox 文件放入 Counso 资料源。首次运行前，先确定要导入的文件夹和格式、选好目标，并确认目标成员有权查看这些文件。每次导入仅覆盖当次配置的范围；文件的修改和确认仍在 Dropbox 中进行。

可导入的文档类型包括 Dropbox Paper、Markdown、Word 和纯文本。导入记录可能包含文件名、Dropbox 标识、文件夹路径、格式以及可读取的创建或修改信息。导入前请管理员确认当前支持的格式和元数据；完成后抽查几份文件，确认正文可读。

先用少量、有代表性的文件试跑。完成后，对比来源与目标数量，查看运行日志，并抽查不同目录和格式的文件。确认正文、路径、名称和日期可读，处理失败项后再扩大范围。文件的后续修改和核验仍以 Dropbox 原件为准。
