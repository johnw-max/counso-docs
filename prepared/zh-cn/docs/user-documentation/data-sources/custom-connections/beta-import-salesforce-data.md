# 将 Salesforce 客户摘要导入 Counso

管理员可以配置并运行导入脚本，将选定的 Salesforce 客户记录整理为 Counso 资料源中的可检索摘要。运行前，先选好目标，并确认要纳入的客户、日期范围和字段。

摘要可能把客户基本信息（如名称、行业、收入、员工数、电话、网站和账单或送货地址）与联系人、客户状态、销售资料、未结束的商机及近期支持案例放在一起。Salesforce 权限会影响可纳入的记录和字段。请仔细检查联系人和支持信息，并确认目标成员有权查看。

先选少量关联信息不同的客户记录试跑。将摘要与 Salesforce 对照，检查客户身份、地址、联系人、商机阶段和金额，以及案例信息。查看导入结果，并按选定的客户核对数量。解决关联缺失、异常值、重复记录和失败项后再扩大范围。CRM 的修改和核验仍在 Salesforce 中进行。
