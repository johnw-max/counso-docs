# 将 Jira Issue 导入 Counso

管理员可以配置并运行导入脚本，将选定的 Jira Issue 放入 Counso 资料源。运行前，先选好目标，并确认本次导入涉及的项目、筛选条件、字段和日期范围。

一份 Issue 文档可以包含键值和摘要、描述、类型、状态、优先级、经办人、报告人、项目及可读取的日期；也可能包含解决状态、标签、组件、冲刺或史诗信息、工时、关联项、子任务、评论和附件引用。导入后请检查附件是文件还是仅有引用。连接 Jira 账号的权限会影响可读取的字段。

先从不同项目和状态中选取少量 Issue，并确认目标成员有权查看其内容和评论。将导入文档与 Jira 对照，核实描述、人员、日期、评论、关联关系和附件。查看导入结果，按选定的 Issue 核对数量。发现缺失或重复时，先查明原因再继续导入。Issue 的修改和核验仍在 Jira 中进行。
