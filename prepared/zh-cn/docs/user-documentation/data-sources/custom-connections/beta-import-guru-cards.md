# 将 Guru 卡片导入 Counso

管理员可以配置并运行导入脚本，将选定的 Guru 卡片放入 Counso 资料源。运行前，先选好要纳入的集合或卡片、目标资料源，并确认目标成员有权查看这些内容。

一张卡片可包含标题和正文，以及归属和验证信息，例如负责人、验证人、集合、看板、验证状态、验证间隔和日期。记录也可能保留卡片标识或来源链接，帮助读者了解内容出处及复核情况。导入后请抽查卡片，确认实际纳入了哪些字段。

先挑选不同集合中的少量卡片试跑，其中包含一张带验证信息的卡片。完成后逐条与 Guru 对照，核对标题、正文、集合、看板、负责人、验证状态和来源引用。查看导入数量与错误，排查缺失或重复后再扩大范围。卡片的修改和验证仍以 Guru 为准。
