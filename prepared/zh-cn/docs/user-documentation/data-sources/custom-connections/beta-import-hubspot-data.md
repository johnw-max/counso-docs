# 将 HubSpot 公司摘要导入 Counso

管理员可以配置并运行导入脚本，将选定的 HubSpot 公司摘要放入 Counso 资料源。运行前，先选好目标，并确认本次纳入的公司和日期范围；管理员可以按所需记录调整筛选条件。

公司摘要可以把基本公司信息与 HubSpot 账号可读取的联系人、交易和备注放在一起。内容可能包括联系人姓名和邮箱、交易阶段和金额、日期及备注文本。受账号权限或所选字段影响，部分关联信息可能无法导入。请检查联系人等信息，并确认目标成员有权查看。

先选少量、关联类型不同的公司试跑，例如包含多位联系人、进行中交易和备注的记录。将 Counso 文档与 HubSpot 对照，核实关联记录、标签、金额和日期。查看导入结果，并按选定的公司范围核对数量。解决关联缺失或重复问题后再扩大范围。CRM 记录的修改仍在 HubSpot 中进行。
