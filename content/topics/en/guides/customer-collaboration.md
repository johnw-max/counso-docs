# Collaborate with a customer safely

## Before you begin

Agree on audience, sources, and deliverable. Use an anonymised example for training; keep real records in the intended restricted Space.

## Steps

1. Create/select a restricted Space and confirm members.
2. Give the Agent only required sources and review editors/unpublished access.
3. Ask a focused comparison question and request evidence, owner, status, and next action.
4. Review before external sharing, remove temporary access when done, and record the final decision.

## Result

### Worked example: customer material progress

Input: three anonymised files—requirements-v3, training-notes-week-2, and open-questions. Put them in a restricted project Space and give the Agent only that Space. Expected output: each requirement mapped to evidence, owner, status (done, in progress, or blocked), and next action; unsupported items are listed separately.

Reusable prompt:

```text
Using only the three project files in this Space, map each requirement to evidence.
Return requirement | evidence file/section | owner | status | next action.
Use "no evidence" when unsupported; do not mark an item done from wording alone.

```

The customer sees a focused deliverable while source access and internal notes remain limited.

## Common questions

**Should every customer use the main Space?** No. Use a dedicated restricted Space.

**Can the Agent declare a project complete?** It organises evidence and gaps; the responsible person approves.

**What if a source is missing?** Ask an administrator to review access; do not copy restricted data into public chat.
