# Troubleshoot missing information

When an Agent cannot answer a question, first separate three possibilities: the source is absent, the request lacks context, or the Agent cannot access the relevant material.

## Narrow the problem

1. Name the document, record, topic, and period you expected the Agent to use.
2. Ask the Agent what information it could find and what is missing.
3. Check that the source is in the workspace area and access scope intended for this task.
4. Add the missing context or source only if you are authorised to do so.
5. Ask the question again with a clear expected result.

If two sources conflict, keep both visible and ask for the differences. If the source is too old, locate the current revision. If the source is available to you but not to the Agent, ask an administrator to review the Agent's data and access settings. Do not copy restricted content into a conversation as a workaround.

If the information still cannot be found, state the gap in the result and assign a human follow-up. Do not fill a missing amount, date, identity, or approval from guesswork. After the retry, [review the result](../getting-started/review-results.md#review-results-before-relying-on-them) against the source.
