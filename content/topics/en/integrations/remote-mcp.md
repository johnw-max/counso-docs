# Add a remote MCP server

## Before you add a remote server

A workspace administrator should identify the server owner, server URL, authentication method, allowed tools, data destinations, and removal owner. Use a server that the organisation has approved; do not paste a secret into an Agent instruction or a public conversation.

## Add the server

1. Open the tool management controls from the administrator area.
2. Add the remote server using its approved URL and authentication method.
3. Complete the provider’s consent flow when required.
4. Select only the tools and Spaces that the Agent needs.
5. Run one read-only request against a non-sensitive resource and inspect the returned source and identity.

The server appearing in a tool list does not prove that a tool call was accepted by the remote service. For a write-capable tool, obtain confirmation and check the remote receipt and object read-back.

### Select authentication

- **Automatic:** enter the provider’s MCP URL so the system can discover configuration and start the available OAuth sign-in.
- **Bearer token:** enter the token issued by the provider. Calls use the account behind that token, so check its sharing scope.
- **Static OAuth:** register an application with the provider, then enter its Client ID, Client Secret, authorization URL, token URL, and required scopes. Register the callback generated by the Counso setup page in that same provider application.

## OAuth and allowlists

The remote service may require a registered client, callback, domain allowlist, or administrator consent. These values are provider-specific. Use the callback, domain, and allowlist values shown by the current setup form. Do not reuse values from another environment. If the provider changes its URL or scopes, reconnect and repeat the read-only check.

## Common issues

- The server saves but its tools are absent: check authentication, allowlists, and which Space exposes the tool.
- Consent loops: compare the registered callback and client configuration with the provider’s current settings.
- A tool returns an access error: check the remote account and the selected resource, not only the Counso Agent settings.
- A tool changes an external record: check the remote receipt and stable ID before reporting success.

For credential ownership, read [Personal and shared access](./personal-and-shared.md#personal-and-shared-credentials).
