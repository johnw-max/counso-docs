# Review results before relying on them

Review an Agent's result before you share it, publish it, or use it to make a decision. A confident answer can still be incomplete or wrong.

## A practical review

1. Read the answer once for the requested outcome.
2. Compare important claims with the source, including dates, numbers, names, and conditions.
3. Look for missing material, assumptions, and unresolved conflicts.
4. Check that the format and audience are right.
5. Decide what needs correction, confirmation, or human follow-up.

If the answer proposes an external action, separate the proposal from the completed result. Confirm what you authorised, then check the destination system for the actual status. Keep the source and result together when the work needs an audit trail.

If the result is unclear, ask a narrower question or request the missing source. If it remains uncertain, say what is unknown instead of filling the gap. For source-specific checks, read [Check sources behind an answer](../knowledge/check-citations.md#check-sources-behind-an-answer). For missing material, read [Troubleshoot missing information](../knowledge/troubleshoot-missing-information.md#troubleshoot-missing-information).
