# Manage conversations and identify an Agent

Conversation controls are available from the conversation itself. Keep the conversation open while you change its title, share it, or copy an Agent ID; the exact control is attached to the current conversation or Agent entry.

## Rename or delete a conversation

1. Open the conversation you want to change.
2. Choose the rename action in the conversation controls and enter a new title. Some layouts show a pencil beside the title.
3. Choose the delete action or bin icon in the conversation controls and complete the confirmation shown by the interface.

Choose a title that tells the next reader what the thread contains. Before deleting, save any result the team still needs because the delete action removes the conversation from the workspace conversation list.

## Share a conversation

1. Open the conversation.
2. Select the conversation’s **Share** control.
3. Invite the colleagues who should join the conversation. They can then work in the thread with you and the Agents.

Sharing makes the conversation available to those colleagues; it does not change their access to the underlying sources or workspace resources. If a colleague cannot use a source, check that source permission separately.

## Use another language

Write to the Agent in the language you want to use. Agents can understand and answer in many languages, and they usually follow the language of the request. You can also put a language rule in the Agent instructions, such as always replying in a selected language, when a workflow needs consistent output. No separate conversation language switch is required for the basic case.

## Copy an Agent ID

1. Open the list of Agents and select the **...** menu for the Agent.
2. Choose **More info**. A details panel opens.
3. Open the **...** menu in that panel and choose the control that copies the Agent ID.
4. Paste the ID into the configuration that requested it and keep it associated with the correct Agent.

The ID identifies the Agent configuration. It does not grant access to the Agent or to its sources, so the person or integration using it still needs the required permissions.

## Common questions

### Where is the rename control?

Open the conversation and look beside its title or in the conversation menu for the rename control. It applies to the current conversation.

### Can sharing bypass source permissions?

No. Sharing lets colleagues join the conversation, while source and workspace permissions continue to apply.

### Will an Agent always reply in the language I used?

Agents generally mirror the conversation language. For a fixed output language, add that requirement to the Agent instructions and test it with a representative request.
