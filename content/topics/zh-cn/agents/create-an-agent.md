# 创建智能体

当工作区授予你相应权限时，你可以创建智能体。开始前先明确任务、使用者，以及完成任务所需的最小数据访问范围。

## 开始配置

1. 进入 **Work**，打开 **Agents（智能体）**。
2. 打开 **Create（创建）**。
3. 选择起点：**Agent from scratch（从空白创建）**、**Agent from template（从模板创建）** 或 **Agent from YAML**。
4. 如果选择 **Agent from scratch**，先查看编辑器，再输入任何私密信息。
5. 填写清楚的名称、说明和指令。只有明确智能体可以使用哪些 Space 或 Pod 后，再配置访问范围。
6. 配置完成后选择 **Save（保存）**。

保存后，检查智能体列表，并重新打开配置，确认名称、说明、指令和访问设置符合预期。如果找不到智能体，请让工作区管理员检查发布状态和你的角色。

## 先做小版本

为智能体设定一个清晰职责，并要求它返回容易复核的结果。只在确有需要时添加能力或知识；条件允许时先从只读任务开始，并说明遇到信息缺失或冲突时应该怎么处理。

保存配置不会自动让所有外部动作安全或可用。分享智能体前，请检查数据和访问设置，并使用非敏感材料检查预期结果。指令设计请阅读[编写智能体指令](./write-instructions.md#编写智能体指令)，访问范围请阅读[管理智能体的数据与访问](./data-and-access.md#管理智能体的数据与访问)。
