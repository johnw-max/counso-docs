# 管理对话并查找 Agent ID

对话控制项位于当前对话中。修改标题、分享对话或复制 Agent ID 时保持对话打开；具体控制项属于当前对话或 Agent 条目。

## 重命名或删除对话

1. 打开要修改的对话。
2. 在对话的操作控件中选择重命名，并输入新标题；部分界面会在标题旁显示铅笔图标。
3. 在对话操作中选择删除或垃圾桶图标，并完成界面显示的确认。

标题应让下一位读者知道线程内容。删除前保存团队仍需要的结果，因为删除操作会将该对话从工作区对话列表移除。

## 分享对话

1. 打开对话。
2. 选择对话的 **Share** 控件。
3. 邀请需要加入的同事。他们随后可以和你及 Agent 一起在该线程中工作。

分享会让受邀同事看到并加入对话，但不会改变其访问底层来源或工作区资源的权限。如果同事无法使用某个来源，请单独检查该来源权限。

## 使用其他语言

直接用希望使用的语言向 Agent 提问。Agent 能理解并用多种语言回答，通常会跟随请求所用的语言。如果流程需要固定输出语言，也可以在 Agent 说明中加入“始终使用某种语言回复”之类的规则。基本用法不需要额外的对话语言切换。

## 复制 Agent ID

1. 打开 Agent 列表，选择目标 Agent 的 **...** 菜单。
2. 选择 **More info**，打开详情面板。
3. 在详情面板中再次打开 **...** 菜单，选择复制 Agent ID 的控件。
4. 将 ID 粘贴到请求它的配置中，并确认对应的是正确 Agent。

ID 只标识 Agent 配置，不会授予 Agent 或来源访问权。使用它的人员或集成仍需要相应权限。

## 常见问题

### 重命名控件在哪里？

先打开对话，在标题旁或对话操作菜单中查找重命名控件。它只作用于当前对话。

### 分享会绕过来源权限吗？

不会。分享允许同事加入对话，来源和工作区权限仍然有效。

### Agent 会始终使用我提问的语言回答吗？

Agent 通常会跟随对话语言。若要固定输出语言，请把要求写进 Agent 说明，并用代表性请求测试。
