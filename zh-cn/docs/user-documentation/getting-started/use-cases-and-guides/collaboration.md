# 在对话中协作

需要同事提供意见时，可以在同一条对话中与智能体和同事协作。

## 提及同事

1. 在消息输入框中输入 **@**，打开提及选择器。
2. 搜索并选择同事。
3. 发送消息，并清楚写明需要对方做什么。

提及同事会通知对方并将其带入对话。如果智能体提出邀请某位同事，请先查看邀请提示，再决定是否添加。

## 分享对话

1. 打开要分享的对话。
2. 点击右上角的 **Copy the link**。
3. 将链接发给需要加入的同事。

加入对话的人可以查看历史记录；只有同时有权使用该对话所用智能体的人，才能与这些智能体协作。分享前先确认对话受众，尤其是使用受限 Space 中智能体的对话。未分享的对话仅自己可见。

## 让智能体请求人工协助

创建或编辑智能体时，说明哪些情况需要人工帮助，以及应该提及谁。例如：“如果无法有把握地回答，请在账单问题中提及 @Aisha，并说明还缺少哪些信息。”

智能体应说明需要人工介入的原因；最终决定仍由负责人作出。

## 跟进对话

侧边栏用蓝点标记未读对话，用黄色标记提示等待你处理的对话。打开对话后会自动标为已读。加入需要跟进的对话，不再需要时可以退出。个人资料中的通知设置决定未读消息提醒和邮件摘要。
