# 数据分析场景

智能体可以帮助分析人员澄清问题、查找数据结构说明、起草查询或解释结果。只有工作区提供了权限合适的数据连接和工具时，才能查询实时数据。

## 准备查询

说明业务问题、日期范围、主体、指标定义、筛选条件和期望的统计粒度，并提供相关数据结构或字典。运行查询前，让智能体先解释关联关系和假设。

## 检查结果

若工作区提供只读查询工具，可先运行小样本或汇总查询。检查生成的查询、筛选条件、关联键、空值处理和时区。分享结论前，应与已知报表或源系统中的重要总数进行核对。

## 向非技术受众解释分析

可以让智能体用通俗语言说明指标、期间、排除项和限制。将查询或来源引用与结果一起保留，方便其他分析人员复现。

## 请求示例

```text
请依据附带的数据结构，起草一条只读查询，按实体统计上一完整季度的月度发票总额。说明日期字段、状态、币种和重复记录方面的假设。我复核查询前不要运行或修改数据。
```

智能体的解释不能验证业务指标定义。作出决策前，数据负责人或分析师必须确认指标和查询。
