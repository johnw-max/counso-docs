# 市场与内容场景

可以用智能体根据获准资料起草内容、面向指定受众润色文字，或将内容改写为不同渠道的版本。请提供团队允许复用的品牌指引和范例。

## 起草和润色内容

提供写作简报、受众、目的、要点和篇幅。要求智能体保留已核实事实、标注待复核说法，并采用指定语气。润色时还要说明能否重组内容，还是只改清晰度和语法。

## 按渠道改写

可以要求智能体将内容改写为产品更新、邮件或社交媒体文案等特定形式。只有在限制已确认时，才提供字符数或必需链接。发布前检查人名、日期、产品表述、无障碍要求和法律措辞。

## 翻译与本地化

提供原文、目标语言和地区、受众，以及需要统一的专有词。要求智能体标出不确定的习语或技术术语。译文通顺也仍需熟悉当地市场和主题的人复核。

## 改编长内容

报告、研讨会转写稿或访谈可以先归纳成简报，再改写为多个版本。保留原文链接，并逐份复核衍生内容；摘要可能省略对外表述中重要的限定条件。

## 请求示例

```text
请根据以下获准的版本说明，起草一段简短的客户更新。语气清楚自然，准确保留日期和功能名称，不增加路线图承诺，并列出需要产品或法务审核的说法。
```

音频或媒体生成只有在工作区提供相应能力时才可用。不要承诺智能体可以直接向内容渠道发布。
