# 招聘与员工支持场景

人力团队可以用智能体查找已批准的政策、起草招聘材料、整理面试笔记并准备管理沟通。候选人和员工记录必须放在获准的访问范围内。

## 员工政策问题

以当前已批准的政策作为来源。要求智能体引用准确章节和生效日期，并将例外或含糊情况交由人力团队处理。最终答复应由政策负责人确认后再作为政策意见使用。

## 招聘材料

智能体可以根据获批的岗位说明起草职位描述、面试计划或候选人沟通文案。要求保留岗位要求、删除无来源的说法，并使用包容一致的措辞。招聘人员应在使用前复核每份材料。

## 面试笔记和反馈

只有在允许处理这些资料时，才能提供面试笔记。要求智能体按岗位相关标准整理证据，保留面试官的原始观察，并标出证据缺口。不要让它作出录用决定，也不要推断受保护特征。

## 管理者支持

管理者可以让智能体依据组织指引起草绩效沟通或反馈记录。准确性、公平性、保密性和最终决定仍由管理者负责。

## 请求示例

```text
请按当前面试评估标准整理这些已获准使用的笔记。将直接观察与解释分开，指出证据缺口，不要给候选人排名或建议录用决定。
```
