# 知识检索与信息整理场景

智能体可以检索已连接且获准使用的来源，并将资料整理成简明回答。它只能查找自身配置范围内的内容，并不会自动了解组织中的每个文件。

## 查找内部答案

提出具体问题，说明团队或时间范围，并要求注明来源。查询政策和流程时，让智能体引用相关规则、生效日期和例外情况。依赖答案前，请打开原文核对。

## 整理团队常见问题

把已批准的指南和重复问题放在可访问的位置。让智能体归类问题、起草简短答案，并标出资料缺口或冲突。由内容负责人核实并发布每条答案。

## 总结讨论和研究

在已连接相关来源且有权限时，限定一组消息或文档及时间范围，要求分别整理依据、决定、阻碍和待解问题。抽查样本记录，不要把不完整的索引当作完整调查。

## 谨慎使用网页资料

若已启用网页搜索，可要求智能体提供带日期的来源链接，并区分公开网页和内部记录。价格、政策或时事可能变化，重要信息应在原始网站核对。

## 请求示例

```text
请仅依据当前获批的差旅政策，判断这次出行是否需要事先批准。引用适用章节和生效日期。如果政策未涵盖这种情况，请说明还缺少哪些信息。
```
