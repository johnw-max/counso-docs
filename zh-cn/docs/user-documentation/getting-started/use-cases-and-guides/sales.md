# 销售场景

销售团队可以用智能体准备客户沟通、整理账户资料、起草回复并识别后续工作。结果应辅助销售人员判断，不能代替本人作出承诺。

## 客户沟通准备

向智能体提供客户简介、获准使用的 CRM 记录、相关会议摘要和核对日期。让它分别整理已确认事实和资料缺口，并列出关键联系人、待问问题、近期决定、风险和下一步。会前对照来源核实客户名称和日期。

## 客户问题和方案回复

提供经批准的产品、安全及价格资料。要求每项事实都附来源，并另列资料无法回答的问题。发送前，应由销售人员或专业负责人批准安全说明、报价、路线图承诺和合同表述。

## 会议记录和跟进

提供符合用途要求的录音转写或会议笔记。让智能体整理摘要、客户明确提出的需求、双方作出的承诺、未解决问题和建议负责人。应区分原话与智能体概述。创建跟进任务前，由人工确认责任人和截止日期。

## 个性化沟通和销售复盘

起草邮件时，提供相关客户背景和获准的范例，并要求措辞具体、礼貌且不超出资料事实。复盘通话时，可让智能体依据团队标准分析转写稿，并引用支持每条观察的对话片段。

## 请求示例

```text
请根据获准的客户资料和最近两份会议摘要，帮我准备下一次客户会议。分别列出已确认事实、待确认问题和后续事项。每项注明来源和日期，不要编造承诺或价格。
```

分享结果前，核实每一项对客表述，并移除不属于目标受众的信息。
