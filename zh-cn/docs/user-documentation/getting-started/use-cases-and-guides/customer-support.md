# 客户支持场景

智能体可以帮助支持团队查找相关指引、总结工单、起草回复和归纳重复反馈。只连接团队获准使用的支持资料和工单记录。

## 排查问题

提供客户问题、相关产品版本、错误信息和获准使用的历史记录。要求智能体列出可能原因、各自依据、建议检查步骤，以及需要升级处理的节点。不能把看似合理的猜测当作已确认诊断。

## 起草客户回复

让智能体依据已批准的帮助文章和已知问题说明起草回复。要求每个操作步骤都注明来源，并单独列出需要工程团队确认的内容。发送前由支持专员检查语气、技术准确性和客户相关事实。

## 归纳客户反馈

限定时间范围，让智能体按主题整理反馈，并提供有代表性的来源。要区分实际检查的记录数和估算的趋势，也要核对重复报告后再发布统计。

## 更新团队知识

问题解决后，由人工判断已核实的处理方式是否应写入帮助文章或已知问题清单。智能体可以起草更新内容，但应由知识负责人批准和发布。

## 请求示例

```text
请依据获准的支持指南和这条工单起草回复。每项排查步骤都列出来源，并标明尚未核实的内容。不要承诺修复日期，也不要发送回复或更改工单。
```

发送回复、修改工单状态或更新客户记录，都需要相应工具已启用并经人工复核。
