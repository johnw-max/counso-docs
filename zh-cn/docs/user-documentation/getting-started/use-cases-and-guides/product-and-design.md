# 产品与设计场景

产品与设计团队可以让智能体依据给定风格指南检查文案、总结研究、整理反馈并准备发布材料。产品主张和用户主题应保留可追溯的证据来源。

## 检查界面文案

提供当前文案、目标用户、界面上下文和获准术语。让智能体检查清晰度、无障碍、一致性和歧义，并给出附简短理由的替代方案；最终选择由产品设计人员决定。

## 准备版本说明

提供已批准的功能说明、目标受众、可用范围和已知限制。让智能体分别起草内部摘要、客户版文案，并列出需要产品或法务复核的说法。不要在来源之外推测发布日期或可用范围。

## 总结用户反馈

限定时间和来源集合。让智能体按用户需求归类反馈，提供代表性引用，区分出现频次和影响，并列出相反证据。产品研究人员应先核实样本，再对外呈现趋势。

## 探索市场问题

若已启用网页检索，请要求提供有日期的来源，并将已核实发现与假设分开。竞争或市场信息应链接到原始页面，对外使用前还需重新确认。

## 请求示例

```text
请面向首次使用的管理员检查这段设置页文案。标出不清楚的术语、无障碍问题，以及供应的产品说明不支持的表述。给出替代写法，但不要修改源文件。
```
