# Counso 简介

Counso 是一个共享 AI 工作空间，供团队使用已配置的智能体、获准的知识来源和已连接的工具。你在工作区中能看到和使用什么，取决于组织配置和你的个人权限。

## 问第一个问题

1. 打开 **Work**，新建一段对话。
2. 查看当前选择的智能体，确认它的用途和数据权限适合这项任务。
3. 清楚说明问题，指出相关资料或时间范围，并说明希望得到什么格式的结果。
4. 分享或据此行动前，先对照来源核实回答。

如果界面提供智能体选择器，可以在对话中用 `@` 指定智能体。初次使用时，可以让它总结一份你有权查看的短文档，再亲自核对关键事实。

## 根据任务选择智能体

工作区可能包含同事创建的共享智能体和通用智能体。打开智能体详情，先了解它的用途、可用工具和数据范围。只有当来源和规则都适合任务时，专用智能体才更合适；它并不意味着对其他问题也一定更准确。

## 与团队协作

需要共同维护对话、文件和任务时，可以使用共享 Pod。敏感工作应放在成员范围合适的受限空间。共享对话或 Pod 不会自动扩大你对外部数据源的访问权限。
