# 欢迎使用 Counso

Counso 将 AI 助手、团队知识和协作工作放在同一工作区。你可以向智能体提问、整理资料、起草内容，或在 Pod 中和同事共同推进任务。模型、数据源和可执行操作以工作区实际配置为准。

## 先熟悉三个工作区域

- **Work**：查找智能体、发起对话，并进入 Pods 和 Skills。
- **Spaces**：查看工作区如何组织连接的数据和访问范围。
- **Admin**：由管理员管理成员、工作区设置和权限。

## 使用时记住三点

1. **选择合适的资料。** 说明文件、时间范围和业务对象；智能体只能使用已连接且当前用户有权访问的内容。
2. **把回答作为草稿或分析。** 核对来源、金额、日期和结论，尤其是财务、法律和客户事项。
3. **分清建议和已完成操作。** 若智能体建议更新外部记录，先确认授权，再到目标系统检查结果。

Counso 可以帮助整理信息、推进协作，但不会替代业务负责人的判断。团队共享空间的用法请看 [Pods 概览](../../pods/overview.md)。
