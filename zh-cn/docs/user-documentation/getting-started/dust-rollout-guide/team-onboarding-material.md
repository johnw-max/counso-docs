# 团队入门培训材料

准备一场简短培训，让每位成员都能完成一次有来源、可复核的工作，而不必一次讲完所有功能。

## 培训流程建议

1. **说明用途和边界**：工作区适合处理哪些任务，哪些资料不应输入。
2. **现场演示**：选一份获准的短文件，展示如何选择智能体、说明目标和指定输出格式。
3. **练习核对**：打开引用来源，检查金额、日期和事实，并指出回答中不确定的部分。
4. **介绍协作方式**：演示如何在 Pod 中共享资料、分配任务以及安排复核。
5. **收集问题**：记录权限、资料更新和结果质量方面的问题，并安排负责人跟进。

## 可复用的团队说明

分享前请按组织规则补充：允许使用的数据类型、需要人工审批的操作、支持联系人，以及已经开通的外部连接。不要把管理员政策或访问权限说成适用于所有团队的通用承诺。

## 课后练习

请每位成员用一项低风险任务走完“提出请求—查看来源—修正问题—保存或分享结果”。培训负责人收集常见问题，再更新团队的示例请求。
