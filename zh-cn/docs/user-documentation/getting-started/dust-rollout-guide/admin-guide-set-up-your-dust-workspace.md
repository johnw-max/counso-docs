# 管理员：准备团队工作区

开放新流程前，管理员应确认成员能够登录、数据连接范围清楚，智能体权限符合目标受众。各工作区的菜单和连接选项可能不同，以管理界面当前显示为准。

## 管理成员和身份

查看成员列表、邀请方式和角色设置。若组织使用单点登录或集中身份管理，由身份管理员按内部流程配置。成员无法登录或找不到工作区时，先核实邀请邮箱和身份提供方状态。

## 配置数据连接和工具

只连接流程需要的数据源，并确认连接账号对资料具有合适权限。要区分数据连接（读取或同步来源）与工具（在来源系统执行特定操作）。逐项检查智能体是否只使用必要的 Space、Knowledge 和工具。

## 设定访问范围

明确哪些空间或 Pod 面向所有成员，哪些必须邀请。共享文件和对话会向该空间成员开放；文件夹名称或智能体指令不能代替权限隔离。若受众不同，应使用不同空间并核对成员名单。

## 监测和维护

定期检查成员、连接状态以及用量页面中可见的指标，并记录业务负责人、数据来源和复核责任。价格、模型和功能以当前工作区设置及服务约定为准，不要把其他部署的数值套用过来。
