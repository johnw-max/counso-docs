# 制定团队试用计划

试用计划要回答四个问题：先解决什么问题、由谁负责、使用哪些资料、如何判断结果值得继续。试用规模和周期按团队情况安排，不必先承诺固定上线日期或收益。

## 明确目标和边界

从一个重复、低风险且容易核对的工作开始，例如依据政策文件整理常见问题，或汇总一周内的待跟进事项。写明：

- 现有流程由谁完成，耗时和常见返工是什么；
- 智能体可以读取哪些资料，哪些数据不能使用；
- 结果由谁复核，什么情况需要升级给负责人；
- 试用结束时要观察哪些指标。

## 组建小型试用组

安排一位流程负责人、几位实际使用者和一位能评估准确性的复核人。让使用者带来不同但有代表性的样例，不要只用演示材料验证。

## 持续复核和回顾

每轮记录完成时间、重要错误、缺失证据、人工修改量和使用者反馈。遇到问题时，先确认来源、范围和指令是否合适，再调整一个因素重新测试。

## 何时扩大

流程能够重复执行、结果有明确复核人且访问范围符合目标受众后，再增加团队或数据源。新增权限和自动化要逐项核对；一次成功回答不足以证明长期质量。
