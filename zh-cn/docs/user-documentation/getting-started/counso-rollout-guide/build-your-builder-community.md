# 支持团队中的智能体创建者

团队创建者熟悉实际流程，愿意整理规则、试用新做法并分享经验。他们不一定是工程师；关键是懂业务、能听取反馈，也知道何时需要管理员或专业人员协助。

## 找到合适的人

留意经常处理重复问题、熟悉团队资料、愿意改善流程的成员。先邀请少数人试用，并为每个试用安排业务负责人和结果复核人。

## 建立轻量的协作方式

- 建立团队可访问的交流渠道或定期短会；
- 记录示例请求、资料范围和已知限制；
- 分享有效用例，也讨论失败案例和修正方式；
- 由管理员处理连接器、成员权限和工作区级设置。

## 创建者负责什么

创建者可以整理智能体指令、选择获准来源、准备测试样例并收集反馈。共享给更多人之前，应检查它能否回答代表性问题、引用是否正确，以及是否只使用必要的数据和工具。

## 让做法持续有效

为每个共享智能体指定维护人。资料、政策或流程变化时重新检查指令和样例。使用量低或结果不再适用时，应更新或停用，而不是继续复制旧配置。
