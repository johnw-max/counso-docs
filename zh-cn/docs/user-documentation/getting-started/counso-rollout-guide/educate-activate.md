# 培训并支持团队

培训目标是让成员知道怎样完成任务、核对答案，并在不确定时找到负责人。每个团队都应按自己的数据政策和权限补充说明。

## 入门培训要回答的问题

- 团队为什么使用 Counso，适合从哪些工作开始？
- 哪些资料可以提供给智能体，哪些应留在原系统？
- 怎样选择智能体、指定资料来源并清楚提问？
- 如何核对引用，发现错误或缺失时如何反馈？
- 哪些结果必须由会计、业务负责人或管理员确认？

## 安排一次实操

使用低风险且获准的样例，演示如何提出请求、查看引用、澄清结果和保存协作任务。让每位参与者亲自完成一次，而不只是观看演示。再准备一个资料不全的案例，练习让智能体说明缺口，而不是自行猜测。

## 持续收集反馈

试用期间定期了解哪些步骤变快、哪些结果需要返工、哪些资料缺失。由流程负责人判断应改进指令、来源或培训，还是暂缓该场景。
