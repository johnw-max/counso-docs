# 衡量效果并谨慎扩大

试用结束时，判断这项工作是否比原流程更快、更容易复核，并且质量没有下降。先记录基线，再用同一组任务和标准比较结果。

## 记录哪些指标

- 完成任务所用时间；
- 人工更正的数量和类型；
- 缺失的来源或未解决的问题；
- 使用者能否独立完成流程；
- 需要升级给负责人的例外情况。

可用简单的试用记录表收集数据。预计节省的时间不能直接算作实际收益，还要计入复核和修改时间。

## 复盘并决定下一步

挑选几项输出，与原始资料逐条核对。若经常缺少证据，先调整数据连接或提示词；若权限不合适，先修正空间范围；若错误影响仍大，就继续由人工主导或暂停该场景。

流程已有明确负责人、输入稳定且结果通过复核后，再考虑增加相邻团队、数据源或自动触发。每次扩大都要重新检查权限、质量和异常处理。
