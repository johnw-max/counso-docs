# 创建第一个智能体

智能体由指令、所选工具和知识来源组成。先明确一项任务，只提供完成任务所需的信息，并在分享前测试结果。

## 1. 从 Create 开始

在首页选择 **Create（创建）**，然后选择空白智能体或模板。Sidekick 会打开，帮助起草指令并建议初始配置。先阅读建议，再决定是否采用；文字和配置都可以继续修改。

## 2. 编写指令

说明要完成什么工作、希望得到什么答案，以及遇到信息缺失或冲突时应如何处理。可以让 Sidekick 帮忙完善草稿，再逐项检查修改。实际写法可参考[编写有效指令](llm-best-practices/how-to-write-effective-instructions.md)。

## 3. 选择工具和知识

Sidekick 可能会根据任务建议可用能力。在 **Tools & Knowledge（工具与知识）** 中，只添加智能体确实需要的来源和操作。以搜索文档为例：选择相应的 Space，选中已连接的数据源及具体文件夹或集合，再写一段简短说明，告诉智能体何时应该搜索这些资料。移除与任务无关的建议。可在[工具与能力](tools/index.md)中了解可用选项。

## 4. 在 Preview 中测试

使用构建器旁的预览区域提出有代表性的问题，检查智能体是否找到预期资料、是否使用了正确来源，以及回答格式是否符合要求。如果结果不理想，调整指令或来源选择后再测一次。

## 5. 设置名称、说明和标签

在 **Settings（设置）** 中填写便于同事调用的名称、简明用途说明和帮助查找的标签。点击 **Suggest（建议）** 可根据说明生成标签建议。可用标签由工作区管理员管理，其他成员从已有标签中选择。

## 6. 发布并设置 Editors

智能体准备好供工作区成员使用后再发布。已发布的智能体仍只对能够访问其底层数据源的人可用。发布前，它仅对你和它的 Editors 可见。在 **Editors（编辑者）** 中添加负责维护智能体的同事。分享前再次检查数据访问范围。

## 7. 使用智能体

在对话中通过名称或调用标识选择智能体，并说明要完成的任务。如果同事找不到它，请检查发布状态以及对方能否访问智能体使用的数据源。

## 几个实用习惯

- 为智能体设定一个主要职责；任务有清楚的不同阶段时，可以串联多个智能体。
- 保持来源精简，让智能体更容易选到相关资料。
- 在同事依赖它之前，先测试指令和预期输出。

指令写法示例见[编写有效指令](llm-best-practices/how-to-write-effective-instructions.md)。
