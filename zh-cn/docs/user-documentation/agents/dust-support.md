# 产品支持指引

此处介绍的 Support Skill 是一种产品帮助能力，工作区可能提供该功能。如果 Agent Builder 中显示该 Skill，可从 **Capabilities（能力）** 中添加，或按需要将其开放给智能体发现。不要假设它附带单独的客服机器人或私有账号访问能力。

启用后，该 Skill 可以搜索为它配置的公开产品文档和其他公开产品资料，并基于这些来源回答使用问题。它可以区分产品使用问题、疑似缺陷和私有账号事项。遇到疑似缺陷时，应收集复现步骤、预期与实际行为、界面错误，以及相关环境信息。

该 Skill 可以帮助整理问题报告，但不会代用户提交问题；也无法检查私有工作区设置、账单记录、日志或账号状态，不能承诺修复结果或处理时限，也不能代替组织提供的账号专属支持渠道。公开资料无法回答时，应如实说明，并指出组织提供的适当支持方式。

配置帮助可先查看相关的[Counso 文档](../getting-started/intro-to-dust.md)。
