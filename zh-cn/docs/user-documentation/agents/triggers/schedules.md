# 为智能体设置时间表

在 Agent Builder 的 **Triggers（触发器）** 区域创建时间表，说明智能体何时运行，并可附上一条用于指导每次运行的消息。

## 创建时间表

1. 在 Agent Builder 中打开智能体，进入 **Triggers**。
2. 添加 **Schedule（时间表）**，填写便于识别的名称，并用自然语言描述运行频率。
3. 选择时间表遵循的时区。初始值可能采用你所在的位置；如果时间表服务于其他地区，请明确核对。
4. 可以添加一条消息，说明每次运行要处理的工作。
5. 检查生成的时间表预览，确认显示的星期、时间和时区都符合预期。
6. 保存智能体以登记时间表。

## 检查定时运行

保存后，查看时间表详情和首次运行。根据工作区配置，触发器运行可能仅对智能体编辑者可见。将时间表用于共享工作前，先确认谁可以查看生成的对话。

如果预览中的当地时间或频率不正确，修改时间表描述或时区，并在保存前再次检查生成的预览。时间表只决定智能体何时启动；它不会自动授予其他人访问数据源的权限，也不会让结果对所有人可见。
