# 为智能体或对话选择模型

模型提供智能体背后的语言和推理能力。要设置智能体的保存默认值，可在 Agent Builder 中选择模型；如果只想改变下一条消息，则在对话输入框中选择。可用选项取决于工作区设置和服务提供方状态。

## 在对话中选择

1. 打开对话，点击消息输入框旁的模型控件。
2. 选择一个自动档位，或打开 **More models（更多模型）** 选择具体模型。在部分工作区也可以输入 **/** 并选择 **Pick model（选择模型）**。
3. 发送消息。输入框中的选择只作用于这条消息，不会修改智能体或影响其他成员。不为消息单独选择模型时，智能体使用已配置的默认值。

## 设置智能体默认模型

在 Builder 中打开智能体，在 **Instructions（指令）** 中点击显示当前选择的模型控件，选择可用的自动档位或具体模型，然后保存。具体模型会一直保持选中，直到有人修改。自动档位按其维护的模型和推理组合顺序选择；某个候选项对当前工作区不可用时，系统可能使用列表中的下一个可用项。自动档位不会根据每个问题的难度逐条切换。

## 自动档位和访问等级

如果工作区提供 **Basic**、**Standard** 和 **Premium**，它们是针对不同成本和能力需求筛选的自动选项。输入框中的自动档位与管理员设置的模型访问等级并不相同。访问等级可能控制单个模型、推理强度以及自动选项。详见[模型访问等级](../admins/usage-seats-and-credits/model-access-tiers.md)。

## 推理强度和可用性

选择具体模型时，选择器可能提供 **None（无）**、**Light（轻）**、**Medium（中）** 或 **High（高）** 推理强度。较高强度可能需要更多时间和 credits。只有该模型支持且工作区允许的选项才会显示。找不到模型时，请检查管理员访问设置、服务提供方或地区可用性，以及工作区当前方案。
