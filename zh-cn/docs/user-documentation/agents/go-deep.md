# Go Deep（深入研究）

如果工作区提供 **Go Deep**，它是一项可为智能体启用较长时间研究流程的 Skill。该 Skill 会让智能体使用与默认 Deep Dive 智能体相同的研究能力和指引；它不再把任务转交给单独的 `@deep-dive` 智能体。

## 添加 Go Deep

为自定义智能体配置时，在 Agent Builder 中打开智能体，从 **Capabilities（能力）** 中添加 **Go Deep** 并保存。工作区默认助手可能已带有此 Skill，并可在任务需要时启用它。其可用性取决于工作区设置；管理员可以停用此能力。

## 可用能力

启用并完成配置后，Go Deep 可能提供：

- 用于协调复杂研究的规划和任务执行子智能体。
- 对已连接公司数据源进行搜索和浏览。
- 对 Snowflake、BigQuery 等受支持的数据仓库运行 SQL 查询。
- 搜索和浏览公开网页资料。

如果问题跨越多个来源、需要结构化仓库分析或持续调查，这些能力会比较适用，运行可能需要几分钟。简单查找或只需读取一份特定文档时，普通搜索通常更直接。

Go Deep 只能使用已连接、已启用且智能体有权访问的来源和工具。添加前请检查数据范围与权限；运行后复核引用和覆盖情况。管理员停用默认 Deep Dive 能力后，其他原本会使用该能力的智能体也将无法使用 Go Deep。
