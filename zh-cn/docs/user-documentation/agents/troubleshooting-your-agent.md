# 排查智能体问题

智能体行为异常时，先明确具体表现，再只调整相关配置中最小的一部分。每次修改后都用 Preview 对比结果。

| 表现 | 检查内容 | 可以尝试 |
|---|---|---|
| 找不到正确来源 | 确认已选择预期来源、文件夹、频道或 Space，并确认用户和智能体都能访问。检查标签筛选是否排除了该文档。 | 将来源范围缩小到相关资料；在提问中指出要查找的文档或主题。必要时改善资料组织方式。 |
| 回答编造细节 | 检查回答是否有检索材料支持、来源范围是否过宽，以及对话是否过长。 | 要求引用来源并在证据不足时说明；添加示例或“不推测缺失数值”等约束。新任务使用新对话。复杂任务可测试工作区提供的更强模型或推理设置。 |
| 多次回答格式不一致 | 检查格式和必需字段是否写清楚。 | 明确输出结构，例如写出表格列名，并提供一份合适示例。使用多种输入测试。 |

## 在构建器中迭代

可以让 Sidekick 根据具体问题协助改进指令，也可以从模板开始。逐项判断是否采纳建议，再在 Preview 中用同一个代表性请求测试。如果看不到某项设置或来源，请工作区管理员检查智能体配置和权限。
