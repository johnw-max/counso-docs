# Discover Tools（发现工具）

**Discover Tools** 可以让智能体在任务需要时查找并启用专用工具集。它能让自定义智能体保持精简的初始配置，同时在对话中按需使用已配置的工具。

## 为智能体添加 Discover Tools

如果工作区提供此能力，在 Agent Builder 中打开自定义智能体，找到 **Capabilities（能力）**，选择 **Discover Tools** 并保存。工作区默认助手可能已启用动态工具发现；请先检查现有配置，避免重复添加。

Discover Tools 只能列出已为该智能体配置为按需使用的工具集。添加这个能力本身不会连接服务、创建凭据或扩大智能体权限。

## 对话中会发生什么

收到请求后，Discover Tools 可以：

1. 查看该智能体可用工具集的名称和说明。
2. 根据当前请求匹配合适的工具集。
3. 在本次对话中启用所选工具集。
4. 在工具和授权允许时，调用其操作读取实时数据或修改外部应用。

启用后，同一智能体在这段对话的后续消息中仍可使用该工具集。现有 Space 权限和身份验证设置仍然生效。

## 适用场景

当智能体需要读取尚未索引到 Knowledge 的实时或私有数据，或者需要执行发送消息、创建页面、更新问题等操作时，可以使用 Discover Tools。它也适合需要按需访问多个已配置应用、但不想一开始加载全部工具的通用智能体。

如果所需信息已经索引到连接的数据源，应使用 **Discover Knowledge**。Discover Tools 面向已配置的操作和实时集成。允许外部修改前，请检查具体动作和目标系统。
