# 为智能体添加 Discover Knowledge

**Discover Knowledge（发现知识）** 让智能体搜索已连接的公司文档；在工作区配置支持时，还可以探索结构化数据源，而不必为每个来源分别添加搜索工具。部分工作区的默认智能体可能已包含它。

## 添加该能力

在 Agent Builder 中打开自定义智能体，在 **Capabilities（能力）** 中选择 **Discover Knowledge** 并保存。智能体只能使用通过相应 Space 和权限向它开放的数据源。

## 可以执行什么

根据已连接的数据源和工作区配置，Discover Knowledge 可能支持：

- 跨连接来源按含义搜索文档；
- 浏览来源层级，查找文件夹、页面、Schema 或表；
- 打开并阅读已知文档或页面；
- 检查数据仓库中的数据库、Schema、表、列、类型或样例值；
- 查询已发现的数据仓库表，计算数量、趋势、排名或关联结果。

处理文档问题时，智能体可以先进行语义搜索，再按需浏览或读取完整来源。处理数据问题时，可以将查询结果与文档中的业务定义结合起来。结果取决于已连接的数据源和实际授予的访问范围。

## 适用场景

如果通用智能体需要跨多个连接来源查找资料、定位路径未知的文档，或结合文字背景与结构化分析，可以添加 Discover Knowledge。它用于查找和分析信息，不负责写入第三方应用。智能体需要在应用中执行操作时，请使用[Discover Tools](discover-tools.md)。
