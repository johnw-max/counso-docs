# 调整进行中的对话

如果工作区支持实时查看智能体进度，你可以在运行过程中跟进，并调整任务方向，无需从头开始。进度可能显示搜索、工具调用和文件操作等步骤；如果界面提供详情视图，可点击步骤查看具体信息。

## 智能体运行时发送补充指令

本次运行结束前，你也可以发送新消息。消息会先显示为待处理。智能体会先完成当前一轮操作，例如完成正在并行执行的一组搜索；随后结合此前的对话上下文读取你的消息，并按新的方向继续。

智能体运行时可以连续发送多条消息。它会在当前操作轮完成后一起处理。可以用简短补充来缩小资料范围、添加背景或调整结果格式；仅仅为了纠正方向，不必取消当前运行。

## 一次只运行一个智能体

实时调整适用于对话中当前运行的一个智能体。当前智能体会显示在输入框中。为了确保补充指令送达，应继续与这个智能体协作，不要在同一对话里同时启动另一个智能体。

## 停止运行

停止智能体后，已经完成的工作仍保留在对话中；停止的是后续工作。检查已完成的步骤和结果，再决定是补充指令继续，还是另开一段对话。

## 用补充指令完善任务

补充指令最好说清要改变什么，同时保留仍然有用的工作。例如，智能体正在整理月度摘要时，你想增加区域维度，可以在它运行时补充要求。它完成当前操作轮后会处理新增要求。请在最终答复中确认它确实采纳了修改。
