# 表格查询

表格查询能力可以让智能体针对结构化数据生成并执行查询，再根据返回的行回答问题。它适用于跨表统计数量、合计金额、筛选、分组和比较。语义检索只返回相关片段，可能不会检查每一行，因此不能替代完整的结构化查询。

根据工作区已连接和启用的功能，可查询的数据表可能来自 CSV 文件、已连接的 Google Sheets 或 Notion 数据库、Microsoft 电子表格，或 Snowflake、BigQuery 等受支持的数据仓库。若工作区提供相应选项，也可以直接在对话中上传 CSV。请以工作区实际显示的来源类型和可用状态为准。

## 根据问题选择查询方式

假设汽车表包含 `cars`、`production_year`、`color` 和 `description` 四列，“2000 到 2010 年生产的汽车中，哪种颜色最常见？”适合用表格查询。“如果我住在纽约，哪辆车最值得买？”需要理解未结构化的描述，更适合检索。

如果任务既需要数量结果，又需要解释背景，可以结合两种方式。

## 为智能体添加 Query Tables

工作区提供此功能时，打开 Agent Builder，找到 **Action & Data sources（操作与数据源）**。选择 **Add a tool（添加工具）**，再选 **Query Tables（查询表格）**。选中智能体需要使用的一张或多张表，然后保存配置。该工具可以同时查询多张受支持的数据表，也可以组合来自不同来源的表。

如果需要关联多个表，请在智能体指令中说明匹配列。例如，`users` 表有 `email` 列，`orders` 表有 `user_email` 列，可以说明这两列代表同一用户。关联关系会影响总额时，还要说明一对一或一对多关系，避免重复计算。

## 从 CSV 创建表格

如果工作区允许手动创建 CSV 表格，Builder 可以在 Knowledge 文件夹中操作：

1. 打开 **Knowledge（知识）**，再进入要存放表格的 Space 的 **Folders（文件夹）**。
2. 选择一个文件夹，或点击 **Add a new folder（新建文件夹）**。
3. 打开该文件夹中的 **Tables（表格）** 标签页，点击 **Add table（添加表格）**。
4. 上传 CSV 文件，并填写清楚的表格说明。

说明每一行代表什么，并解释重要列的含义。例如：“这是 CRM 导出的数据。每行代表一位潜在客户，包含最近一次会面日期和当前销售阶段。”清楚的说明能帮助智能体按正确的数据含义生成查询。

连接设置完成且有权限访问相关文件或数据库后，Google Sheets 和 Notion 数据库可能会作为表格出现。对于 BigQuery，如果连接启用了元数据选项，智能体可能会读取表格和列的说明。具体能力取决于工作区里的连接器和设置。

## 核对数量结果

说明统计期间、筛选条件、分组方式、币种或计量单位，以及如何处理缺失值和重复行。关联多张表时写明关键列。需要完整覆盖时，对照原表核查返回表格、筛选条件和行数。结果看起来合理，并不能证明查询使用了所有预期记录。

表格查询面向结构化数据，不适合直接理解未结构化文本。若要分析文档含义或提出建议，应使用检索能力，并核对所引用的来源。
