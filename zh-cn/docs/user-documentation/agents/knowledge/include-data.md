# 纳入数据

如果希望智能体每次回答时都把一组指定文档放进上下文，可以使用 **Include Data（纳入数据）**。它与搜索不同：搜索会根据当前问题寻找相关资料；Include Data 则纳入选定来源中的资料，不按问题相关性排序。

## 它如何选择资料

启用此操作后，智能体会按更新时间倒序读取所选数据源中的文档，从最新文档开始，再依次读取更早的文档，直到达到 Include Data 的上下文容量上限。它不会根据当前问题筛除不相关文档。

Include Data 有自己的上下文容量限制，并不等同于智能体所选模型的完整上下文窗口。超出这一限制的内容不会进入本次运行，即使原件仍保留在数据源中。

## 适用场景

如果来源范围较小且需要持续考虑最新内容，Include Data 可能适用，例如产品更新或每周项目记录。举例来说，智能体可以根据更新记录来源中最近的条目，整理每周摘要。

如果来源很大，或者需要由具体问题决定哪些文档重要，应使用搜索。搜索按相关性挑选资料；Include Data 则优先纳入最新内容，直到达到自身的上下文容量上限。

## 重要限制

- 它优先读取最新文档，不会按问题挑选最相关文档。
- 它纳入近期来源内容时不做相关性过滤。较旧但直接回答问题的文档，可能会在容量被新内容占满后被排除。
- 实际纳入的内容量取决于文档大小和该操作的上下文容量。来源更大，并不代表每次运行都能读取所有文档。

如果工作区提供 **Include Data** 操作，可在智能体配置中添加它并选择目标来源。用一条已知的近期记录和一条较早但相关的记录进行测试，确认本次运行实际会考虑哪些内容。
