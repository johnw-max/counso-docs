# Deep Dive 智能体

如果 Counso 工作区提供 **Deep Dive** 智能体（可能显示为 `@deep-dive`），可以用它调查需要跨多个来源综合分析的问题。与快速回答型智能体相比，它会花更多时间进行规划、检索和归纳。是否可用、能访问哪些来源，取决于工作区配置。

使用时，在对话中选择或提及 Deep Dive 智能体，并说明问题、涉及的期间或对象，以及答案需要提供哪些依据。简单查找使用普通智能体进行定向检索通常更直接。

## 调查过程

对于简单问题，Deep Dive 可能直接回答。较复杂的任务可能包括以下环节：

1. 规划调查并拆分不同研究问题。
2. 将任务交给专门的子智能体，例如文档检索、网页研究或数据库分析。
3. 并行执行相互独立的研究任务，最多可同时运行六个子智能体任务。
4. 综合结果，整理成带引用的结构化答复。

深入调查可能需要几分钟。请查看运行进度，并在依赖综合结论前复核来源、覆盖范围和假设。

## 来源与能力

根据连接和智能体已启用的功能，Deep Dive 工作流可能使用：

- **知识检索与浏览：** 查找相关段落、浏览来源目录，并分段读取完整文档。
- **数据仓库：** 查看可用结构，并查询 Snowflake、BigQuery 等受支持的数据仓库。
- **网页搜索与浏览：** 查找最新公开资料并查看相关页面。
- **可发现工具：** 在任务需要且已配置访问权限时调用工作区支持的集成工具。
- **Frames：** 在图表或交互视图有助于理解结果时生成相应展示。
- **子智能体：** 把复杂调查拆成独立部分，再汇总各自结果。

这些能力并非默认保证可用。工作区必须已连接相应来源，智能体也需要具备所需权限并启用相关工具。若完整性很重要，请要求它说明引用和来源覆盖情况。

## 权限与限制

默认的 Deep Dive 智能体使用 **Company Data** 中的知识和工具，并受当前用户的权限约束。它不能访问 **Restricted Space**，也不能使用针对电子表格和 Notion 表格的独立 **Table Query** 操作；数据仓库查询属于另一项能力。采用 Personal 认证的工具使用当前用户连接的账号，子智能体继承相同的访问限制。工作区管理员可以停用默认 Deep Dive 智能体。

Deep Dive 适合研究和综合。作出决定或更新其他系统前，请回到来源记录核对结论。
