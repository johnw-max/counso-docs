# Skill 示例

Skill 将可重复执行的流程集中维护，供多个智能体遵循同一套规则。下面的例子展示如何说明适用场景、编写指引，以及在需要时添加能力。请根据团队实际系统调整字段和规则。

## 示例一：录入 CRM 商机

销售团队可以通过共享 Skill，确保不同智能体创建的商机记录口径一致。

**说明**

> 本 Skill 说明如何向 CRM 添加商机，包括公司的字段约定。

**指引**

```text
目的：在创建 CRM 记录前，统一商机信息格式。

必填字段：
- amount_usd：只填数字，不带货币符号（例如 15000）
- size_bucket：低于 2,000 美元为 small；大于或等于 2,000 美元为 big
- spqr_stage：suspect | prospect | qualified | ready_to_close
  SPQR 是本公司“销售管道资格评级”的历史字段名称。
- close_date：格式为 YYYY-MM-DD

示例：
商机名称：Acme Corp - Enterprise
金额：15000
规模：big
阶段：qualified
预计成交日期：2026-03-15

检查金额门槛：1,800 美元的商机应标为 small，而不是 big。
```

如果该 Skill 需要创建或更新 CRM 记录，只有在工具可用且已获准供智能体使用者调用时才添加 CRM 工具。Skill 本身只提供流程指引，不会自动授予账号权限。

## 示例二：创建符合品牌规范的 Frame

团队可以用共享 Skill 统一图表和演示材料的视觉风格。本例假设团队已在可访问的文件夹中保存 Frame 模板。

**说明**

> 创建需要遵循本公司视觉规范的 Frame 时使用此 Skill。

**指引**

写明团队使用的颜色、字体、版式原则，以及各颜色的含义。若要引用已保存的模板，在指引编辑器中输入 **/**，按标题搜索模板，并从选择器中选中。之后再用自然语言补充模板中没有涵盖的规则，例如偏好的图表类型或摘要数据的排布方式。

只有当智能体能使用 Frame 创建能力时，才将其加入 Skill。用一个示例 Frame 测试，检查是否采用指定模板和视觉规则。

## 示例三：统一公司沟通语气

共享的语气 Skill 可以帮助面向客户、内部沟通和内容创作的智能体保持一致。

**说明**

> 向客户、潜在客户或合作伙伴发送信息时使用此 Skill。保持专业、亲切，并体现公司的价值观。

**指引**

```text
目的：让对外沟通清楚、一致。

语气原则：
- 清楚，不官腔：使用简单语言，避免不必要的行话。
- 有帮助，不机械：态度友善，聚焦解决读者的问题。
- 自信，不傲慢：表达直接，但不居高临下。
- 专业，不生硬：保持得体，也要容易沟通。

优先使用：帮助、使用、简单、修复、展示、解释、我们建议。
避免使用：赋能、利用（utilize）、整改（remediate）等官样词，
以及“我们谨此建议您或许可以考虑”等冗长表达。

句子尽量简短，使用主动语态，先讲重点。内容较长时使用小标题或列表。

客户支持：先回应问题，再给出明确后续步骤。
产品更新：先讲对用户的好处。
销售沟通：先了解对方需求，再说明结果和建议。

不佳：“我们很高兴地通知您，已根据您的反馈完成所请求功能的实施。”
更好：“好消息：你提出的功能已经上线。可以这样使用……”
```

这个 Skill 主要提供沟通指引，因此可能不需要工具。如果智能体需要参考以往邮件或客服记录，可以添加获准使用的邮件或客户支持工具，并另行确认访问范围。
