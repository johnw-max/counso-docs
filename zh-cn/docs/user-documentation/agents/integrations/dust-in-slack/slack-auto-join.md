# 自动加入新的 Slack 频道

如果工作区启用了 Slack Auto-Join，名称符合条件的新公开频道可以自动加入并开始同步。管理员无需逐一手动添加符合条件的频道。此功能针对配置规则后新建的频道；已有频道请单独检查。

## 配置频道名称规则

1. 请工作区管理员确认 Auto-Join 是否可用并已启用。
2. 在 Slack 集成设置中填写名称规则，只匹配预期需要同步的公开频道。
3. 新建一个符合规则的测试频道，确认集成已加入并开始同步。
4. 检查同步后的频道是否加入了预期 Space，以及 Space 受众是否合适。

例如，`support-*` 可能匹配新建的 `support-questions` 频道。规则应尽量具体，过于宽泛的规则可能会把无关讨论也加入同步数据。配置或修改集成可能需要 Slack 管理员权限。

Auto-Join 不会把私密频道变成公开频道，也不能代替对目标 Space 访问范围的检查。依赖新频道回答问题前，请确认实际同步了哪些数据。
