# 将 MCP 客户端连接到 Counso

Counso 的 MCP 服务允许兼容的外部应用使用你的工作区。你可以在 IDE 或其他 AI 助手中，以自己的 Counso 身份查找智能体、处理会话、搜索知识，以及访问 Pod 文件和任务。使用前，工作区需要启用 MCP 服务访问。

如果你希望让 Counso 智能体使用外部服务的工具，请参阅[添加远程 MCP 服务器](../../admins/tools-management/adding-an-mcp-server.md)。

## 连接应用

1. 向工作区管理员获取当前 Counso 部署的 MCP 服务地址。使用已发布、以 `/mcp` 结尾的服务端点；文档站的网址不是服务端点。
2. 在应用的 MCP 设置中，用这个地址添加远程服务器。应用需要支持带 OAuth 认证的远程 MCP。
3. 按提示登录 Counso，选择要连接的工作区并完成授权。
4. 连接后，请应用确认当前工作区，或列出你可以使用的智能体。

连接采用 OAuth，不需要填写 API Key。不同应用的设置界面会有区别，通常会在添加或连接服务器时启动授权。

## 可以完成哪些操作

服务器可以提供以下工具：

- 确认登录用户和工作区，列出可用智能体。
- 查看或创建会话、发送消息，以及读取会话消息。
- 读取 Pod 信息和任务。
- 列出、读取、创建、搜索和解析会话或 Pod 中的文件。
- 搜索有权访问的 Space 中的知识。

具体工具列表取决于工作区启用的版本。Counso 中配置的第三方工具不会因此全部开放给外部客户端。

## 访问范围与认证

应用以完成授权的 Counso 用户身份操作，只能访问该用户有权访问的 Space、会话、Pod 和文件。连接外部客户端不会让它获得其他成员的私有内容。

兼容的客户端可以通过动态客户端注册（DCR）注册，也可以使用客户端 ID 元数据文档（CIMD）标识自身。客户端必须在 OAuth 授权请求和令牌请求中都携带 `resource` 参数，以便令牌签发给正确的 MCP 服务。MCP 令牌的用途限定在这一连接，不能与工作区 API Key 互换。

工作区管理员可以关闭 MCP 服务访问，并控制授权时允许使用的回调地址。

## 连接失败时

先核对服务地址，并确认客户端支持远程 MCP、OAuth 和 `resource` 参数。如果还没进入 Counso 登录页面就失败，请更新客户端，并检查其 OAuth 自动发现支持。如果提示拒绝访问或回调地址不被接受，请管理员检查工作区是否启用了 MCP 服务，以及是否允许该客户端的回调地址。

工作区权限规则见[访问控制与权限](../../admins/admin-governance/access-controls-and-permissions.md)；客户端兼容性要求见 [MCP 授权规范](https://modelcontextprotocol.io/specification/2025-11-25/basic/authorization)。
