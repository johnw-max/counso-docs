# 在 Slack 频道设置自动回复

智能体可以配置为在指定 Slack 频道中自动回复，不必每次都提及工作区机器人。这适合专门的问答频道，但在普通讨论频道中可能带来过多回复。开始配置前，工作区管理员需要注册并连接当前 Counso 部署使用的 Slack 机器人应用，并使用该部署提供的回调和事件地址。机器人应用与 Slack 数据连接、个人 Slack 工具是分别配置的能力。智能体必须已经发布，才能调整频道设置。

## 选择自动回复的频道

管理员在智能体的 **Slack Channel Settings（Slack 频道设置）** 中配置行为。选中频道并启用 **Respond to all messages in channel（回复频道中的所有消息）**。如果设置中提供 **Top-level posts only（仅回复顶层消息）**，启用后就会跳过线程中的回复；否则，智能体可能既回复新频道消息，也回复线程内容。

明确提及机器人的消息仍按提及方式处理。其他机器人发送的消息会被忽略，以避免机器人之间反复回复。

## 私密频道

工作区机器人应用获得访问权限后，私密频道才会出现在智能体的频道列表中。请邀请机器人加入频道，并确认已连接的集成能够读取频道消息。添加个人 Slack 工具不会授予工作区机器人权限；数据同步应用也需单独配置。

## 检查设置效果

在选定频道发布一条简短测试消息；如果设置允许，也测试线程回复。确认回复来自预期智能体、频道成员能够访问它所需的来源，并且其他无关频道未改变。若要调整行为，返回智能体的频道设置并保存更新。
