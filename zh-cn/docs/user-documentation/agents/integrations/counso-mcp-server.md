# 将 MCP 客户端连接到 Counso

通过兼容的外部应用，可以使用自己的 Counso 账号处理智能体请求、会话、知识和 Pod 资料。用户连接客户端前，需要部署管理员启用 MCP 服务并配置 OAuth 授权。

如果是要让 Counso 智能体使用第三方服务，请查看[添加远程 MCP 服务](../../admins/tools-management/adding-an-mcp-server.md)。

## 连接应用

1. 向工作区管理员取得当前部署的 MCP 服务地址。使用提供的服务地址，不要填写文档页面或自行猜测域名。
2. 在外部应用的 MCP 设置中，用该地址添加远程服务。客户端需要支持远程 MCP 和 OAuth。
3. 按提示授权，登录 Counso 并选择工作区。
4. 先尝试简单请求，例如确认当前工作区或列出有权使用的智能体。

连接通过 OAuth 完成，工作区 API Key 不能替代这个登录流程。

## 使用已连接的工作区

客户端会获取服务提供的工具列表。根据服务配置，可以包含智能体请求、会话、知识搜索，以及 Pod 文件或任务等操作。以实际返回的工具列表为准；其中不会自然包含 Counso 中配置的所有第三方工具。

授权使用你的 Counso 身份和访问范围。在外部应用中修改或分享工作区内容前，应确认具体操作。

## 排查登录问题

检查服务地址、客户端 OAuth 支持及所选账号。如果回调被拒绝或访问被关闭，请管理员检查 MCP 服务设置和允许的回调地址。如果尚未进入登录页就失败，可能需要更新客户端的 MCP 或 OAuth 支持。
