# 创建对话分支

如果希望从现有对话的某个位置继续探索，同时保留原讨论不变，可以创建分支。分支是独立对话，后续消息和文件各自保存。

## 创建分支

使用对话右上角的**三点菜单**，可从最新的智能体消息创建分支。如果要从较早位置开始，在对应的智能体消息上打开菜单，并选择分支操作。对话菜单中的选项以最新一条智能体消息为起点。

准备分支通常需要 10–20 秒，系统会在此期间生成对话摘要。等待时可以发送消息；新对话准备好后，这些消息会排队处理。

## 分支包含哪些内容

新对话首先包含截至所选位置的对话摘要，还会复制父对话当时可用的文件和工具输出。因此，之后在分支中编辑文件不会改动父对话中的文件，反之亦然。

分支会继承相同的 Space 或项目，以及创建者可用的工具和 MCP 服务器。创建分支的人会成为最初参与者。父对话会显示分支起点的链接或提示，分支中则会显示 **Branched from（源自）**链接，方便追溯来源。

## 权限与独立性

创建分支不会修改父对话。分支是独立对话，之后的消息、文件和操作互不影响。分支创建时会继承父对话的访问范围，但如果之后加入受限内容或成员权限变化，两边的权限可能不再相同。

有权访问父对话的人不一定会自动成为分支参与者。分享前请检查分支的参与者和 Space 设置。

## 常见问题

**可以从另一个分支再创建分支吗？** 可以。每个分支都是独立对话，并保留自己的来源关系。

**新分支中还能使用附件吗？** 系统会复制分支起点可用的文件和工具输出。新副本与父对话中的工作副本相互独立。

**想尝试不同的答案怎么办？** 在分支中说明新的方向并继续即可。父对话保持不变，可以对比两种思路。
