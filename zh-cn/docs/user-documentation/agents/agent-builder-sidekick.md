# Agent Builder 中的构建助手

如果 Counso 工作区启用了 Agent Builder 构建助手，它可以协助起草和完善智能体。建议只是供你评估的草稿；应用前请逐项检查。

## 从空白智能体开始

1. 在 Agent Builder 中打开 **New Agent（新建智能体）**，用自然语言说明任务。写清使用者、可用资料来源和期望结果。
2. 回答助手提出的澄清问题。助手可以在指令中提出行内修改建议，并推荐工具、技能和模型。
3. 如果助手提议检索工作区知识以了解业务流程，先检查它要查询的范围，再决定是否允许。
4. 逐项检查指令修改建议。点击 **Accept（接受）** 应用，或点击 **Reject（拒绝）** 忽略。你随时可以直接编辑指令；有待处理的建议时，表单仍可使用。
5. 分别检查工具、技能和模型建议。只有当智能体确实需要某项来源、且预期使用者有权访问时，才把它加入智能体。
6. 切换到 **Preview（预览）**，用有代表性的请求进行测试。继续编辑和测试，直到结果符合预期流程。

## 从模板开始

在模板库中选择模板后，Agent Builder 会载入模板背景。构建助手可以协助调整初始指令，并建议相关工具或知识来源。请用实际流程替换模板中的示例假设，逐项检查建议，再到 Preview 中测试后发布。

## 改进已有智能体

在 Builder 中打开智能体。如果工作区提供相应能力，构建助手可以查看当前配置、反馈和使用情况，并提出指令修改、缺少的能力或可用知识来源等建议。建议需要编辑者审核和应用后才会改变智能体。添加来源或能力前，先确认它符合智能体的用途和访问范围。

## 将对话转换为智能体

如果对话中显示 **Convert to agent（转换为智能体）**，可以从该对话开始创建智能体。构建助手会使用当前可用的对话上下文，起草指令和配置建议。请检查最终配置；先前对话使用过的工具和资料来源，不一定适合新智能体。

## 助手能做什么，不能做什么

启用这些功能时，构建助手可以起草或修改指令、推荐可用工具和技能、建议模型、查找知识来源，并协助整理工作流程；部分工作区还支持生成简单的流程图。

构建助手不能代替 Agent 编辑器和 Preview。已记录的 Builder 流程中，触发器仍需手动配置；助手可以推荐现有技能，但不会创建或编辑技能；测试仍需在 Preview 中进行。它只评估当前编辑的智能体，不会替你设计或运行多智能体流程。

构建助手只能在自身可访问的范围内使用工作区信息提出建议。受限来源仍不可访问；推荐某个来源也不代表它已经加入智能体。保存前请检查来源清单和访问设置。

助手对话可能是临时的，但尚未应用的建议仍可能保留在 Builder 中。离开页面前检查工作区显示的状态，并确认需要保留的修改已应用和保存。
