# 为共享 Frame 添加品牌信息

如果工作区提供此设置，管理员可以配置公开分享的 Frame 所显示的品牌信息。品牌会显示在 Frame 页面上，在支持的情况下也可能出现在链接预览中；它不会改变 Frame 的数据内容或分享权限。

## 配置 Logo 和图标

1. 打开 **Admin（管理）**，选择 **Branding（品牌）**。
2. 上传公司 Logo 和图标并保存。
3. 打开一个公开分享的 Frame，在浏览器标签页和链接预览中检查效果。

建议使用在窄标题栏中仍清晰可读、适合浅色背景的横向 Logo。公司图标应为 **1:1 正方形**，用于浏览器网站图标。若分享目标支持 Open Graph 预览，链接预览也可能使用公司 Logo。

检查公开 Frame 中只包含计划向外部查看者展示的信息。品牌设置只会改变公开 Frame 的呈现方式，不会自动保护私密内容，也不会限制谁可以打开公开链接。

此功能可能取决于工作区配置。如果管理员看不到 **Branding** 或相关 Frame 选项，请核对工作区当前的功能设置。
