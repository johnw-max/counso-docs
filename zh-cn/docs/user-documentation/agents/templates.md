# 从模板创建智能体

模板为常见智能体用途提供起点。选择模板后，会在 Sidekick 中打开带有模板背景信息的引导式创建流程。Sidekick 会起草初始指令，也可能根据用途建议工具和数据来源。

## 按引导流程完成配置

1. 打开模板列表，选择与目标工作相符的模板。
2. 检查 Sidekick 起草的指令，以及建议添加的工具和来源。
3. 可以采用建议，也可以根据团队流程修改；如果不适用则拒绝。
4. 在 Preview 中用目标流程的示例测试智能体。
5. 设置名称、说明、标签、受众和 Editors；配置完成后再发布。

模板只是起点，并不保证其指令或来源选择适合你的组织。发布前逐项检查建议的能力和数据来源。完整配置流程见[创建第一个智能体](create-your-first-agent.md)。
