# 定时唤醒

Wake-up（定时唤醒）会安排 Agent 在之后的时间继续工作。它可以执行一次性检查、按周期重复运行，或在预期有人回复后跟进。用户提出需求后，Agent 可创建唤醒；管理员无需另接一个第三方服务。

例如，可以要求 Agent 在每个工作日检查指定的公开状态页，仅在组件状态变化时提醒；也可以指定某个日期，让 Agent 回到会话检查是否收到回复。说明创建原因、时区、检查来源、重复频率，以及 Agent 恢复运行后要做什么。待执行唤醒会显示在输入区上方和对应会话中。

## 可用操作

- `schedule_wakeup`：填写原因和计划时间，创建未来任务。此操作需要较高确认。
- `list_wakeups`：查看任务状态、时间安排和创建原因。
- `cancel_wakeup`：取消待执行的唤醒。

未来运行会使用最初创建请求用户的身份。唤醒待执行期间，其他用户不能向该会话发送消息，以避免他们影响使用原用户凭据执行的任务。每个会话同一时间只有一个待执行唤醒；触发后可再创建下一个。周期计划有执行次数上限，以当前界面显示为准。计划运行计入该用户通常的 Agent 额度。请检查计划，并在不再需要时取消。
