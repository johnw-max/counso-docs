# Agent 记忆

Memory（记忆）可让 Agent 在不同会话间保留部分信息，提供必要的上下文连续性，例如用户明确表达的偏好或反复出现的背景。为 Agent 启用后，它可能会判断哪些会话信息值得记住；用户也可以直接要求它记住某件事。

记忆与共享 Knowledge 来源不同：它属于单个用户在该 Agent 下的个人信息，不是其他成员都能查看的工作区记录。用户可在 Agent 详情面板中查看或删除已保存内容。删除后无法恢复；记忆会一直保留，直到被删除。

在 Agent 构建器的 **Tools** 区域启用 Memory，并在 Agent 指令中说明适合记住哪些用户偏好。不要让它保存凭据、敏感记录或不应长期保留的临时信息。如果回答似乎依赖过时的个人背景，可先检查记忆面板。
