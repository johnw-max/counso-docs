# Google Calendar

Google Calendar 工具使用每位用户自己的 Google 账号查询和管理日程。它使用个人凭据：只有授权用户能访问的日历事件才会显示。

工作区管理员从 **Spaces → Tools → Add Tools** 添加 Google Calendar，并按表单要求完成管理员设置；随后由每位实际使用者连接自己的 Google 账号。将工具加入 Agent，先用有限的时间范围搜索日程，或读取一条已知事件。

创建或更新日程时，明确日历、参与者、时区、起止时间和重复规则。更改或发送邀请前先查看预览，完成后回到 Google Calendar 核验同一事件。日程缺失时，确认实际操作用户有权访问该日历，并检查时间范围和时区设置。
