# 按需启用工具

Just-in-time（JIT，按需启用）允许用户从会话输入区临时开启某项能力，而无需修改 Agent 的共享配置。这项选择只在当前会话任务中生效，不会永久添加到其他用户使用的 Agent 中。

当一次性请求需要某项平时不应一直开放的能力，或希望遵循最小权限原则时，可使用 JIT。在会话输入区打开工具或能力选择器，选中任务需要的项目后继续。可选项取决于工作区配置和当前 Agent。

JIT 不会绕过第三方认证、资料权限或 Space 分享设置。用户仍须有权调用对应工具，Agent 也只能访问授权身份能看到的记录。执行写入前应确认目标和内容。如果某能力经常被需要，请管理员评估是否加入共享 Agent 配置，而不要长期依赖每次临时启用。
