# HubSpot

HubSpot 工具可让 Agent 读取 CRM 对象；若授权范围允许，也可新建或更新联系人、公司、交易、工单和自定义对象。具体工具列表会随第三方账号和授权变化，应查看当前 Agent 构建器中实际可用的操作。

工作区管理员从 **Spaces → Tools → Add Tools** 添加 HubSpot，选择目标 HubSpot 账号并完成 OAuth。只授予 Agent 任务需要的 CRM 对象权限。将工具分享给合适的 Space，再加入 Agent。

先对目标对象类型调用 **Get Object Properties**，然后通过 ID 读取一条已知记录。属性响应可帮助确认哪些字段可写。新建或更新前核对目标对象和字段值，之后再按同一 ID 读取回查。认证成功却查不到对象，常见原因是应用范围、对象权限或私有应用策略未配置完整。只需回答问题的 Agent 不应获得宽泛写入权限。

## 可用操作

根据启用的权限，工具列表可包括对象属性发现；创建联系人、公司、交易、线索、任务、工单、备注、沟通记录和会议；读取联系人、公司、交易或会议；对象计数和最新对象查询；文件公开 URL 查询；关联会议查询；以及 CRM 对象搜索。创建对象需要对应对象权限和可写字段。写入自定义字段前先检查属性列表。
