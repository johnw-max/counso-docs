# Jira

Jira 工具可让 Agent 浏览项目和 Issue、执行搜索、创建或更新 Issue，并在连接身份具备权限时执行工作流转换。除了工具配置，Jira 项目角色和工作流条件也会影响可执行操作。

在 **Spaces → Tools** 中添加 Jira，并选择当前表单提供的站点和凭据方式。完成 OAuth 或其他受支持的认证后，将工具分享给目标 Space 并加入 Agent。使用自建应用时，采用连接表单显示的回调地址。搜索至少需要 **Browse Projects** 和 Issue 读取权限；只有 Agent 需要写入时才添加创建/编辑 Issue 或转换状态的权限。

先读取一个已知项目和 Issue。创建或修改时，明确项目键、Issue 类型、摘要、字段和目标状态；完成后按同一 Issue 回读。即使能读取 Issue，状态转换仍可能因工作流条件、必填字段或项目权限不足而失败。
