# 调用其他 Agent

`run_agent` 能力可让一个 Agent 把另一个专门 Agent 当作工具调用。任务需要明确分工或独立子任务时适合使用，例如由研究 Agent 先收集证据，再交给写作 Agent 整理答复。

在 Agent 构建器中启用此能力，并选择允许调用的 Agent。确保被调用 Agent 的指令和资料范围适合子任务。主 Agent 只应传递完成任务所需的上下文，并说明期望返回的格式。

默认模式会在单独会话中运行被调用 Agent，完成后返回结果，适合较长或独立的工作。如果界面提供“在当前会话中响应”模式，则可将调用留在当前交互中。两种模式都不保证返回内容正确；主 Agent 应检查结果、来源以及可能产生的外部影响后再使用。避免递归或过于宽泛的委派，以免责任和结果来源难以追踪。
