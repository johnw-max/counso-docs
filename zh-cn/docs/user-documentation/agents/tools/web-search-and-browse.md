# 网页搜索与浏览

Web Search 用于查找与问题相关的公开网页；Browse 可打开选定网页并读取当前内容，让 Agent 据此处理问题。这些能力访问的是公开互联网，与搜索组织内部连接的资料不同。

在 Agent 的 **Tools** 设置中启用相应能力。请在指令中说明何时搜索、哪些域名或页面类型合适、需要多新的信息，以及如何引用来源。对于最新或有争议的结论，可要求 Agent 对比多个可靠网页并附上链接。

搜索结果可能漏掉页面、出现过时内容，或只反映网站已公开发布的文字而非底层记录。部分页面会屏蔽访问或要求登录。希望限定范围时，应提供具体域名或页面。处理公司内部资料时，应使用获授权的 Connection 或 Tool，不能假设网页搜索能访问私有内容。依赖答案前，请打开引用页面核实重要事实。
