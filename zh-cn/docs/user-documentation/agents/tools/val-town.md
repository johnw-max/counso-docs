# Val Town

Val Town 工具可让 Agent 访问授权账号中的 Vals 和文件。根据启用的操作，可列出和搜索 Vals、读取文件、创建或更新代码、删除文件以及调用 HTTP 端点。

在 **Spaces → Tools** 中添加 Val Town，使用目标账号完成 OAuth，将工具分享给相关 Space 并加入 Agent。使用前确认连接账号。先运行 `list vals`、`get val` 或 `list val files`，识别目标并检查现有代码。

运行 Val、写入文件、删除内容或调用 HTTP 端点都可能对会话外部产生影响。执行前检查代码和端点，明确指定 Val 或文件，并核对预期结果。若能看到 Val，却看不到其文件或端点，检查所有权和账号权限。认证成功不等于可以执行任意代码。

## 可用操作

工具支持创建 Val、读取/列出/搜索 Vals、列出文件、读取文件内容、创建或写入文件、更新或删除文件，以及调用 HTTP 端点。相关操作可能部署或执行无服务器函数。通过工作区的受保护 Secret 机制配置 Val Town 令牌，并赋予其所需读写权限；不要将令牌粘贴到会话中。
