# Notion

Notion 工具可让 Agent 搜索页面和数据库；在授权范围允许时，也可创建或更新页面、数据库条目、内容块和评论。搜索结果受已分享给 Notion 集成的页面、数据库以及授权身份限制。

管理员从 **Spaces → Tools → Add Tools** 添加 Notion 并完成第三方授权。在 Notion 中，明确将需要访问的页面或数据库分享给集成；仅是工作区成员并不意味着集成可以读取所有页面。将配置好的工具分享给目标 Space，再加入 Agent。

先搜索一篇已知页面并核对页面路径。处理数据库前，检查数据库属性再创建或更新条目。编辑页面内容块时保留已有内容，完成后回读页面。如果找不到页面，确认它已单独分享给集成，且授权账号能够打开。将写入范围限制在 Agent 实际需要的页面和数据库内。

## 可用操作

Notion 操作覆盖页面创建、读取、更新和添加内容；数据库创建、读取 Schema、查询、读取数据、新增或更新行；内容块读取、子块列表和删除；搜索；评论；以及用户列表和用户信息查询。页面和数据库的共享范围需要在 Notion 中设置。数据库可见不代表其下每个页面或内容块都可见；扩大工具访问前先核对目标分享范围。
