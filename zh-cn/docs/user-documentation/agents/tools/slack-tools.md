# Slack 工具

Slack Tool 可让 Agent 搜索消息和频道、读取讨论串、查找用户，并在获准时发送或定时发送消息。它使用已连接用户的 Slack 身份。

工作区管理员从 **Spaces → Tools → Add Tools** 添加 Slack 并完成 OAuth。每位用户可能需要分别授权自己的账号。将工具分享给目标 Space，再加入 Agent。支持操作包括消息搜索、账号支持时的语义搜索、会话或讨论串读取、用户查询、发送和定时发送。

需要精确发送时，尽量使用频道和用户 ID；在讨论串中回复时附上线程时间戳。定时消息可能不支持附件。发送后回到 Slack 读取频道或消息进行核验。私有频道缺失时，可能是实际用户或应用尚未加入。请核对工具权限和频道成员范围。

## 可用操作

工具集包括消息搜索、账号支持时的语义消息搜索、发送和定时发送消息、频道列表与搜索、用户列表与详情，以及会话或讨论串查询。Agent 构建器显示的名称是当前工作区实际可用的操作。定时发送可能不支持附件；发送消息时指定正确的频道或用户 ID，在讨论串中回复还要提供线程时间戳。
