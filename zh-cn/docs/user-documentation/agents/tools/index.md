# Agent 工具

工具可让 Agent 使用内置能力，或在已连接的第三方服务中执行操作。工具需要加入 Agent 的配置；某个工具在列表中可用，不代表该 Agent 已获授权使用。工作区管理员可能需要先启用该工具，并将其分享给目标 Space。

## 只添加当前工作需要的能力

内置能力可能包括知识搜索、网页搜索与浏览、数据可视化、文件和图片生成、记忆，以及委派给其他 Agent。第三方工具可查询或操作邮件、日历、项目管理、CRM、文件存储和客服系统。当前构建器会显示此工作区实际可用的工具。

对每种能力都要明确：哪些请求应使用它、可访问哪些资料、是否能够修改或发送内容，以及由谁检查结果。将这些规则写入 Agent 指令。只需要查询时优先使用只读权限。对于可写工具，明确实际操作账号、限制 Space 的使用成员，并让负责人复核重要操作。

## 配置与检查

1. 在 Agent 构建器中打开 **Tools**，添加角色需要的能力。
2. 在资料或知识设置中，仅选择 Agent 需要的来源，并说明每项来源的用途。
3. 提出一个有代表性的请求，检查 Agent 是否使用了预期工具，以及引用的来源或第三方记录是否正确。
4. 若 Agent 有写入能力，只测试范围明确且安全的操作，并到第三方系统核验结果。

工具调用可能受第三方权限、授权账号或资料范围影响而返回不完整结果。增加更多工具无法消除这些限制，反而可能使回答来源更难判断。单次请求若有按会话临时启用工具的选项，应优先采用，避免改动共享 Agent。
