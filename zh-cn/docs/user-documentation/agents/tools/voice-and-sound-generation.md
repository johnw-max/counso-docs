# 语音与声音生成

如果当前工作区提供相应能力，Agent 可以将文字转换为语音。请提供准确脚本、目标听众、语言、发音提示和语气。生成的音频属于输出文件，分发前应实际试听。

在 Agent 构建器 **Tools** 中启用可用的语音或音频生成能力。先生成一段较短样例，检查姓名、数字、发音、停顿以及语气是否符合要求。如果使用声音档案或参考录音，应确认使用授权且适合目标听众。

音质和支持格式取决于当前模型及工作区。不要默认转录、录音或生成声音已获准公开发布。完整试听并核验后，再保存或下载输出。

## Speech Generator

Speech Generator 可生成单人旁白或多角色对话，并可设置声音、语言和说话风格。原始规格记录单人语音最多 10,000 个字符、多角色对话最多 5,000 行、支持 21 种语言并输出 MP3。请以当前能力面板显示的限制和格式为准。在 Agent 构建器中启用即可，无需额外的第三方设置。
