# Semrush

Semrush 远程工具可将 Agent 连接到 Semrush 账号提供的关键词、域名、SEO 或趋势数据。工具由 Semrush 运营和支持；可用报告及 API 额度取决于第三方账号和方案。

工作区管理员从 **Spaces → Tools** 添加 Semrush MCP 工具，并按当前表单显示的方式完成认证。使用经批准的 Semrush 账号，只向相关 Space 分享。将工具加入 Agent 后，先执行范围明确的域名或关键词报告。

使用结果前，检查选中的账号、报告类型、日期范围和 Semrush 显示的 API 额度消耗。如果无法访问，确认该 Semrush 账号已启用 API 访问，且密钥或 OAuth 身份拥有所需产品权限。数据或 API 的第三方问题应联系 Semrush。
