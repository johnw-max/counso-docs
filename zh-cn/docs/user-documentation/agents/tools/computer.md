# Computer

Computer 为 Agent 提供安全的临时工作区，可用于检查文件、运行代码、转换数据并将完成的成果返回当前会话。需要精确计算或真实文件输出时适用；简单问答或短摘要通常不需要它。除非通过获准的界面上传，Agent 无法读取用户笔记本电脑上的文件。

## 处理文件

Computer 可清理或计算 Excel 和 CSV 数据、更新已有工作簿、创建或编辑 PowerPoint、更新 Word 文档、提取 PDF 文本、分析图片、处理 ZIP 压缩包，并生成报告、图表、CSV 导出或格式转换文件。处理电子表格时，说明需要检查的行、列、公式和格式；要求它核对汇总值。更新演示文稿时，可上传模板并明确要修改的幻灯片或章节。模板结构重要时，应修改原文件副本而不是从零重建。向工作区外发送前请检查最终文件。

Computer 还可通过代码对大型表格或结构化文件的每一行进行精确计算，只返回简洁答案，而不返回原始数据。中间文件保留在临时工作区，并明确要求 Agent 返回最终文件或文本。

## 网络和密钥

外网访问受工作区域名允许列表控制。管理员可以添加完整域名或通配子域名。若管理员启用了按需访问，Agent 可以请求当前 Computer 会话临时访问某个域名；这不会改变工作区允许列表。提示域名被拦截，与第三方服务返回 401/403 不同；后者通常表示凭据或提供方权限有问题。

管理员可以提供非敏感环境配置。凭据应放入 HTTPS Secret，并限制可接收它的域名。Computer 看到的是占位值而非密钥原文；不要把 API 密钥粘贴进提示词或保存为普通环境变量。配置在 Computer 启动时载入，已有会话不一定能看到后来修改的值。

## 输出和持久化

Computer 工作区是临时的。请 Agent 将完成的 `.xlsx`、`.pptx`、PDF 等附件返回到会话；或通过相应的第三方工具保存到已连接位置。只留在临时工作区中的文件不是共享的持久文件。打开返回的成果，检查公式、排版、分页和重要数字后再依赖或分享。
