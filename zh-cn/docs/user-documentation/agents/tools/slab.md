# Slab

Slab 工具提供授权 Slab 工作区中帖文、主题和搜索结果的只读访问。未分享给连接集成的私有主题或帖文，Agent 仍无法访问。

管理员从 **Spaces → Tools → Add Tools** 添加 Slab，授权目标工作区，并将工具分享给应当使用它的 Space。将 Slab 加入 Agent 后，先搜索一个主题，再读取一篇已知帖文。确认连接身份和主题分享设置。

搜索结果缺少预期帖文时，检查集成是否有权访问该主题，以及用户本身在 Slab 中的访问权。不要认为添加工具就自动获得整个工作区的所有内容。该工具为只读；若需要对选定知识集合进行同步搜索，可使用 Slab Connection。

## 可用操作

只读操作包括 **Get Post**、**List Posts**、**Get Topic**、**List Topics** 和 **Search**。可先搜索主题或列出帖文，再读取目标内容。未分享给集成的私有主题不会出现在结果中。
