# 图片生成

Image Generation（图片生成）可让 Agent 根据文字提示创建图片。在支持的情况下，还能使用参考图片保持视觉方向，并生成多个版本供选择。具体画质和宽高比选项会显示在图片工具中，可能因模型或工作区而异。

在 Agent 构建器的 **Tools** 区域启用该能力。有效提示应说明主体、构图、风格、色彩、输出尺寸或宽高比，以及必须保持一致的细节。使用参考图时，指出哪些元素应保留、哪些可以调整。除非用户有权使用，否则不要提供私密或受版权保护的源材料。

检查生成图片中的文字是否准确、是否出现不需要的元素、视觉风格是否一致，以及是否适合预期用途。制作系列图片时，使用相同参考图并明确描述重复风格。生成结果只是视觉草稿，不会自动验证品牌、事实或授权要求；发布前请逐张检查。

## 输出设置

生成界面可能提供 1K、2K、4K 等画质尺寸，以及 1:1、3:2、2:3、4:3、3:4、4:5、5:4、16:9、9:16、21:9 等宽高比。请使用当前模型实际显示的选项。会话预览可能经过压缩；检查细节时应下载原始尺寸文件。

生成时可以引用先前输出或上传图片以保持视觉连续性，也可以并行创建多个相关图片。请明确说明哪些部分必须保持一致、哪些可以变化。生成图片可能带有来源水印，并受内容过滤规则限制；不支持的请求可能会被拒绝。
