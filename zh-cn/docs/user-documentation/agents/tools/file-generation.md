# 文件生成

File Generation（文件生成）可让 Agent 根据回答创建可下载文档，或将提供的内容转换为支持的格式。常见输出包括 PDF、Word、Excel、CSV 和演示文稿；当前会话中的工具会显示实际可用格式。

在 Agent 构建器的 **Tools** 区域启用该能力，并说明要生成的文件、使用者和结构。对于电子表格，请指定工作表名称、列、公式、计量单位以及是否保留源数据。对于演示文稿或文档，请说明读者、篇幅和章节。

Agent 可以创建新文件或转换现有格式，但转换不保证公式、排版、媒体内容和格式都能保留。分享前请打开下载文件，检查内容、公式、链接、分页和尺寸。如果结果不完整，应补充源文件范围和输出要求，不要默认第一次生成的文件即可交付。
