# Canva

Canva AI Connector 可让 Agent 查找已有设计；在 Canva 组织启用后，也可能创建、编辑、套用模板或导出设计。具体能力取决于账号方案、组织控制项、模板权限及授权身份。

## 连接 Canva

Canva 管理员先在组织的 **Controls and permissions** 中启用 AI Connector。然后在工作区工具列表添加 Canva MCP 工具，使用目标 Canva 账号完成 OAuth。回调和字段以当前连接表单显示为准；只向需要该工具的 Space 分享。

将工具加入 Agent 后，先搜索或读取一份已知设计。创建、调整尺寸、套用模板或导出时，说明目标文件夹或设计及输出格式，并到 Canva 中检查结果。如果工具不可用，确认管理员已启用 Connector，且授权账号有权访问相应设计或模板。
