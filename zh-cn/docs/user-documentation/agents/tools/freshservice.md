# Freshservice

Freshservice 工具可处理工单、工单任务、服务目录申请、解决方案文章、审批、部门、请求者、值班表、SLA 策略及相关记录。部分操作会创建公开回复、提交申请或修改记录，应从最小权限范围开始。

## 连接服务

使用 Freshservice 的 **Agent** 角色账号，不要用 Requester。先确认该角色能访问所需区域：Tickets、Service Catalog、Knowledge Base 和 Approvals。在 **Spaces → Tools** 中添加 Freshservice，按表单要求输入 Freshservice 域名和组织网址，再以该 Agent 账号完成 OAuth。将工具分享给合适的 Space，并加入 Agent。

先列出并读取一条已知工单，再查看可用字段定义，然后才创建或更新工单。内部备注仅供工作人员查看；公开回复会发送给请求者。提交服务申请前，先检查目录项字段和审批要求。数据缺失时，检查 Agent 角色、字段可见性、租户网址和第三方服务限制。

## 工具类别

Freshservice 工具集包括工单列表、读取、创建、更新、内部备注和公开回复；工单任务的列出、新建、更新和删除；服务目录类别/项目列表、搜索、详情、字段查询和申请提交；解决方案类别/文件夹/文章列表，以及文章读取和创建；工单审批的列表、详情和申请；部门、产品、请求者、值班表、SLA 策略、采购订单和预设回复查询；以及工单读写字段发现。创建或更新前先查第三方当前字段定义。仍受 Freshservice 的请求限额约束。
