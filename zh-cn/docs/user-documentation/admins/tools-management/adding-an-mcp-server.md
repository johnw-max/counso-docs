# 添加远程 MCP 服务器

远程 MCP 服务器通过 Model Context Protocol 向 Agent 提供第三方工具。Counso 作为 MCP 客户端连接服务器，工具及其权限由服务器提供方管理。

## 添加并分享服务器

1. 打开 **Spaces → Tools → Add Tools → Add MCP Server**。
2. 填写提供方或集成负责人给出的服务器名称和端点网址。保存前核对服务器身份和传输设置。
3. 选择服务器支持的认证方式：Automatic OAuth、Bearer token 或 Static OAuth。具体服务器可能只支持其中部分方式。
4. 使用 OAuth 时，在提供方注册客户端时，应采用 Counso 表单中显示的回调地址，不要复制其他环境的回调。使用 Bearer token 时，将提供方令牌存入受保护的凭据字段；不要写进 Agent 指令。
5. 保存服务器并完成授权，检查可用工具，只分享给需要它们的 Space。
6. 将所需工具加入 Agent，并先对一条已知记录执行读取，再考虑开放写入操作。

## 认证方式

**Automatic OAuth** 适用于服务器支持标准发现流程的情况；用户可在浏览器中授权第三方账号。**Bearer token** 适用于第三方提供了带权限范围的令牌。通过该服务器发出的调用会使用令牌所代表的第三方账号，不会自动切换成每位 Counso 成员自己的身份。如果成员需要分别使用自己的第三方账号，可为每人单独配置服务器，并且只分享给该成员的 Restricted Space。**Static OAuth** 适用于管理员需要手动填写客户端 ID、密钥、授权网址、令牌网址、权限范围或令牌端点认证方式的应用。

## 自建服务器检查

自建 MCP 服务器应使用稳定的 HTTPS 端点，说明工具名称及其副作用，并将第三方凭据限制在最低必要权限。按当前表单核对认证和网络要求，授权后确认预期工具确实出现。连接成功界面本身不能证明工具有权读取目标第三方记录；测试写入后，应回读同一记录进行验证。
