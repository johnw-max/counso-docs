# 工具的个人与共享凭据

工具凭据模式决定由哪个第三方身份执行操作，以及使用谁的权限。第三方可能同时支持个人凭据和工作区共享凭据，也可能只支持其中一种。请以当前工具设置表单提供的选项为准。

**个人凭据**让每位用户授权自己的账号。第三方系统可将操作归属到该用户，返回结果遵循其第三方访问范围。即使采用个人凭据，管理员仍可能需要先完成应用设置或管理员同意，之后用户才能分别连接。

**共享凭据**使用管理员配置的一套账号，供所有获准使用该工具的人共用。这种方式设置更简单，但共享账号可能比任何单个用户都能看到更多数据。只向必要的 Space 和 Agent 开放，并明确凭据轮换与撤销的负责人。

选择模式时，确认谁对第三方操作负责、不同用户是否应有不同权限、需要访问哪些资料，以及如何撤销访问。无论哪种模式，仍要通过 Space 和 Agent 控制使用范围。连接账号或成员范围变化时，撤销或重新授权，并重新检查一条已知记录。用户通常可在个人资料的已连接工具区域断开个人授权。
