# 管理智能体

在智能体管理页面查找和整理自己可以访问的智能体。列表可搜索和筛选，例如查看自己能编辑的智能体，或工作区提供的默认智能体。

## 打开和编辑智能体

从主页打开 **Manage Agents（管理智能体）**。选择一个智能体，查看其说明、配置、编辑者、标签和访问范围。管理员可以以只读模式打开任意智能体；如需修改，可在提示横幅或 **Editors & Access（编辑者与访问）** 区域选择 **Become an editor（成为编辑者）**，将自己加入编辑者列表。然后即可编辑并保存。

修改智能体前，先检查它使用的数据源和 Space。工具或受众变更可能同时影响数据访问范围和可使用智能体的人。

## 创建和分配标签

标签可以帮助成员按用途、团队或工作流程查找智能体。管理员可打开 **Manage Agents > Tags > Manage Tags（管理智能体 > 标签 > 管理标签）**，创建、重命名或删除标签，并查看哪些智能体使用了该标签。如果尚无标签，工作区可能会根据现有智能体给出建议。

标签准备好后，可在智能体列表中分配。保持标签命名一致，方便成员搜索和筛选目录。

Skill Builder 中也可能提供相同的 **Become an editor** 操作，用于编辑 Skills。
