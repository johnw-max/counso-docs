# 订阅与账单

Counso 当前订阅决定工作区可用的功能、成员容量、用量控制和账单条款。请核对本工作区显示的方案和条件；不同客户的订阅可能不同，旧版产品说明也不一定适用。

## 查看当前订阅

工作区管理员可打开 **Admin > Billing**，查看当前工作区提供的订阅信息。页面可能显示方案或合同、续订日期、付款资料、发票和订阅管理选项。具体内容取决于工作区和管理员的账单权限。

方案名称、包含的席位、连接器、Space、用量额度、限制、税费和续订条件均因订阅而异，请以当前订阅摘要或与 Counso 签订的协议为准。

## 开通或更改订阅

如果账单页面提供更改方案或结账选项，请在确认前查看完整摘要。核对所选方案、席位数量与类型、计费周期、生效日期、税务或公司信息，以及应付总额。如果表单支持企业付款，请填写与登记信息一致的法定公司名称和税务资料。

新增或移除席位、更改方案或调整计费周期，都可能影响访问权限和费用。请阅读确认信息和账单预览，核对生效日期及任何按比例调整。条款不清楚或所需选项不可用时，确认前先联系工作区账单负责人或 Counso 对接人。

## 管理付款资料与发票

如果当前角色可以使用这些功能，可在 **Admin > Billing** 查看或更新付款方式、下载发票。保持账单联系人资料有效，确保订阅通知发送给合适的负责人。只有具备账单管理职责的管理员才应更改付款信息。

## 取消、续订或重新启用

取消和续订方式由 Counso 当前订阅及合同约定。安排取消前，核对结束日期，并阅读页面对成员、已连接数据源、Agent、对话和已上传文件后续状态的说明。不要默认取消后会删除数据、保留所有功能，或让所有连接继续可用。

如果准备停止使用 Counso，请在订阅结束前导出所需记录或文件，并确认连接的第三方系统状态。重新启用订阅时，使用 **Admin > Billing** 中显示的选项，或联系工作区账单负责人。如需删除工作区或其数据，请向 Counso 确认适用的数据保留或删除流程，并在不可逆删除前取得明确确认。

席位分配和用量访问见[席位管理](../usage-seats-and-credits/seat-management.md)；余额及限额见[积分管理](../usage-seats-and-credits/credit-management.md)。
