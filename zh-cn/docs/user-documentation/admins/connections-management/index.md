# 管理数据连接

数据连接将外部平台的指定内容同步到 Counso，供助手检索。打开一个 Space，选择 **Connections**，再选择要连接的平台。管理员完成授权后，选择需要同步的内容。

尽量固定连接账号及其权限；账号访问范围变化会影响连接能获取的资料。同步后，将数据源分配到合适的 Space，并在助手的知识设置中选用。

按平台查看具体说明：

- [Google Drive](google-drive.md)
- [Notion](notion.md)
- [Confluence](confluence.md)
- [GitHub](github.md)
- [Microsoft](microsoft.md)
- [Slack](slack.md)
- [Intercom](intercom.md)
- [Zendesk](zendesk.md)
- [Gong](gong.md)
- [Snowflake](snowflake.md)
- [BigQuery](bigquery.md)

数据连接负责同步知识。如果还需要在外部平台创建或修改记录，请另行配置对应的助手工具。
