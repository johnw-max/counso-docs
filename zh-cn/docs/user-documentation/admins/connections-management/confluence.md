# 连接 Confluence

将指定的 Confluence 全局空间接入后，助手可以检索团队文档。私人空间和存在查看限制的页面不会同步；受限页面的下级页面也不包含在同步范围内。

## 选择账号和空间

1. 指定一位同时拥有 Counso 管理权限、并能访问所需 Confluence 全局空间的管理员。
2. 打开 **Spaces > Connections**，选择 Confluence 并完成授权。
3. 勾选需要同步的全局空间，然后保存。

尽量由同一个账号维护连接。换用不同账号重新授权，可能改变能访问的内容范围。调整所选全局空间时，无需重置整个连接。

## 更新连接

打开已有连接，可增减空间或重新授权。修改连接账号权限前，先检查相关助手是否依赖受影响的内容。选择一个空间并不会绕过页面本身的查看限制。

所选空间的修改可能在几秒到几分钟内出现；连接也会大约每小时检查新增和更新内容。页面缺失时，请检查空间是否选中、页面及其父页面是否受限、连接账号是否有权限，以及最近一次同步状态。

## 按标签搜索

Confluence 的自定义标签名称会随文档同步，可在[知识搜索工具](../../agents/knowledge/search-data-sources.md)中用于筛选。请使用 `deprecated` 这类可读标签名称，而不是旧的数字标签标识。
