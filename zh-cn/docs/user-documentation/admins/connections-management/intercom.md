# 连接 Intercom

Intercom 连接可同步帮助中心文章和已关闭的会话。配置人员需要 Counso 管理权限，以及 Intercom 中安装、配置和删除应用的权限。

## 选择同步范围

在 **Spaces > Connections** 中选择 Intercom，完成授权后，选择需要同步的团队和帮助中心顶层集合。首次保存需要准备权限和内容，可能花费较长时间。

会话范围选择 **Conversations** 时包含所有团队；如果只选择部分团队，则只同步归属于其中任一团队的会话。会话还必须已经关闭，并且在过去 90 天内创建。

帮助中心只同步所选顶层集合中已发布的文章。

## 包含哪些内容

会话内容包括消息、作者姓名、备注、标签和来源。可以在连接配置中关闭备注同步；如果内部客服备注不应进入助手知识范围，请检查这一项。

文章同步标题和正文，不包含草稿或未发布文章。

## 更新与标签

增减团队或集合后，会启动对应内容的同步或移除，完成时间取决于资料量，可能需要几分钟。已授权团队中新关闭的会话，会在收到 Intercom 通知后处理，通常为几秒。帮助中心每小时刷新一次，因此新文章最多可能等待约一小时。

会话自定义属性会形成 `attribute:name:value` 标签，普通标签使用 `tag:name`。助手可利用这些标签进行[知识搜索筛选](../../agents/knowledge/search-data-sources.md)。
