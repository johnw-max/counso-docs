# 排查 Slack 集成问题

Slack 功能使用集成中的不同部分。先确认问题属于消息同步、Counso 交互应用还是 Slack Tool。安装其中一项并不会自动启用其他部分。

| 组件 | 用途 | 优先检查 |
|---|---|---|
| 数据同步应用和连接 | 加入选定频道，并让智能体使用同步后的消息 | 应用是否已加入频道？频道是否被选中并同步到预期 Space？ |
| Counso 应用 | 让成员直接从 Slack 调用智能体 | 集成是否启用、应用是否已加入频道、是否在支持的频道中提及应用？ |
| Slack Tools | 让智能体搜索 Slack 或执行操作 | Slack Tool 是否已连接并添加到智能体？实际执行操作的 Slack 身份是谁？ |

## 频道未显示或未同步

- **看不到私密频道：** 将数据同步应用添加到该私密频道，再刷新连接中的频道列表。私密频道在有权限的成员添加应用前不会对集成开放。
- **频道可见但未同步：** 应用已加入频道不等于频道已加入同步范围。在 **Spaces > Connections > Slack** 中，将频道加入连接并指定目标 Space。如果已选中，保存一次变更后重新检查同步状态。
- **看不到较早的消息：** 新加入的应用可能只能接收加入频道之后的消息。请检查频道集成记录以及服务提供方当前的同步行为。
- **权限列表无法加载：** 确认 Slack 账号有权管理应用和频道。如果工作区频道较多，初次加载可能需要时间；待加载完成后重试。
- **智能体不能使用频道内容：** 检查同步数据进入哪个 Space，以及智能体和使用者是否都能访问该 Space。

## Counso 应用没有回复

确认工作区设置中已启用 Slack 集成、应用安装在预期 Slack 工作区，并且已加入相关频道。在同一条消息中提及应用并写出问题。如果工作区集成不支持私信，请在频道或线程中使用。

应用通常只能获得提及它的线程内容，而不是整个频道历史。请在消息中补充相关背景，或在包含讨论内容的线程里提及应用。要调用具体智能体，可使用 Agent 选择器或工作区配置的语法，例如 `@Counso +agent-name`。公开频道可能可以设置默认智能体；私密频道则可能需要明确选择智能体。

如果希望智能体不经提及自动回复，需要工作区管理员为该智能体和频道启用自动回复。检查该设置是回复全部消息还是仅回复顶层消息。

## Slack Tool 缺失或身份不正确

- **Agent Builder 中没有工具：** 打开 **Spaces > Tools > Add Tools**，选择 Slack 并完成个人授权，然后将 Tool 添加到智能体。
- **搜索结果不全：** 检查智能体可用的是语义搜索还是仅关键词搜索。关键词搜索时，尝试精确词语和不同表述。
- **操作显示为你的名字：** 个人 Slack 连接会以授权用户身份执行操作。如果需要机器人身份，请检查工作区是否提供 Slack Bot Tool；机器人只能在已邀请它的频道操作。
- **操作被拒绝：** 确认当前 Slack 身份有权执行该操作并访问目标频道。

## 设置或授权失败

安装或管理 Slack 应用可能需要 Owner、Admin 或 App Manager 权限。新应用处于待审批状态时，请 Slack 管理员在组织的应用请求区域检查。创建或编辑 Slack 应用时，按工作区当前的 Counso 配置指引操作；除非指引要求，不要修改 OAuth 范围、回调地址或签名凭据。凭据轮换后，应在已保存的连接设置中同步更新。

对于旧连接，请按工作区当前连接指引确认是否需要更新，不要依赖过期的迁移日期。

## 已知行为

为避免将智能体生成内容当成来源材料，消息同步可能会排除机器人消息。即使同步了多个 Slack 工作区，工作区也可能只允许一个交互式 Counso 机器人。私密频道可能无法设置默认智能体。非线程消息的链接有时只能定位到频道中的大致位置；需要精确上下文和链接时，请使用线程。

## 准备有效的问题报告

问题仍未解决时，请记录操作步骤、预期与实际表现、错误文本、工作区名称、Slack 频道或线程链接，以及问题影响一个人还是所有人。通过组织提供的支持渠道提交。不要附上密码或应用密钥。
