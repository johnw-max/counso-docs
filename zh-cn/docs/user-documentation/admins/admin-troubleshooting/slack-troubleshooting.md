# 排查 Slack 连接与工具问题

先确定涉及哪一种 Slack 能力。数据连接、对话机器人和个人工具使用的凭据与访问设置不同。

| 能力 | 首先检查 |
| --- | --- |
| 消息同步 | 数据同步应用是否安装、选择了哪些频道、目标 Space 和同步状态 |
| Slack 中的智能体回复 | 机器人是否安装并加入频道、是否被提及、回复设置是否正确 |
| 个人 Slack 工具 | 授权的 Slack 账号、频道访问权限，以及智能体是否使用该工具 |

## 找不到频道或消息

私有频道需要有权限的成员先加入数据同步应用，应用才能发现该频道。之后还要在 Counso 连接中选择该频道进行同步。应用加入频道和选择同步，是两个步骤。

检查资料存入的 Space，以及智能体和使用者能否访问。缺少历史消息时，检查连接的历史范围及当前同步状态，不要默认所有消息都已经进入索引。频道很多时，列表加载可能需要一些时间。

## 机器人没有回复

确认机器人安装在正确的 Slack 工作区，并已加入目标频道。在消息或相关会话线程中提及它，写明问题，并通过配置的提及语法或选择器指定智能体。

希望不提及机器人也能收到回答时，需要检查该频道的自动回复设置及所选智能体。回复新频道消息还是线程消息，取决于相关设置。启用数据同步不会自动开启机器人回复。

## 工具使用了错误账号

检查工具授权中的 Slack 身份。个人工具使用所连接用户的权限；使用机器人工具时，还要单独核对机器人加入了哪些频道。必要时用正确账号重新连接，并确认智能体实际调用的是哪个工具。

## 安装或授权失败

Slack 管理员可能需要先批准应用。对于自建应用，请部署管理员核对注册的回调地址、事件地址、相应应用凭据及 webhook 服务。凭据轮换后，要同步更新保存的连接。

问题仍未解决时，向管理员提供错误文字、操作步骤、预期结果和频道或线程链接，报告中不要包含应用密钥。
