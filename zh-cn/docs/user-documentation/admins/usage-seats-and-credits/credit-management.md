# 积分管理

在 **Admin > Usage** 中查看 Counso 当前工作区已启用的用量信息和控制项。可用积分来源、限额、重置日期和账单选项由当前订阅决定。

## 了解可用余额

工作区可能显示成员个人额度、工作区共享池，或两者同时显示。有些订阅还会显示超额用量选项。请按照用量面板显示的顺序和状态，了解一次请求会从哪个来源扣取；不要套用其他计划的限额或超额规则。

如果个人额度和共享池同时启用，当前用量面板会说明扣取顺序。成员个人的支出限额可能用于限制其可使用的共享池额度。请核对限额说明：在仅限制共享池的配置中，它不会减少成员独立的席位额度。

## 查看用量并管理限额

Usage 页面显示工作区余额；如果提供 Members 表格，还可以查看每位成员的席位、已用量和剩余额度。可使用表格搜索或筛选成员，并在有相应控制项时调整席位或个人共享池限额。

根据订阅配置，管理员可能会看到以下设置：

- **Default workspace pool limit：**设置成员默认可使用的共享池额度。设为零可能会阻止成员从共享池取用。
- **Member spend limit：**为某位成员设置不同的共享池额度。检查更改默认值时，是否只影响仍沿用默认设置的成员。
- **Upgrade request：**成员达到限额时可申请更换席位或调整用量。如有此功能，可在 Members 区域查看申请。
- **Automatic seat change：**如页面提供此项，成员达到限额时可能自动升至更高席位。开启前先确认订阅及账单影响。
- **余额和申请通知：**核对当前设置中显示的阈值和通知对象。

如果当前界面提供充值，可增加工作区余额。购买前请在结账摘要中核对金额、价格、有效期及其他条件。

## 自动化活动

如果 Counso 显示某个已启用自动化工作流的独立用量区，请核对负责人、运行频率、预期数量和可用限额。仅使用当前工作区实际显示的控制项和适用来源。

角色与席位的区别见[席位管理](seat-management.md)；交互用量的构成见[用量积分](credits.md)。
