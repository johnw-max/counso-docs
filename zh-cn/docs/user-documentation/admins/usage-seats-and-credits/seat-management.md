# 席位管理

成员的**角色**和**席位**分别控制不同事项。角色决定成员能访问哪些工作区区域和设置；席位决定该成员在当前订阅下可使用的用量容量或积分额度。管理员也可以分配较低用量的席位，权限受限的成员也可能有较高用量的席位。

## 查看可用席位类型

在 **Admin > Members** 或 **Admin > Usage** 中查看工作区当前提供的席位类型。名称、包含的积分和适用条件由 Counso 当前订阅决定；不要照搬其他工作区或旧计划说明。

有些订阅为每位成员分配个人用量，有些则使用工作区共享池。使用共享池的工作区，席位可能决定成员能否使用工作区，而不是提供独立的个人额度。请以 **Admin > Usage** 的当前用量详情为准，并参阅[积分管理](credit-management.md)。

## 分配或更改席位

邀请成员时，如果邀请表单要求选择席位，请同时选择工作区角色和席位。可选项取决于当前订阅和已分配的席位数量。发送邀请前，核对 Counso 显示的席位及账单摘要。

管理员可在 **Admin > Members** 查看成员，并通过成员行或 **Admin > Usage** 中的用量控制管理席位。如果当前工作区采用席位制，未分配席位的成员仍可能列在工作区中，但在分配席位前无法发送消息或与 Agent 交互。更改角色或重新邀请前，先查看成员状态和产品提示。

席位更改的生效时间可能不同，也可能影响下一张账单。确认面板会显示访问权限何时变化、是否立即生效以及可能的账单调整。确认更改或移除席位前，请先阅读该摘要。

## 升级申请

如果 **Admin > Usage > Settings** 中显示 **Upgrade request**，管理员可以开启此功能，让达到用量限制的成员申请其他席位，而不是直接被阻止且没有后续选项。如有此功能，可在 Members 区域的 **Requests** 标签中查看待处理申请。批准前，结合成员的工作需要和 Counso 显示的费用影响进行判断。

## 计费周期与未分配席位

如果当前订阅提供按月或按年计费选项，两种方式在新增或取消分配席位时可能适用不同规则。请在订阅摘要中确认计费周期、生效日期、按比例调整情况，以及释放的席位是否可以重新分配。离职成员的访问权限和相关席位额度由当前订阅条款决定。

工作区余额、限额和个人用量请参阅[积分管理](credit-management.md)。
