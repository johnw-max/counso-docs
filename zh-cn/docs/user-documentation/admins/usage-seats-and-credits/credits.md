# 用量积分

用量积分用于衡量 Counso 工作区中的 AI 功能使用情况。一次消息可能会产生模型处理用量，也可能因资料检索、文件生成或连接工具等操作产生额外用量。具体消耗取决于实际任务和当前工作区配置。

## 哪些因素会影响用量

可以先按以下方式理解一次交互：

`交互用量 = 模型处理用量 + 适用的操作用量`

模型用量会随模型处理的文字和资料量、所选模型及推理设置而变化。Agent 使用工具或其他计量能力时，可能产生操作用量；具体金额取决于该能力和当前配置。一次请求若触发后台 Agent 或其他 Agent 运行，也可能计入总用量。

如果产品提供交互用量明细，可在对话中查看已完成操作的消耗。核对明细，了解请求是否使用了模型处理、工具或额外的 Agent 运行。请以 Counso 当前页面显示的用量说明和费率为准；不同工作区的费率和额度可能不同。

## 积分分配与重置

积分额度、席位名称、重置日期和结转规则由当前 Counso 订阅决定。成员可在 **Admin > Usage** 或账号用量详情中查看当前余额。工作区管理员说明个人可用额度时，应以现行订阅及页面显示的数值为准。

个人积分与工作区共享池是不同来源。成员能否同时使用两者，以及用量扣取顺序，取决于工作区配置。参阅[积分管理](credit-management.md)和[席位管理](seat-management.md)。

## 合理使用积分

评估积分用量时，也要结合完成的工作。明确任务范围有助于减少重试和无关检索；需要深入调查时，较强模型或更全面的分析也可能是合理选择。实用建议见[优化积分使用](optimize-credit-consumption.md)。
