# 请 Agent 检查图片

图片附件可让 Agent 结合当前任务和它有权访问的知识，分析视觉材料。常见用途包括阅读截图、按品牌规范检查设计、分析商品图片，或发现两份文档中的可见差异。图片理解效果取决于 Agent 所选模型的能力和文件清晰度。

在会话中附加清晰图片，并说明检查目标及应参考的资料。例如，检查品牌规范时，请提供当前规范，并要求逐项指出图片中的位置和对应条款。处理收据或扫描件时，请它转录清晰可辨的字段，并将不确定之处标出来，不要自行补值。

好的检查应区分观察和判断：先描述看到的颜色、文字、对齐或物体，再说明与规范的差异。让 Agent 标出无法辨认的区域，不要推断图片中没有呈现的信息。采取行动前，应对照原图或源文件复核重要尺寸、文字和合规结论。

Agent 无法读取图片时，先确认所选模型支持视觉输入，且文件未超过上传限制。分辨率过低、裁切、旋转或模糊的图片，可能需要重新提供清晰版本。
