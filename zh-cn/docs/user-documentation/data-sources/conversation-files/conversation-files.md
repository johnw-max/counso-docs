# 会话文件

Agent 需要临时参考某些材料时，可将文件附加到当前会话。Agent 可以读取支持的文档、分析表格；所选模型具备视觉能力时还可查看图片；也可以转录音视频，或据此生成新文件。会话附件仅属于当前会话，不会进入工作区搜索，也不会自动出现在其他会话中。

上传界面说明的常见大小限制为：图片 5 MB、音频 25 MB、文档和代码 50 MB、CSV、TSV、XLS、XLSX 等分隔或表格文件 50 MB。不同工作区支持的格式和限制可能不同，请以附件控件显示为准。

为了获得可核对的结果，请说明要检查什么、相关页码或工作表、日期范围、所需字段或计算规则，以及输出格式。例如，请 Agent 比较两份制度并列出有变化的条款及页码和章节；或汇总指定工作表，同时保留原币种并说明排除的行。

分享前将回答与原文件核对。若后续还要复用材料，请将它保存到适合的共享位置并设置正确的访问范围。在会话中生成文件并不代表它已保存到共享 Folder 或第三方网盘。
