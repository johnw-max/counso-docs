# 数据源与工具

Agent 可以从不同位置获取资料和能力。**Connection（连接）**会同步选定的第三方资料，供检索使用；**Tool（工具）**使用获授权的身份，实时查询或操作第三方系统；**网站数据源**抓取公开网页；**Folder（文件夹）**保存上传的文档或表格；直接附加到会话的文件，则只为该会话提供临时上下文。

按工作方式选择入口：需要持续检索选定资料时用 Connection；需要查询最新记录或执行操作时用 Tool；需要收录公开网页时用网站数据源；需要维护一组上传材料时用 Folder；只处理一次性任务时直接附加文件。这些入口的权限和更新方式各不相同。添加数据源不会自动授予工具权限，添加工具也不会让整个第三方系统变成可搜索资料。

工作区管理员或 Space 构建者负责配置共享数据源。使用结果前，先确认目标 Space、资料范围、实际授权身份和最近更新时间；再请 Agent 查找一条已知资料，并与第三方系统核对。
