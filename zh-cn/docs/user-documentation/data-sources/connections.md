# Connections（连接）

Connection 会将管理员在第三方系统中选定的资料同步到 Space，供 Agent 检索。配置时要分别决定两件事：同步哪些记录，以及哪些人可以使用。先选定文件夹、频道、站点、页面、项目或其他资料范围，再把连接分配给目标 Space。如果资料只应向特定成员开放，就使用 Restricted Space。

完成授权后，首次同步可能需要几分钟。查看同步状态，再请 Agent 查找一条已知且不敏感的资料。将返回内容、来源位置和可见范围与第三方系统核对。资料缺失时，依次确认它是否已选中同步、连接账号是否能访问、连接是否放在正确的 Space，以及刷新是否完成。先查明是哪一层导致缺失，再决定是否调整范围。

Connection 用于同步和检索资料，不会让 Agent 实时操作第三方系统；要执行这类操作，需要另外配置 Tool。反过来，Tool 的凭据也不会自动让第三方系统的全部内容变得可搜索。
