# Folders（文件夹）

Folder 用于集中保存上传的参考资料，并将其作为来源提供给 Agent。管理员和 Space 构建者可从 **Spaces → Folders** 创建文件夹。名称和说明应写明主题、负责人、日期范围和包含的资料，帮助 Agent 判断何时使用。

Folder 主要保存两类材料：

- **文档**，如 PDF 和文本文件，可用于搜索与提取。PDF 会转换为文本；复杂表格和嵌入图片不一定能完整提取。
- **表格**，通常为 CSV，可通过表格查询能力进行结构化分析。

手动上传到 Folder 与直接附加到会话的文件，大小限制不同。界面会显示当前适用限制；原始说明给出的参考值是 Folder 手动上传 30 MB、会话附件 10 MB。准备大文件前请以当前界面为准。

Folder 的访问范围由所在 Space 决定，不会自动对每个 Agent 开放。请将相关 Folder 加入 Agent 的知识配置，再验证它能找到一条已知记录。Folder 不会同步原文件后续的修改；源文件更新时，需要替换或更新 Folder 中的内容。
