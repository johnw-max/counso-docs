# 使用 Pod 文件

**Files** 区域是 Pod 的共享资料库。上传的文件、链接的公司资料以及助手生成的文件都可供成员使用，助手也可以搜索它们。

## 开始前

先准备源文件，并决定 Pod 需要副本还是实时链接。需要稳定快照时上传副本；源文件应由中心位置管理时链接公司数据。

## 添加和整理文件

1. 打开 Pod，选择 **Files**。
2. 选择 **Add**，再选择 **Upload file**。选择文件，或将文件拖入列表。
3. 需要整理时选择 **Add > New folder**，输入文件夹名称，再通过拖放或文件菜单移动文件。
4. 要链接共享公司资料，选择 **Add > Add from Company Data**，选择页面或文件夹并保存。
5. 点击文件可预览。通过文件菜单重命名、移动、删除上传文件或移除链接项。

助手也可以通过已启用的连接器取得资料并保存到 Pod。请说明结果是快照还是转换后的副本，并在文件名或说明中保留来源名称和日期。

## 保持经常变化的文件最新

对于周报等持续变化的文件，可以要求助手按计划重新取得来源并覆盖同一个 Pod 文件。先确认连接器能读取来源，且助手有权限写入 Pod。创建一个相似名称的新文件不等于更新原文件。

## 完成后应看到什么

文件会出现在共享列表中，拥有权限的成员可以打开。链接数据会显示链接状态，并从受管理的来源读取；上传文件是 Pod 中的副本。已建立索引的材料可被助手自动使用；未建立索引的格式可能需要在对话中直接引用。

## 常见问题

### 为什么不能链接私有来源？

Pod 链接必须保证所有成员都能读取。可以上传经过批准的副本，或把工作放入成员具备相应来源权限的 Pod。

### 为什么源文件变化后没有立即显示？

索引或同步可能需要时间。检查来源，等待下一次更新；需要精确当前内容时，让助手直接读取原始来源。

### 生成文件是否等于正式来源？

不等于。请明确标注生成或转换文件。权威来源仍保留在其所属系统，Pod 文件用于协作或明确标注的快照。
