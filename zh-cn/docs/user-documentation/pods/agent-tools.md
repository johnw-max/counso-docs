# 智能体在 Pod 中可以做什么

智能体可能能够在当前 Pod 中协助工作，但仍受自身配置和当前用户权限约束。可用操作可能包括查找可访问的 Pod、读取或发布对话、搜索 Pod 知识、处理任务以及创建或更新文件。

## 常见操作

| 工作区域 | 智能体可能执行的操作 |
|---|---|
| Pod 信息 | 查看 Pod 用途和可访问成员；某些配置允许 Editor 更新 Pod 信息。 |
| 对话 | 在有权限的位置新建对话或追加消息。 |
| 知识 | 搜索智能体获准访问的共享文件和对话。 |
| 任务 | 在相应能力已启用时创建、指派、更新、启动或完成任务。 |
| 文件 | 在文件访问已启用时读取、创建或更新 Pod 文件。 |
| 共享展示 | 仅在具备相应能力和角色时创建或固定 Frame。 |

具体能力以智能体配置和可查看的操作记录为准。不要假设每个智能体都拥有以上所有权限。

## 权限仍然有效

智能体不会因为能够搜索 Pod，就自动获得受限 Pod 的访问权。它只能使用当前用户有权访问且在自身数据范围内的 Pod。修改成员、设置或共享内容需要相应角色和能力。

允许智能体写入前，说明它可以修改哪份文件、任务或对话，以及哪些内容不能改。完成后到 Pod 检查结果。智能体执行操作不等于外部审批、付款、过账或消息已发送。
