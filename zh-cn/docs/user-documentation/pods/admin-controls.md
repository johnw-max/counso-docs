# 工作区管理员的 Pod 设置

工作区政策可能影响谁能创建 Pod、可选择哪些可见性，以及成员能否添加文件。管理员应检查自己工作区中实际提供的设置；控件名称和选项可能不同。

## 检查可见性选项

决定成员能否创建开放 Pod，或新 Pod 是否应默认或按政策限制为受限范围。开放访问可能使更广泛的工作区成员看到对话和文件。客户、财务、人事或内部底稿应采用满足需要的最小成员范围。

更改工作区政策后，不一定会自动调整所有已存在的 Pod。政策变更后，还要单独检查已有 Pod 和成员。

## 检查文件添加规则

如果工作区提供手动添加 Pod 文件的政策设置，应确定谁能上传文件或添加链接资料。限制更严格有助于集中管理来源；开放成员添加则便于协作，但需要明确的资料处理规范。

告知成员允许使用的文件类型和来源、权威副本由谁维护，以及如何更正。Pod 文件夹用于整理，不能隐藏文件以限制其他成员查看。

## 沟通并验证变更

更改设置前，先识别受影响的 Pod 和负责人。保存后打开一个代表性 Pod，确认其创建或文件控件符合预期。不要仅凭按钮隐藏或设置改名，就认定访问控制已生效；还要检查现有内容对谁可见。
