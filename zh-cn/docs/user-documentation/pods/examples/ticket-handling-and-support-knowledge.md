# 示例：在 Pod 中协作处理支持案例

支持团队可以使用 Restricted Pod 协作审查案例，并随手查阅获准的排查资料。添加任何工单内容前，先明确哪些角色可以查看客户详情。

## 创建案例空间

1. 为支持团队创建 Restricted Pod，并指定负责人。
2. 将已批准的帮助文章、升级规则和已知问题放入 **Files**。
3. 对需要调查的案例创建任务，只加入必要的引用和明确的下一步。
4. 让智能体根据其可访问资料总结证据、建议检查和待确认问题。

## 复核案例

支持专员核实诊断，并确认回复符合当前指引。专员通过获准的支持系统修改和发送回复，再把已验证的解决办法记录到对应知识库。Pod 可以留存协作过程，但不应成为未经管理的第二份客户数据库。

自动接收工单、分派任务或对外发送回复，需要专门启用的工具和经过测试的流程。客户沟通和敏感变更应保留人工复核。
