# 示例：每位客户使用一个 Pod

会计师事务所可为每位客户建立一个 Restricted Pod，适用于客户的协作成员、资料来源或保密边界不同的情况。这样可以集中协作，同时避免不同客户的资料混放。

## 创建客户空间

- 使用双方约定的客户名称，并在说明中注明服务期间或项目。
- 只添加应查看共享工作区的事务所人员和客户联系人。客户不应看到的内部复核记录，应留在单独受限的区域。
- 添加服务简报、约定政策和客户提供的文件，并注明日期和来源。
- 为缺失资料、复核工作和约定的跟进事项创建任务。

## 处理客户提供的资料

让智能体列出收到的文件，在资料可判断时识别期间和实体，并标记缺失或无法读取的项目。负责会计师核实前，不要推测缺少的数字，也不要向客户称资料已处理完成。原件和更正版本应保留可追溯关系。

邀请客户意味着其按 Pod 成员权限查看 Pod 内容；Pod 内的文件夹不会形成对其他成员隐藏的隔离区。如果内部和客户受众不同，应使用不同 Pod，并仔细检查各智能体的数据范围。
