# 示例：项目 Pod

当一个项目的协作成员和资料范围基本固定时，可以为它建立一个 Pod。例如，产品发布团队可以在整个发布周期内集中保存简报、决定、待解问题和交付物。

## 建立项目空间

- 用项目命名，并在说明中写清目标和成功标准。
- 添加负责人、参与者和复核人；若资料不适合全工作区查看，选择 Restricted。
- 将获准的项目简报、路线图和设计资料放入 **Files**。
- 为各项交付创建任务；在已知时填写负责人、预期结果和截止日期。

## 推进工作

用对话讨论并记录决定及其原因。将跟进事项转为任务，并随进展更新状态。定期让智能体依据相关任务或对话，把工作归为已完成、进行中、受阻和未开始。

从项目系统导入事项、处理会议转写或定时生成摘要，都需要已支持的工具和相应配置。检查导入任务是否有重复 ID 和明确负责人。状态摘要只是协作视图，重要日期和完成情况仍应到权威项目系统确认。
