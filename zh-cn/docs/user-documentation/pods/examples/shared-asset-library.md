# 示例：共享素材库

设计、品牌或传播团队可以用 Pod 集中管理经批准、可重复使用的资料。Pod 只应存放目标成员可以共同查看的素材；只有所有工作区成员都可以查看时，才适合使用开放 Pod。

## 创建素材库

1. 创建用途清楚的 Pod，例如“已批准品牌素材”。
2. 将负责维护素材的小组设为 Editor，并选择合适的可见性。
3. 上传获准的标识、模板、写作规范和参考文件。可用 `品牌`、`模板`、`产品图片` 等文件夹整理内容。
4. 在说明中写明当前版本和资料更新联系人。

## 使用和维护

起草报告或内容时，让智能体使用指定的素材文件。工作稿应保存到对应项目 Pod，不要覆盖已批准的母版。素材负责人审核替换版本、移除过期文件；若更新会影响其他团队，应保留简短的变更说明。

## 分享前检查

不要把受许可限制、机密或客户专属文件放进广泛可见的 Pod。确认需要素材的成员均可访问，也确认移除成员后，其他位置不会继续暴露副本。
