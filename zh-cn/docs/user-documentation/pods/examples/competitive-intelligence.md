# 示例：竞争研究 Pod

产品或商务团队可以用 Restricted Pod 整理获准的竞争资料，并准备注明日期的比较简报。Pod 是协作空间，不能证明所有市场动态都完整或最新。

## 创建研究空间

- 添加需要查看研究的团队成员，并指定资料维护人。
- 在 **Files** 中整理获准的产品比较、赢单/丢单笔记、客户反馈和公开资料。
- 记录每项来源的日期、市场范围和已知限制。
- 为产品试用或来源核查创建复核任务。

## 准备比较简报

让智能体针对一个具体问题比较指定竞争对象，例如某项产品能力或买方需求。要求以表格列出观点、依据、来源日期和可信程度，并补充资料缺口及需要实时确认的问题。如果已启用网页检索，应保留原文链接和发布日期，并打开页面核实。

## 保持资料有效

指定人工负责人定期检查有日期的来源并修正过时说法。定时监控或提醒需要启用来源并明确配置；不要假设智能体会在后台持续监控竞争对手。对外分享前，检查保密要求并删除未核实或商业敏感的表述。
