# 示例：内容制作 Pod

活动或编辑项目可以用 Pod 集中保存简报、草稿、意见、审批和发布任务。若其他内容的受众或资料不同，应为不同活动分别建立 Pod。

## 创建内容空间

1. 将已批准的简报、受众、关键信息、术语和品牌规范放入 **Files**。
2. 为每项交付创建任务，例如文章、邮件或活动介绍。
3. 指定撰稿人和复核人，并在任务中说明渠道、格式和截止日期。
4. 让智能体依据指定来源起草内容，并标出没有来源支持的表述。

## 复核和发布

将草稿和反馈保留在任务对应的对话中，方便后续复核者了解修改过程。复核人应在批准前检查事实、链接、图片使用权限和语气。由人员通过正常渠道发布，再将最终链接和日期记入 Pod。

智能体可以帮助把获准文案改短或翻译，但除非已通过合适的工具完成操作并得到目标渠道确认，否则不应发布内容或声称发布成功。内容日历、自动创建复核任务和效果报告属于可选流程，需另行配置工具。
