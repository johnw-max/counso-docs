# 示例：个人知识 Pod

个人 Pod 可以集中存放自己经常使用的笔记和参考资料，便于管理重复工作和后续事项。但它不应成为未经检查的私人文件或连接账号副本集合。

## 创建个人空间

1. 创建一个 Restricted Pod；除非确有协作需要，成员只保留自己。
2. 只添加组织允许存放在此处的政策、笔记和工作文件。
3. 简短说明当前工作重点，以及智能体应如何使用这些资料。
4. 对需要负责人或截止时间的承诺创建任务。

## 实用的每周回顾

让智能体总结 Pod 中未完成的任务和近期笔记，区分已作出的决定与想法，并列出需要你关注的事项。检查后更新任务，并移除或替换过期信息。除非组织允许在 Pod 中保存副本，否则敏感源记录仍应留在获准系统中。

定时摘要或连接邮箱、日历需要相应工具和权限。如果当前没有这些功能，就手动回顾，不要假设 Pod 会在后台自动收集资料。
