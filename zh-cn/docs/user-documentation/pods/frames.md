# 创建和使用 Frames

Frame 是保存在 Pod 中的交互式文件，可以展示仪表盘、报告、状态视图或智能体创建的其他界面。

## 查看并置顶 Frame

在 Pod 的 **Files** 中打开 Frame 预览。Editor 可以将它置顶，让所有 Pod 成员在 **Conversations** 顶部看到它。

横幅高 **280px**，占满 Conversations 标签页的宽度。同一时间只能置顶一个 Frame；置顶另一个会替换当前横幅。可以在 Files 中打开 Frame 的 **...** 菜单并选择 **Pin as Pod banner**，也可以在预览页眉点击 **Pin**。取消置顶可在 Files 菜单中选择 **Unpin Pod banner**、在预览页眉关闭 **Pinned**，或将鼠标移到横幅上点击取消置顶控件。只有 Editor 会看到置顶控件。

横幅控件还可以仅为自己隐藏横幅、重新显示，或全屏打开。隐藏只影响自己；取消置顶会影响整个 Pod。

## 让 Frame 保持更新

Frame 根据生成时的 Pod 数据生成，不会自行更新。若视图中的内容会变化，可以配置智能体使用 wake-up tool 按固定周期运行，读取最新的 Pod 任务、对话或文件，并覆盖同一个 Frame 文件。置顶横幅仍绑定该文件；成员下次打开 Pod 时会看到更新后的版本，不需要重新置顶。

例如，请智能体创建并保存每周状态 Frame，先将其置顶，再在新对话中要求它每周一使用 wake-up tool 读取最新任务和总结，并覆盖这个 Frame。

横幅 Frame 应按固定的 280px 高度设计：展示少量、便于快速查看的共享信息，避免需要纵向滚动的内容。创建或更新后要检查置顶横幅本身，因为它与预览的显示空间不同。

## 以底层记录为准

Frame 展示来自 Pod 内容的信息。重要数值应回到底层任务、文件或连接的系统核对；Frame 上的显示值本身不会更新这些来源。
