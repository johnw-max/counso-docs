# 创建和使用 Frames

Frame 是保存在 Pod 中的交互式文件。它可以利用 Pod 的对话、任务和文件展示仪表盘、报告或状态视图。

## 开始前

先确定一个明确用途和需要展示的数据。置顶横幅应保持紧凑、便于快速浏览。再判断这个视图是生成的快照，还是读取已保存 Pod 记录和任务的配置视图。

## 创建并置顶 Frame

1. 在 Pod 对话中，请能创建 Frame 的助手根据指定的 Pod 来源生成视图。
2. 要求助手将结果保存到 Pod 的 **Files** 区域。
3. 打开 Frame 预览，检查布局、链接和展示数值。
4. 如果所有成员都应在 Conversations 顶部看到它，从文件菜单或预览中选择 **Pin as Pod banner**。
5. 将鼠标移到横幅上，可以仅为自己隐藏、全屏打开；Editor 可以取消置顶。

同时只能置顶一个 Frame。置顶新 Frame 会替换当前横幅。隐藏只影响自己；取消置顶会影响整个 Pod。

## 刷新变化中的视图

普通生成的 Frame 是快照。要更新它，请要求助手读取最新 Pod 数据并覆盖同一个 Frame，然后检查新文件。横幅仍然绑定该文件，每次覆盖后不需要重新置顶。

已配置的数据读取视图可以在打开时，以及选择 **Refresh** 操作时，读取已保存的 Pod 记录和原生 Tasks。它可以根据这些已保存记录更新显示，而不必每次都重写 Frame 源码。这表示视图打开时读取已配置的记录，不表示关闭后仍在后台执行任务。

有业务意义的数值应以底层任务、文件或连接的正式系统为准。Frame 中的勾选或数字只是投影，除非底层记录已保存并可以重新读取。

## 完成后应看到什么

成员打开 Pod 时会看到置顶 Frame，也可以打开完整文件查看细节。快照显示重新生成后的版本；配置的数据读取视图在打开或刷新后显示它能够读取的最新保存记录。

## 常见问题

### 为什么横幅和预览看起来不一样？

横幅和预览使用的显示空间不同。请直接检查置顶视图，并简化在固定高度下被裁切的内容。

### 为什么任务改了，横幅上的数值仍然旧？

对于快照，请重新生成或覆盖 Frame。对于配置的数据读取视图，请选择 **Refresh**，并确认底层任务已保存且可读取。不要把显示值当成底层记录已变化的证明。

### 谁可以置顶或取消置顶 Frame？

Pod Editor 管理共享横幅。Member 可以查看，也可以只为自己隐藏。
