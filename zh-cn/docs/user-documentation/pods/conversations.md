# Pod 对话

Pod 对话为成员提供共享空间，可以向智能体提问、讨论依据并记录决定。若上下文应对该 Pod 的成员持续可见，就在 Pod 对话中开展工作。

## 开始对话

1. 打开 Pod，选择 **Conversations**。
2. 新建对话，说明任务、相关期间或文件，以及期望结果。
3. 希望智能体回复时提及智能体；需要同事关注时提及同事。
4. 保持讨论聚焦；如果后续事项已有明确负责人和下一步，将其记录为任务。

发送前检查 Pod 成员范围，不要粘贴其他成员无权查看的数据源内容。加入共享对话不会扩大成员在源系统中的权限。

## 查找和跟进工作

使用对话列表及可用筛选返回最近或未读讨论。搜索时使用项目、文件或决定的名称，方便团队之后查找。通知设置可能因人而异；需要回复时应明确指定负责人，不要只依赖通知。

## 外部触发或定时活动

如果智能体配置了受支持的触发器，它可能会在 Pod 中创建或更新对话。触发器需要相应连接、权限和明确配置。请将生成的内容视为共享工作区信息，因为 Pod 成员都可能看到。

## 对话不能代替什么

对话是协作记录，不是审批或账务记录。消息写着“已完成”，并不能证明外部系统已接受变更。重要更新应到目标系统核实，并保留确认结果。
