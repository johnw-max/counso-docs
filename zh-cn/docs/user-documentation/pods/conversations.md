# Pod 对话

Pod 的 **Conversations** 标签页列出在该 Pod 中创建的对话，所有 Pod 成员都可以查看并参与。对话会自动建立索引，智能体可以搜索并引用此前的 Pod 讨论。

## 开始对话

1. 打开 Pod，选择 **Conversations**。
2. 编写消息并输入 **@** 提及智能体。
3. 选择智能体并按 **Enter**。对话会在 Pod 中创建，所有成员都能看到。

提及智能体会让它在对话中回复；提及同事会通知对方。如果对方还不是 Pod 成员，界面会提示添加；添加成员仍须满足相应的 Pod 角色权限。

智能体也可以在 Pod 中创建对话、发布进度或分享结果。配置好的触发器或定时 wake-up 可以让智能体通过 Pods skill 找到目标 Pod 并发布相关内容。

## 查找对话

多人 Pod 中可以使用以下筛选条件：

| 筛选项 | 显示内容 |
|---|---|
| **Mine** | 你发送过消息的对话。 |
| **Group** | 有多位参与者的对话。 |
| **All** | Pod 中的全部对话。 |
| **Hide triggered** | 在你自己的列表中隐藏由触发智能体创建的对话。 |

**Hide triggered** 是针对个人和当前 Pod 的偏好设置，不会对其他成员隐藏对话。由触发器创建的对话标题前带有 **⚡**。使用列表上方的搜索框可以搜索整个 Pod 的对话内容。

## 加入 Pod 和设置通知

Open Pod 的 Conversations 底部会显示 **Join the [Pod name] Pod**；点击即可加入并参与。Restricted Pod 不提供加入按钮，需要 Pod Editor 邀请。

每位成员可以分别设置自己在每个 Pod 中的通知偏好。打开 Pod，点击右上角 **...**，再选择 **New conversations：All 或 Never**，以及 **New messages：All、Mentions only 或 Never**。应用内、Slack 或邮件等通知渠道在个人资料设置中统一配置。

Pod 对话用于协作记录。若消息称外部操作已经完成，仍应到相应的源系统核实。
