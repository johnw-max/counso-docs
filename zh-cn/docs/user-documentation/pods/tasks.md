# 管理 Pod 任务

任务是 Pod 中的轻量工作项，为工作提供清晰说明、负责人和状态；它不替代业务交易的正式记录系统。

## 开始前

在说明中写清预期结果、来源材料和需要确认的边界。决定任务应分配给某人，还是暂时不分配。

## 创建并运行任务

1. 打开 Pod，选择 **Tasks**。
2. 选择 **Add a task**，输入说明，并按需选择负责人。
3. 保存任务。初始状态为 **Open**。
4. 将鼠标移到待处理任务上，选择播放操作。添加消息或选择助手，然后启动。
5. 在 **Conversations** 中查看关联对话。任务会变为 **In progress**。
6. 工作完成后标记为 **Done**。仍需继续时，清除完成状态即可重新打开。

可以直接编辑任务文字、重新分配负责人或从菜单删除任务。任务较多时使用 **Mine**、**All** 和说明搜索。

## 与其他项目工具同步

让具备相应项目工具的助手读取未完成事项并创建对应 Pod 任务。持续同步时，为每个字段规定唯一来源，并防止已完成事项在下一次运行中重新创建。开启周期同步前先用少量事项测试。

## 完成后应看到什么

任务会按负责人分组，Pod 成员可看到状态。启动助手会创建关联对话，人员可以查看进度并调整方向。已完成任务会保留，方便查阅历史。

## 常见问题

### Done 代表什么？

代表协作任务完成，不代表付款、过账、审批或外部系统更新已经发生。

### 为什么任务仍是 Open？

说明尚未启动助手，也没有人将它改为进行中。请启动任务或分配给负责下一步的人。

### 为什么同步产生重复任务？

同步说明可能缺少稳定匹配键或唯一来源规则。使用外部 ID 匹配，并在任务中记录外部链接后再运行同步。
