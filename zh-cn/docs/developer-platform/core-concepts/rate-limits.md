# API 速率限制

Counso 会在滚动时间窗口内限制 API 请求量。滚动窗口表示较早的请求离开统计窗口后，额度会逐步释放，而不是所有调用方在同一时刻统一重置。不同操作可能有不同的限制范围，例如按工作区或应用计算。比如，文档 upsert 限制可以按工作区统计，应用运行额度则可以按应用统计。

公开参考中的配置默认值为：数据源每个工作区每分钟最多 120 次文档 upsert；每个应用每天最多 10,000 次请求。工作区或部署设置可能另有数值。设置请求频率前，先确认当前 Counso 环境的限制。超过限制时，请求可能返回 HTTP `429`。

遇到限流时，请降低并发并将剩余请求排队，不要紧密循环重试。按响应中提供的重试提示处理，并同时监控成功请求和限流错误。导入文档时使用稳定的文档 ID，在检查结果后可以更稳妥地重试 upsert。Counso 环境当前公布的限制请参阅 [API 参考](../counso-api-documentation/openapi-and-postman.md)。
