# 获取对话事件

获取指定工作区中某个对话的事件。

```http
GET /api/v1/w/{wId}/assistant/conversations/{cId}/events
```

服务地址：`https://app.counso.ai`

## 认证

在 `Authorization: Bearer <token>` 中传入工作区 API key 或用户 OAuth access token。凭据须由当前 Counso 环境签发，并有权访问目标工作区与资源。

## 请求参数

| 参数 | 位置 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- | --- |
| `wId` | 路径 | string | 是 | 工作区 ID |
| `cId` | 路径 | string | 是 | 对话 ID |
| `lastEventId` | 查询 | string | 否 | 最后一个事件的 ID |

## 响应

| HTTP 状态 | 说明 |
| --- | --- |
| 200 | 对话事件；更多信息请参阅本文档中的 Events 页面。 |
| 400 | 请求错误：参数无效或缺失。 |
| 401 | 未授权：身份验证令牌无效或缺失。 |
| 404 | 未找到对话。 |
| 500 | 内部服务器错误。 |
