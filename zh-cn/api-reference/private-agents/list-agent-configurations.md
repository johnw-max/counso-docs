# 列出智能体配置

会话接口：列出当前用户可访问的工作区智能体配置。

```http
GET /api/w/{wId}/assistant/agent_configurations
```

服务地址：`https://app.counso.ai`

## 认证

此接口需要用户身份：外部客户端通过 `Authorization: Bearer <token>` 传入用户 OAuth access token；已登录的浏览器也可使用 Counso 会话 Cookie。工作区 API key 不能代替用户身份。

## 请求参数

| 参数 | 位置 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- | --- |
| `wId` | 路径 | string | 是 | 工作区 ID |
| `view` | 查询 | string | 否 | 按视图筛选智能体 可选值：`all`, `analytics`, `list`, `favorites`, `published`, `admin_internal`, `manage_unrestricted`, `global`, `workspace` |
| `limit` | 查询 | integer | 否 | 最多返回的结果数 |
| `withUsage` | 查询 | string | 否 | 包含用量统计 可选值：`true` |
| `withAuthors` | 查询 | string | 否 | 包含近期作者 可选值：`true` |
| `withFeedbacks` | 查询 | string | 否 | 包含反馈数量 可选值：`true` |
| `withEditors` | 查询 | string | 否 | 包含编辑者列表 可选值：`true` |
| `sort` | 查询 | string | 否 | 排序顺序 |

## 响应

| HTTP 状态 | 说明 |
| --- | --- |
| 200 | 成功 |
| 401 | 未授权 |
