# Find and manage Skills

Go to **Work** and open **Skills**. The Skills page helps you find reusable packages and see which ones are available to you.

## Find a Skill

1. Use the search field to look for a Skill by name.
2. Choose **All** to see active packages.
3. Choose **Editable by me** when you need to maintain a package yourself.
4. Open **Archived** when you need to check an older package.
5. Use **Show hidden skills** or **All availabilities** when the list needs a broader search.

Read the Skill description and availability before adding it to an Agent. A matching name is not enough: check the task, the information it may use, and whether its tools fit the intended result.

## Maintain a Skill

Use **Create skill** only when you have a clear procedure worth reusing. Give the Skill a focused name and explain its expected input and output. Keep one procedure together rather than combining unrelated tasks. Before making a change available to other people, try it with non-sensitive material and compare the result with the source.

If you cannot see a Skill, check the selected list view, hidden setting, availability filter, and your workspace access. Ask an administrator to check the configuration when the package should be available to you. For the role of a Skill, read [Understand Skills](/en/skills/overview/#understand-skills).
