# Check sources behind an answer

When an answer matters, check the source behind each important claim. A source reference helps you locate the material; it does not make the claim correct by itself.

## A quick check

1. Identify the claim you need to rely on.
2. Open the named source or locate the corresponding passage.
3. Compare the wording, number, date, and conditions with the answer.
4. Check whether the source is the right revision and applies to the requested period.
5. Record a correction or ask a narrower question if the answer does not match.

Pay special attention to summaries that combine several documents. Confirm that the source set is complete and that the answer did not treat an example as a rule. If the answer has no clear source, ask the Agent to identify the material or state that the information is unavailable.

For external actions, also check the destination system. A source reference can support a recommendation, but it is not a receipt that another service accepted a write. Use [Review results](/en/getting-started/review-results/#review-results-before-relying-on-them) to apply the same check to the complete response.
