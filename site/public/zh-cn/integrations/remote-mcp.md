# 添加远程 MCP 服务器

## 添加远程服务器前

工作区管理员应确认服务器负责人、服务器 URL、认证方式、允许的工具、资料目标和停用负责人。只使用组织批准的服务器；不要把密钥写入智能体指令或公开对话。

## 添加服务器

1. 从管理员区域打开工具管理入口。
2. 使用已批准的 URL 和认证方式添加远程服务器。
3. 需要时完成服务商同意流程。
4. 只选择智能体所需的工具和 Space。
5. 用非敏感资源执行一条只读请求，并检查返回的来源和身份。

服务器出现在工具列表中，不代表远程服务已经接受工具调用。对可写工具，执行前要确认，并检查远程回执和对象重新读取结果。

### 选择认证方式

- **Automatic**：输入服务商的 MCP URL，让系统发现配置并启动可用的 OAuth 登录。
- **Bearer token**：填写服务商签发的令牌。调用会使用该令牌所属的账号，因此应核对共享范围。
- **Static OAuth**：先在服务商注册应用，再填写 Client ID、Client Secret、授权地址、令牌地址和所需 scope。把 Counso 设置页生成的回调地址登记到同一个服务商应用。

## OAuth 和允许列表

远程服务可能要求注册客户端、回调、域名允许列表或管理员同意。这些值由服务商决定。使用当前设置页显示的回调、域名和允许列表值。不要复用其他环境的值。服务商改变 URL 或范围后，重新连接并重复只读检查。

## 常见问题

- 服务器保存了但没有工具：检查认证、允许列表，以及哪个 Space 暴露该工具。
- 同意流程循环：把注册回调和客户端配置与服务商当前设置对比。
- 工具返回无权访问：检查远程账号和目标资源，不要只看 Counso 智能体设置。
- 工具改变了外部记录：在报告成功前检查远程回执和稳定 ID。
