# 写清楚请求

清楚的请求能帮助智能体聚焦正确的工作，也让结果更容易检查。把最重要的信息放在请求开头。

## 使用五个部分

1. **任务：** 说明希望完成什么。
2. **上下文：** 提供相关文档、主题、读者或期间。
3. **限制：** 写明必须包含、避免或保持不变的内容。
4. **输出：** 说明所需格式和详细程度。
5. **复核点：** 说明你会检查什么，或什么内容需要确认。

例如：“为新成员总结当前批准的政策。只使用当前政策，列出他们需要采取的三个动作，并写出章节名称。需要管理员确认的内容请标记出来。”

保持一个请求聚焦。如果任务有多个阶段，先让智能体返回第一个可复核结果，再进入下一阶段。写出预期来源，以及你准备与来源对照的结果。

不要要求智能体猜测缺失事实，也不要在没有确认的情况下要求它执行外部动作。收到回答后，先[检查结果](/zh-cn/getting-started/review-results/#在依赖结果前先检查)，再分享或依赖它。
