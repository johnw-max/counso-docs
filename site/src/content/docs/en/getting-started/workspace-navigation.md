# Workspace navigation

Counso AI groups the main workspace experience into **Work**, **Spaces**, and **Admin**. Start from [Counso AI](https://app.counso.ai), then use the top-level tabs. Items vary by account and workspace permissions.

## Work

Use **Work** for day-to-day activity. Work includes:

- **Create a new conversation** and **Conversations** for asking questions and returning to previous work.
- **Agents** for finding and managing configured agents.
- **Skills** for reusable packages of instructions and tools.
- **Pods** for organising related work.

When you start a conversation, check the selected agent before you send your request. The conversation view also exposes a model control and a **Send message** control. Available models and tools depend on workspace configuration and permissions.

## Spaces

Use **Spaces** to organise workspace information and how data is made available. A Space can be open or restricted. Connections and Tools are separate: a Connection authorises access to an external service, while a Tool represents an available action. Check access settings and Agent configuration before using connected data.

## Admin

Use **Admin** for workspace administration, including workspace settings and permissions. If you are not an administrator, ask the workspace owner which setting or access change is appropriate.

## A simple way to find your next step

1. Go to **Work** when you need to ask a question or choose an Agent.
2. Go to **Spaces** when you need to understand where connected information is organised.
3. Go to **Admin** when you need a workspace-level permission, governance, or account setting.

If an item is missing, tell the workspace administrator which area and task you were trying to access. They can check your role and workspace configuration.
