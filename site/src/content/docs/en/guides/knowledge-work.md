# Use an Agent for knowledge work

## Before you begin

Choose Space/sources, audience, date range, and decision; keep confidential material in a restricted area.

## Steps

1. In Work select the Agent and state the outcome in one sentence.
2. Name the source set and time range and ask for citations.
3. Request separate facts, assumptions, and open questions.
4. Check citations; turn the reviewed result into a decision note or task with an owner.

## Result

### Worked example: compare two policies

Input: a travel policy dated 2026-01-01 and an updated policy dated 2026-08-15 in one restricted Space. Ask the Agent to compare only those files, identify changed approval thresholds, and quote the source section. Expected output: a table of rule, affected role, effective date, and citation, followed by open questions.

Reusable prompt:

```text
Compare Policy A (2026-01-01) with Policy B (2026-08-15).
Return changed rule | affected role | effective date | source citation.
Do not infer a date or threshold that is absent; list it under Open questions.

```

A colleague can see what was found, where it came from, and what still needs human judgment.

## Common questions

**Can it answer every connected source?** Only sources in its configured scope and the user's access.

**What if sources disagree?** Show both with dates and owners; the responsible person decides.

**Can a summary become policy?** No. The responsible owner approves policy, legal, financial, or customer decisions.
