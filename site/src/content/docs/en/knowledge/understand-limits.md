# Understand Knowledge limits

Knowledge can improve an Agent's context, but it is not a guarantee of truth. The result depends on the material available to the Agent, the request, the configuration, and the permissions in use.

Keep these limits in mind:

- A missing source can produce an incomplete answer.
- An old or conflicting source can produce a misleading summary.
- A source may be visible to you but outside the Agent's access.
- A generated answer may contain errors even when it names a source.
- A proposed external action is not proof that the destination system accepted it.

Use the source and result together. Define the material and period you expect, ask the Agent to show the basis for important claims, and compare the answer with the source. Escalate decisions that need professional judgement, authority, or a complete record.

When the gap is a missing source, read [Troubleshoot missing information](/en/knowledge/troubleshoot-missing-information/#troubleshoot-missing-information). When you have an answer, use [Review results](/en/getting-started/review-results/#review-results-before-relying-on-them) before relying on it.
