# Workspace access checklist

If a member cannot see an Agent, source, or workspace area, check their role, Space membership, and Agent access settings. Review the required data permissions before assigning an Agent a new task.

## Check in order

1. **Workspace:** confirm that you are signed in to the intended Counso AI workspace.
2. **Area:** check whether the task belongs in **Work**, **Spaces**, or **Admin**.
3. **User:** confirm that the person has the role needed for the task.
4. **Agent:** check the Agent's intended users, editors, and publication state.
5. **Data:** check that the required source is in the Agent's configured data scope.
6. **Result:** use a small request and review the result before expanding access.

Keep the scope as narrow as the task allows. Giving a person access to an Agent does not automatically make every source or tool available, and adding a source does not automatically make every action appropriate. Ask an administrator to review the configuration when the expected access is still missing.

Write down the area, task, and access question when you request help. Do not share passwords or copy restricted material into a conversation to work around an access problem. Once access is corrected, repeat the small request and [review the result](/en/getting-started/review-results/#review-results-before-relying-on-them).
