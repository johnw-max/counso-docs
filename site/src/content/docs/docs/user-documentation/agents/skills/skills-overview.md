# Understand Skills

Skills are reusable packages of instructions and tools that Agents can use for a type of work. A Skill can give an Agent a repeatable method without putting every detail into the Agent's main instructions.

## When a Skill helps

Use a Skill when:

- a task follows the same checks each time;
- several Agents need the same guidance; or
- a team wants to maintain a procedure in one place.

For example, a team might use a Skill that asks an Agent to collect the source, list missing information, and prepare a reviewable summary. The Skill does not remove the need to check the source or decide whether an action is authorised.

## Choose deliberately

Before adding a Skill, read its description and ask whether it matches the Agent's purpose. Check what information the work needs and whether the Skill includes tools that can affect an external system. Start with one small, read-only task so you can compare the result with the source.

Skills, Tools, and Knowledge serve different roles: a Skill packages reusable guidance and tools, a Tool represents an available action, and Knowledge provides sources for an answer. Keep the configuration understandable so people can review why an Agent produced a result.

To find or manage the available packages, read [Find and manage Skills](/en/skills/find-and-manage/#find-and-manage-skills). When an answer is produced, use [Review results](/en/getting-started/review-results/#review-results-before-relying-on-them) to check it before sharing.
