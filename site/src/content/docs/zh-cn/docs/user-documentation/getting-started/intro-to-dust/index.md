# Counso AI 简介

Counso AI 是面向个人和团队的 AI 工作区。你可以使用可用的 AI 模型，处理文档和知识来源，创建和使用智能体（Agent），连接业务应用，并执行受支持的工作流。你能看到和使用的内容取决于工作区、账号角色以及已开放的功能。

## 从应用开始

打开 [Counso AI](https://app.counso.ai)。登录后，先认识三个主要区域：

1. **Work** 用于发起对话，并查找 Agent、Skill、Pod 和 Conversation。
2. **Spaces** 用于整理工作区的数据区域。
3. **Admin** 用于管理工作区设置和权限，通常由管理员使用。

不同账号看到的标签和项目可能不同。如果你看不到某个区域或智能体，请让工作区管理员检查你的访问权限。

## 第一个可检查的动作

在 **Work** 中点击新建对话按钮（**Create a new conversation**）。检查当前选中的 Agent，查看可用的模型控件，再描述一个范围较小的任务，并提供智能体完成任务所需的上下文。第一次请求适合选择容易复核的事情，例如总结一份你有权使用的文档。分享或依赖回答前，请自己检查来源和关键事实。可用模型和工具取决于工作区配置和权限。

## 下一步学习什么

阅读[工作区导航](/zh-cn/getting-started/workspace-navigation/#工作区导航)，了解常用区域的位置。然后分别认识 Agent、Skill、Tool、Connection 和 Space。如果工作流可能修改外部记录、发送消息、发布内容或产生费用，请先确认要执行的动作，完成后再到目标系统检查结果。
