# 认识 Knowledge

Knowledge（知识）为智能体准备回答时提供可参考的来源。来源可以来自工作区通过配置的数据区域提供的资料。智能体仍然需要清楚的指令，才能知道如何使用这些来源。

## Knowledge 是来源，不是结论

Knowledge 可以帮助智能体找到相关上下文，但不能保证回答完整、最新或正确。来源可能缺失、过时、重复，或不在智能体的访问范围内。在重要任务中，请让智能体说明它依据了哪些材料。

选择与任务相符的来源。流程可能需要当前政策；复核可能需要原始文件和对应期间；总结可能需要完整资料，而不是一份方便的文件。把无关材料排除在智能体范围外，结果会更容易检查。

## 谨慎使用 Knowledge

依赖回答前，将重要表述与来源对照，检查日期、金额、名称和条件。如果来源不完整，就补充材料或收窄问题。不要把听起来确定的回答当成来源一定可用，或外部动作已经完成的证明。

关于选择资料，请阅读[选择 Knowledge 来源](/zh-cn/knowledge/choose-sources/#选择-knowledge-来源)。关于实际检查方法，请阅读[检查结果](/zh-cn/getting-started/review-results/#在依赖结果前先检查)。
