# 认识 Skills

Skill（技能）是可复用的指令和工具包，智能体可以用它完成一类工作。Skill 能提供可重复的方法，不必把所有细节都写进智能体的主要指令。

## Skill 什么时候有用

以下情况适合使用 Skill：

- 任务每次都要经过相同的检查；
- 多个智能体需要同一套指导；
- 团队希望集中维护一套流程。

例如，一个团队可以使用 Skill，让智能体收集来源、列出缺失信息，并准备一份可复核的摘要。Skill 不会替代来源检查，也不会替你判断某项动作是否获得授权。

## 有意识地选择

添加 Skill 前先阅读说明，确认它与智能体的用途相符。了解任务需要什么信息，并检查 Skill 是否包含可能影响外部系统的工具。第一次可以用一个小型只读任务，拿结果与来源进行对照。

Skill、Tool 和 Knowledge 的作用不同：Skill 封装可复用的指导和工具，Tool 代表可用的动作，Knowledge 为回答提供来源。保持配置清楚，方便团队理解智能体为什么得到某个结果。

查找或管理可用包，请阅读[查找和管理 Skills](/zh-cn/skills/find-and-manage/#查找和管理-skills)。得到回答后，请使用[检查结果](/zh-cn/getting-started/review-results/#在依赖结果前先检查)再分享。
