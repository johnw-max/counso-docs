# 选择智能体

Agent（智能体）是为某类任务配置的工作方式。不同智能体可能有不同的指令、数据访问范围、技能和工具。请选择用途和访问范围都符合当前任务及授权的智能体。

## 在新对话中选择

1. 打开 [Counso AI](https://app.counso.ai)，点击 **Create a new conversation（新建对话）**。
2. 打开当前选中智能体的控件，按名称搜索智能体。
3. 从搜索结果中选择智能体，然后提出一个与其用途相符的小任务。

## 在开始前比较智能体

新对话主页面也会列出智能体及其说明。你可以在这里使用 **All agents（所有智能体）** 或 **Editable by me（我可编辑）** 浏览列表，再作选择。这些列表视图位于主页面，不在当前选中智能体的搜索菜单中。

如果列表里有多个相似选项，优先选择说明最清楚、完成任务所需访问范围最小的智能体。不要为了测试访问范围，就把敏感信息放入对话。

## 找不到智能体时

智能体可能因为发布状态、访问设置或工作区配置而不可见。请让工作区管理员检查你的访问权限，以及该智能体面向的使用者。可用模型和工具同样取决于工作区配置和权限。

选择智能体本身不代表连接的外部服务已经接受某项动作。请检查回答，并到目标系统核对重要结果。选择智能体后如何发起请求，请阅读[开始第一次对话](/zh-cn/getting-started/first-conversation/#开始第一次对话)。
