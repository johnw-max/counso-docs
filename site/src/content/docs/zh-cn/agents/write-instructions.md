# 编写智能体指令

指令告诉智能体应该如何完成工作。好的指令足够具体，能引导可重复的任务；同时也应保留空间，让智能体处理每次对话中不同的输入。

## 实用结构

可以按以下顺序编写：

1. **角色和目的：** 说明智能体帮助谁，以及它负责什么结果。
2. **输入：** 说明可以使用哪些来源，以及来源缺失时如何处理。
3. **流程：** 按顺序写出需要执行的检查或判断。
4. **输出：** 规定格式、详细程度，以及需要人工复核的项目。
5. **边界：** 说明未经确认不得推断、披露或修改什么。

使用清楚的语言和短段落。只有在能说明预期结果时才加入一个代表性示例。不要把凭据或密钥放进指令和对话；访问已授权服务时，请使用指定的连接方式。

## 检查配置

在智能体编辑器的 **Instructions（指令）** 区域编写内容，并使用已有的格式控件整理文本。选择工作区提供的模型选项。保存前，确认智能体能否用你选择的数据和工具完成任务。如果不能，先收窄任务或调整访问方案，不要默认扩大访问范围。

用一条小型、非敏感的请求检查结果，并与来源进行对照。如果结果不完整，每次只改进一项指令：说明输入、补充检查，或明确输出格式。如果任务可能影响外部系统，请在指令中要求先确认，并在目标系统核对结果。
