# 获取 Counso 支持

## 前提

确定工作区、角色、智能体或 Space 及最小复现请求，不发送密码、密钥、令牌、客户记录或私密对话。

## 步骤

1. 检查智能体、来源、Space 和用量，记录错误和时间。
2. 安全地重复一次最小请求，记录影响范围。
3. 使用 Counso 显示的支持入口或管理员批准渠道。
4. 提供工作区标识、区域、客户端、复现、预期/实际结果和追踪编号，只附脱敏材料。

### 支持报告示例

```text
我已登录账务工作区，在 Work > Agent conversation 中请求“列出八月未付供应商账单，并附来源和金额”。回答称找不到来源。两名成员遇到了相同结果，没有尝试写入。提交报告时附上实际请求时间和页面显示的追踪编号。

```

这些信息有助于支持人员定位调查范围；需要补充材料时，再提供对应的脱敏样本。

## 结果

支持人员收到可复现且保护隐私的报告。

## 常见问题

**公开状态页在哪里？** 只使用 Counso 提供的链接。

**应发公开 issue 吗？** 非敏感问题可用公开渠道，账号和安全问题走私密渠道。

**看不到支持控件怎么办？** 请所有者提供已批准的 Counso 联系方式。
