# 查找和管理 Skills

进入 **Work**，打开 **Skills（技能）**。Skills 页面用于查找可复用的技能包，并查看哪些技能对你可用。

## 查找 Skill

1. 使用搜索框按名称查找 Skill。
2. 选择 **All（全部）** 查看启用中的包。
3. 需要自己维护技能时，选择 **Editable by me（我可编辑）**。
4. 需要查看旧包时，选择 **Archived（已归档）**。
5. 需要扩大搜索范围时，使用 **Show hidden skills（显示隐藏技能）** 或 **All availabilities（所有可用性）**。

添加到智能体前，先阅读 Skill 的说明和可用性。名称相似并不代表适合使用，还要检查它服务的任务、可能使用的信息，以及其中工具是否符合预期结果。

## 维护 Skill

只有在有明确且值得复用的流程时，才使用 **Create skill（创建技能）**。名称要聚焦，并说明预期输入和输出。把一套流程保持在一起，不要把无关任务混成一个包。向其他人开放变更前，先使用非敏感材料检查，并将结果与来源对照。

如果找不到某个 Skill，请检查列表视图、隐藏设置、可用性筛选和工作区访问权限。如果该技能应该对你可用，请让管理员检查配置。关于 Skill 的作用，请阅读[认识 Skills](/zh-cn/skills/overview/#认识-skills)。
