# 排查缺失信息

智能体无法回答时，先区分三种可能：来源不存在，请求缺少上下文，或智能体无法访问相关资料。

## 缩小问题范围

1. 写明你预期智能体使用的文档、记录、主题和期间。
2. 询问智能体找到了哪些信息，以及缺少什么。
3. 检查来源是否位于本任务应该使用的工作区区域和访问范围内。
4. 只有在获得授权时，才补充缺失的上下文或来源。
5. 用清楚的预期结果重新提问。

如果两个来源冲突，请保留两者，并让智能体说明差异。如果来源太旧，请寻找当前修订版本。如果你能访问来源、智能体却不能，请让管理员检查智能体的数据与访问设置。不要为了绕过权限，把受限内容复制进对话。

如果仍然找不到信息，请在结果中说明缺口，并交给人工跟进。不要凭猜测补全金额、日期、身份或审批。重新提问后，根据来源[检查结果](/zh-cn/getting-started/review-results/#在依赖结果前先检查)。
