# 选择 Knowledge 来源

选择 Knowledge（知识）来源时，可以问自己四个问题：

1. **它能回答这个任务吗？** 让来源匹配问题、工作流或期间。
2. **它是否权威？** 优先使用拥有该信息的文档或系统。
3. **它是否足够新？** 检查日期，以及是否有新修订替代它。
4. **这个智能体和使用者有权使用它吗？** 确认来源属于智能体配置的访问范围。

政策问题使用当前批准的政策；交易复核将原始记录和支持材料放在一起；总结任务先说明要包含哪些文件，避免无意遗漏相关来源。

不要因为方便就添加范围很大的资料区。额外材料会让回答难以追溯，也可能暴露与任务无关的信息。如果两个来源不一致，请让智能体展示冲突，并指出日期或修订版本，不要默默选择其中一个。

选好来源后，在请求中写清楚希望得到的结果、相关期间或文档。然后根据来源[检查结果](/zh-cn/getting-started/review-results/#在依赖结果前先检查)。如果智能体找不到资料，请先阅读[排查缺失信息](/zh-cn/knowledge/troubleshoot-missing-information/#排查缺失信息)，再考虑扩大访问范围。
